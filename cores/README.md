# 코어 개발 현황과 로드맵

| 코어 | 현재 상태 | 첫 범위 | 제품 상태 |
| --- | --- | --- | --- |
| [GB/GBC](gbc/README.md) | C44 실기 정상 확인 | 기존 지원 매퍼·메뉴·저장·RTC | sd2snesHST 0.9.0 편입 계획 |
| [NES](nes/README.md) | 조사 대기 | 기본 카트리지 경로와 화면·소리·입력 | 미포함 |
| [PC Engine](pce/README.md) | 조사 대기 | HuCard 기본 경로 우선 | 미포함 |

우선순위 제안은 **GBC 안정 배포 → NES 가능성 조사 → 공통 경계 검증 → PCE 가능성 조사**입니다. 구현 범위와 일정은 자원·입출력 실험 뒤 결정합니다. 비용에 비해 가능성이 낮으면 근거를 기록하고 중단·축소합니다.

각 코어는 [제안서](CORE-PROPOSAL.ko.md)와 [이식 절차](../docs/PORTING-PLAYBOOK.ko.md)로 시작합니다. [등록부](registry.json)는 실제 구현 상태와 코드 경로를 구분하며, 이름만 추가했다고 지원 완료로 보지 않습니다.
