# PC Engine — 가능성 조사 대기

아직 PCE 구현이나 실행 성공을 주장하지 않습니다. 첫 범위는 **HuCard 기본 실행 경로**를 제안합니다. CD-ROM²·SuperGrafx·추가 메모리 및 주변기기는 별도 과제로 둡니다.

## 첫 조사

1. upstream 코어의 출처·고정 커밋·고지와 보드 요구.
2. CPU·영상·음향·메모리 경로의 독립 합성 비용과 클록·RAM 접근 요구.
3. 가변 화면 모드·색·오디오를 SNES로 전달할 실측/모델 예산.
4. ROM 뱅킹, 입력, 저장 기능이 있는 소프트웨어의 보존 방식.
5. 메뉴 복귀·재실행·다른 코어 전환 때 메모리 소유권과 초기화.
6. 자작 진단 → 최소 실기 표본 → 범위 확대.

NES 작업에서 검증한 부분만 공통 기반으로 사용합니다. GBC 또는 NES의 화면·RAM·타이밍 수치를 그대로 적용하지 않습니다. 비용이 커지면 지원 범위를 줄이거나 보류한 근거를 기록합니다.
