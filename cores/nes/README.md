# NES — 가능성 조사 대기

아직 NES 구현이나 실행 성공을 주장하지 않습니다. 여러 기존 코어 후보의 출처·라이선스·이식 범위를 비교한 뒤 후보를 고정합니다.

## 첫 조사

1. 사용할 upstream의 고정 커밋·지원 범위·도구·고지와 수정 가능 범위.
2. CPU/PPU/APU, 최소 카트리지 매퍼를 포함한 독립 합성의 LE/M9K/PLL 및 클록 요구.
3. NES 출력 프레임·색·오디오를 SNES 출력 경로에 전달할 예산. 정확한 변환·프레임 정책을 먼저 결정.
4. 최소 자작 진단 프로그램으로 화면·입력·소리·리셋 확인.
5. 기본 카트리지부터 한 단계씩 매퍼·배터리 저장을 확대.
6. 기존 GBC와 코어 전환 및 공통 경로 회귀.

FDS·추가 음원·특수 매퍼·강제 저장 등은 기본 실행 가능성이 확인된 뒤 별도로 범위를 결정합니다. NES가 “간단할 것”이라는 가정만으로 완료 일정이나 제품 버전을 지정하지 않습니다.

다음 산출물은 [제안서](../CORE-PROPOSAL.ko.md)를 채운 조사 결과이며, 바로 배포 바이너리를 만드는 단계가 아닙니다.
