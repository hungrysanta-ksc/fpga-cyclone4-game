# H1 패턴 생산기와 SNES DMA033
2026-10-06. 후보 **NES-H1-PATTERN-033**.

**H1 자체 패턴 생산기와 SNES DMA 프로그램을 구현하고 각각 실제 실행으로 검증했다.**
031 전송 RTL은 변경하지 않았다. 실기용 보드 통합은 아직 남아 있다.

|검증|실제 결과|
|---|---|
|Questa RTL|3개 클록 조합 × 5조건, 총43,008바이트 정확히 일치|
|Mesen 정상 실행|WAIT 이후1→2→3→1→2→3, 6회 실제 PPU DMA,12,288바이트 일치|
|Mesen 오류 실행|미응답·잘못된 길이 모두 LINK ERROR, 패턴 DMA/commit 0회|
|화면 대조|정상7장+오류4장, 총673,024화소 일치|
|H1 전용 Quartus map/fit|1,144LE /104LAB /20M9K,758registers, 첫 실행 성공|

## 구현과 관찰

생산기는2048바이트 타일맵3개를 순환하며 두 슬롯이 차면 같은 순번에서 기다린다.
전체 전송·소비 완료 전에는 슬롯을 반환하지 않는다. RESET 도중 읽기와 생산 중단,
새 세대 재시작 및 잘못된 epoch 주입 후 정지를 확인했다.
총43,008바이트는 세 실행의14,336바이트씩이며, 매 실행6페이지+RESET 뒤1페이지다.

SNES 프로그램은 큰 제목 NES H1 033, GRID/BARS/CROSS, LINK WAIT/ERROR를 표시한다.
READY·길이·오류를 확인한 후40:8000부터2048바이트를2118/2119로 DMA한다.
소비 길이 확인과commit 응답 뒤 화면 번호를 갱신하며 정상 페이지 간격은60프레임이었다.
오류에서는 자동 성공 표시나 임의 재시도를 하지 않고 명시적인 오류 화면으로 정지한다.

실제 DMA와commit 구간은18,190~18,240 master clocks였고 최소 VBlank 여유는32,118이었다.
이 수치는 아래 장치 모델의 응답 지연을 사용한 Mesen 실행에 한정한다.
정상 픽셀뿐 아니라 빈 위아래7/8줄까지 포함한239줄 전체를 대조했다.
실제 실행 기준 화면 (로컬 비공개 자료: `local-h1-pattern-033/h1-reference-contact.png`).

## 검증 범위

RTL의 논리 핀 시험과 실제 SNES 프로그램 실행은 **별도 실행**이다.
Mesen에는 RTL에서 실제 읽힌 바이트를 공급하는 Lua MMIO 장치 모델을 연결했다.
모델은stage 대기21,478 master clocks,commit200clocks를 가정한다.
이는 실시간 RTL 공동 시뮬레이션이나 물리 버스 응답 시간의 증명이 아니다.
다만 SNES CPU가 실제 명령을 실행하고 DMA와 PPU가 실제 화면을 만들며, VRAM/화면을 주입하지 않는다.

자원 구성은 H1 전용이며 NES 코어가 없다. 생산기ROM6KiB/8M9K,
queue6KiB/8M9K,stage3KiB/4M9K가 보고서에 남았다.
96virtualpins와미할당clock2pins를 사용했다. STA와PLL/물리핀/IO/loader는 미포함이다.
032의13,417LE/923LAB/24M9K 공동 배치 및40LAB 잔여 판단을 대체하거나 두 수치를 합산하지 않는다.

Quartus 경고는 원문 보존했다. async_reg 미인식, ROM의 미사용 write port,
페이지/주소 폭 절삭, RAM read-during-write 및 미할당 clock pins가 포함된다.
페이지 값은0..2를 순환하며 이번 시험에서 일치했지만, 경고0이나 CDC 완료를 주장하지 않는다.
실제 보드 단계에서 Quartus용 동기화 식별·배치·타이밍 제약을 적용하고 확인해야 한다.

## 보존한 실패와 수정

- 첫 빌드는 새 문구에 쓰는K/W/M/P 글꼴이 없어 실패했다.033 생성기에만 글꼴을 추가하고 다시 빌드했다.
- 정상 Mesen 실행은 완료됐지만 최초 감사기가 DMA 간격을 항상8클록으로 가정해 실패했다.
  실제 기록과 로컬 Mesen 구현에서 DRAM refresh40클록 정지를 확인했다.
  감사기는8/48간격과 각48간격의 리프레시 위치를 검사하도록 수정했다.
  ROM·Lua·원시 실행은 바꾸지 않고 같은 실행을 재검증했다.

65535번째 publish의 정지 처리는 구현했으나 이번 유한 실행에서 그 경계를 실행하지 않았다.
epoch1은 공통 cold reset 가정이다. warm reset과menu 복귀용 세대 전달은 다음 보드 작업 대상이다.
224줄은 자체 진단용이며 NES 표시 정책을 변경하지 않는다.
