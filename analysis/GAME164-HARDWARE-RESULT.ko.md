# NES164 실기 결과 — 검정 구간 제거 통과, 정상 플레이 미달성

**검정 구간은 없어졌고 사운드는 사용자 청취상 정상으로 보인다. 그러나 화면이 심하게 끊겨 정상 플레이가 불가능했으므로 연속 화면 목표는 미달성이다.** 기본 조작은 정상으로 보였으며, 아래 방향을 누른 채 유지하는 시험은 하지 않았다.

`screen_error=169`는 A9 초기화 성공 코드이며 게임 오류가 아니다. 종료는 정상 실행 예산 만료 경로다. 시간은 펌웨어의 경과 시각이며 독립적인 실측 초가 아니다. 예산에는 제목·선택·월드맵 시간도 포함된다.

67.27초 영상에서2초 간격으로 추출한34개 프레임을 확인했다. 제목·선택·월드맵·첫 레벨 진입, 이동·점프와 이후 메뉴가 보인다. 카메라29.97fps는 게임 FPS가 아니다. `screen_frames=281`도 신뢰 플래그0이므로 측정 FPS로 환산하지 않는다. 반복 검정 구간이 사라졌다는 판정과 정상 플레이가 불가능할 정도의 끊김 판정은 사용자의 직접 관찰을 근거로 한다. 드문 영상 표본만으로 모든 짧은 검정 구간의 부재를 증명하지는 않는다. 사운드는 사용자 청취 보고이며 별도 청취·채널별 음질 측정은 하지 않았다.

## 끊김의 해석

164는 첫 화면 이후 강제 블랭크를 없앴지만, 전체57344바이트를5632바이트씩10회와1024바이트1회로 나눠 **11번의 수직 공백**에 걸쳐 보낸다. 준비·캡처 대기도 별도로 있다. 따라서 검정 화면 없이 표시를 유지하는 목표와 빠르게 새 화면을 완성하는 목표는 서로 다르며, 이번 결과는 전자만 통과했다.

이 구조 자체가 전체 화면 갱신 속도를 제한하므로 심한 끊김과 부합한다. 실행·ROM 오류0은 오류 감지 없이 실행을 마쳤다는 뜻이지 부드러운 표시나 정확한 코어 속도를 보증하지 않는다. 현재 로그로 NES 내부 프레임 속도와 전송 대기의 기여도를 각각 측정한 것은 아니다. 이미 확인한 CRT 촬영 대각선은 코어 결함으로 세지 않는다.

입력 변화127건 중 마지막16건만 남고111건은 덮어써졌다. DOWN/NONE 기록이 있지만 실제 손의 유지 여부가 없으므로 유지 실패·해결 어느 쪽도 판정하지 않는다. 사용자는 이번에 유지 시험을 못 했다고 명시했다. `ppu_history_flags=1`은 오류가 없는 정상 말단 기록이다.

## 다음 작업

PR106 머지 후 **영상 전송량과 전체 화면 갱신 지연을 줄여 실제 SMB3를 조작 가능한 상태로 만드는 것**이 우선이다. 기존 GBC 표시 경로와 현재 전송·메모리 제약을 먼저 비교하고, 필요한 경로만 바꿔 최소 검증 후 실기 ROM으로 평가한다. 수직 공백 예산을 넘겨 DMA 청크만 키우거나 같은 검정 화면 진단을 반복하지 않는다. 현재 LAB3/M9K0 여유에서 전체 화면 이중 버퍼나 더 많은 메모리가 가능하다고 가정하지 않는다.

163 SPC 초기화·162 음성 경로, 정상 오류 감지·정지·메뉴 복귀를 보존한다. 화면이 조작 가능한 수준이 된 뒤60초 제한 해제와 오류/본체 리셋 시 안전 로그·메뉴 회수, 이어 장시간 입력 유지를 평가한다. 아래 방향 유지는 미확인으로 남기되 현재 영상 병목보다 먼저 입력 단독 진단을 늘리지 않는다. 같은164·044/GBC·사운드 전용 시험·무변경 전체 적재 시험은 재요청하지 않는다.

이번 커밋은 결과 기록만 수행한다. 새 펌웨어·FPGA·패키지를 만들지 않았고, 동결164 제작 증거와 이전 소스 핀을 변경하지 않았다.
