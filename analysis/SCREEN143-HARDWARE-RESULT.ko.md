# NES143 실기 결과 — 기본 표시 비교와 메뉴 복귀 통과

사용자가 파란 배경(A), 빨강·청록 양면(B), 반복 무늬(C), 기존 진단 화면(D)의 순서를 사진과 설명으로 확인했고, 후속 답변에서 자동 메뉴 복귀도 정상이라고 확인했다. A/B는 기준과 명확히 일치한다. C/D는 기대하는 큰 형태와 부합하며 사진으로 픽셀 단위 정확성을 보증하지 않는다. 카메라 대각선 띠는 판정에서 제외한다.

로그 47개 기록에서 81,920바이트 적재·전량 대조, RUN/STOP, base 복원이 통과했고 기록된 오류는 0이다. 표시 구간은 521,160~552,870ms(31.71초), 메뉴 준비 완료는 556,120ms(9분16.12초)다. 실제 메뉴 복귀는 로그와 별도로 사용자 확인을 받았다.

`screen_stage=112(0x70)`와 `screen_phase_mask=8`은 예상99/15와 다르다. 실제 보인 A/B/C를 단계 미실행으로 해석하지 않는다. `screen_frames=122`도 독립적으로 확인한 정상 TV 프레임 수가 아니다. 표식 관측 경로의 정확성을 미해결 항목으로 남긴다.

기본 표시·ROM DMA·기존 NES 화면 경로의 육안 비교는 실기 진전으로 인정한다. 같은143 또는044 복원 시험을 다시 요구하지 않는다. 다음144에서는 무작위 CHR를 읽을 수 있는 NES 글자·테두리로 바꾸고 실제 NES가 선택하는 뱅크를 구별한다. 관측 표식 문제는 별도로 한정해 다룬다. 게임·패드·오디오 완료와는 구분한다.
