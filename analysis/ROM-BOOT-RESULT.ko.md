# NES053 ROM 적재·실행 연결 결과

**진단 ROM을 PSRAM 핀 쓰기로 적재한 뒤 실제 NES 코어를 실행하는 경로를 연결했다.** 메모리 모델을 미리 초기화하지 않고, 로더가 쓴 데이터를 읽어 실행했다.

- PRG64KiB+CHR16/32KiB 두 구성에서 단위 검사360505개,180226바이트 읽기 확인을 통과했다.
- 적재 전 실행, 잘못된 종료·중복 명령, 실행 중 쓰기 등8가지 오류 시나리오를 검증했다. 쓰기 중 오류·중지는 진행 중 펄스와 유지 시간을 마친 뒤 핀을 해제한다.
- 실제 코어2종·8프레임의491520픽셀이052와 같다. 패킷은 공개 시각 필드 외에 일치하며, 프레임별 시각 차이는 {'banks32': [-4, -4, -4, -4], 'fine_x': [1, 1, 1, 1]} NES클록이다. 적재 시간에 따른 리셋 해제 위상 차이를 기록했다.
- 공동 합성·배치13612LE/929LAB/26M9K 통과. LAB34개가 남았다.

여기서 완성한 것은 **로더와 메모리 소유권 RTL**이다. MCU의 실제 SPI 전송, 보드 클록 연결, ROM 무결성 확인, SNES 소비자 및 실제 핀 타이밍은 아직 연결·검증해야 한다. 길이가 맞게 적재됐다는 상태를 데이터 무결성 검증으로 취급하지 않는다.

초기 테스트의 명령 타이밍 문제와 통합 코드의 선언 순서 문제를 수정했고, 실패 기록도 보존했다. 최종 단위·실제 코어·배치는 같은 최종 회로 소스를 사용한다.

다음은044 보드 제어에 MCU 적재 명령과 상태 보고를 붙이는 작업이다. **새 실기용 SD 이미지는 없으며044와GBC는 유지했다.**
