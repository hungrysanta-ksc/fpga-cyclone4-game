# NES163 실기 결과 — 사운드·첫 레벨 플레이 통과

**사용자가 사운드 출력과 플레이가 정상이라고 확인했다. 로그의 본체 초기화 성공 A9와 일치하며, 이번 무음 수정 목표는 실기에서 달성했다.** 영상의 기침은 외부 녹음음으로 취급하며 게임 음질 문제에 포함하지 않는다.

## 로그와 영상

| 항목 | 결과 |
| --- | --- |
| 식별·ROM | NES-GAME-163 / 6B·E5, 적재·비교 각각393216바이트, 오류0 |
| 본체 초기화 | spc_init_status_hex=a9, spc_init_status_valid=1, spc_unmute_confirmed=1 |
| 실행·정지 | run_passed=1, run/ROM/first/stop 오류0, fault_context_valid=0 |
| 실행 구간 | DISPLAY_NEXT232760 → DISPLAY_STOPPED293410ms: **60.650초** |
| 회수 경로 | STOP·base 복원 성공, MENU_PREPARED296540ms: 정지 이후3.130초 |
| 진행 기록 | 512바이트×104레코드, seq0..103 연속·경과 시각 단조 증가 |

`screen_error=169`는163에서 재사용한 **A9 성공 코드**다. 게임 오류는0이다. 위 시간은 펌웨어 경과 시각이며 독립적인 실측 초가 아니다. 60초 예산은 제목·월드맵까지 포함하고 첫 레벨 안에서만60초가 아니다.

66.77초 영상에서2초 간격으로 추출한33개 프레임을 확인했다. 제목·선택·월드맵·첫 레벨 진입, 마리오의 이동과 점프, 이후 월드맵이 보인다. 녹음에는 AAC 음성 트랙이 있으나 사운드 정상 판정은 **사용자의 직접 청취 확인**에 따른다. 이번 분석에서 별도 청취·주파수나 채널별 음질 측정은 하지 않았다. 사진의 대각선·명암 띠는 이미 확인한 CRT 촬영 간섭으로 코어 결함 판정에 사용하지 않는다.

영상 표본은 월드맵에서 끝나므로 실행 종료 후 파일 선택 메뉴의 실제 표시까지 확인한 것은 아니다. 로그는 안전 정지·base 복원·메뉴 준비 완료를 확인한다. 이번 메시지에는 메뉴 복귀의 별도 사용자 확인도 없어 그 항목은 과장하지 않는다. 이미 확인한044/GBC 복원 재시험은 요구하지 않는다.

## 의미와 남은 작업

162의 FPGA 로직·음성 경로를 유지한 채 본체 SPC/DSP 초기화를 추가한163에서 소리가 정상화됐다. 따라서 빠져 있던 본체 초기화 보완이 이번 무음 해결에 유효했다. 초기화 읽기 확인만으로 소리 성공을 추정한 것이 아니라 실제 청취 결과가 추가된 것이다. 전체 게임 호환성·모든 음원 채널의 정확도·장시간 안정성까지 완료한 것은 아니다.

입력 변화306건 중 마지막16건만 남고290건은 덮어써졌다. 이는 게임이 읽은 변화 기록이며 물리 버튼 클릭 횟수가 아니다. DOWN 유지 문제 해결 근거로 쓰지 않는다. `screen_frames=405`는 신뢰 플래그0이므로 FPS로 해석하지 않는다. `ppu_history_flags=1`은 오류가 없는 정상 말단 기록이다.

**PR105 머지 후 다음 목표는 연속 화면이다.** 현재 전체57344바이트 DMA의 강제 블랭크·hold6 구조를 개선하며,163의 SPC 초기화와162 음성 경로·정상 정지/회수를 유지한다. LAB3/M9K0 여유를 고려하고, 바뀐 경로의 최소 검증 후 실제 SMB3로 판단한다. 단순히 hold를0으로 바꾸고 연속 화면이 완성됐다고 판단하거나 범용 디버그 회로를 추가하지 않는다.

사운드·화면 확인 뒤 정상60초 제한 해제와 오류/본체 리셋 시 안전 로그·메뉴 회수, 이후 장시간 입력 유지 평가 순서다. 현재60초 제한·리셋 로그 미구현·DOWN 유지 미해결 상태를 그대로 기록한다. 같은 사운드 시험·044/GBC·무변경 전체 적재 시뮬레이션은 반복하지 않는다.

이번 결과 커밋은 새 펌웨어·FPGA·패키지를 만들지 않는다. 동결163 자료와 기존 공개 소스 핀은 변경하지 않는다.
