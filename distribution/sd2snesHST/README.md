# sd2snesHST
**HungrySanTa의 FXPAK Pro 추가 코어 프로젝트**

> 0.9.0 공개 준비 초안입니다. 배포 저장소와 Release는 아직 만들지 않았습니다.

sd2snesHST는 FXPAK Pro에서 새로운 게임 코어를 사용할 수 있도록 확장하는 프로젝트입니다. HST는 20년 넘게 이어 온 프리랜서 프로그래머 팀 **HungrySanTa**의 약자입니다.

첫 버전 **0.9.0**은 실기 검증을 마친 GB/GBC 코어를 제공합니다. 게임 저장, RTC, 강제 저장 4슬롯, 약 3배 빨리감기, 소리 설정과 게임 리셋을 지원합니다.

## 다운로드와 설치

공개 후 이 저장소의 Releases에서 **v0.9.0** 업데이트 ZIP을 내려받도록 안내할 예정입니다.

- 대상: **FXPAK Pro / Mk.III** — STM32 MCU + Cyclone IV EP4CE15F17C8.
- 정상 설치된 공식 sd2snes 1.11.2 계열 위에 적용하는 업데이트입니다.
- 설치 전 기존 SD의 펌웨어·세이브·설정을 백업하고 ZIP의 파일을 같은 폴더에 합쳐 복사합니다.
- 구형 SD2SNES/Mk.II와 다른 포크를 섞은 설치는 검증하지 않았습니다.

## 게임 실행

게임 복사본의 확장자를 `.egbc`로 바꾸면 새 GB/GBC 코어로 실행됩니다. `.gb`와 `.gbc`는 기존 SGB 경로를 사용하며 기존 SGB 파일이 필요합니다.

L + R + Start로 코어 메뉴를 열고 R을 누르고 있으면 빨리감기를 사용합니다. WRITE SRAM은 게임의 저장 RAM을 SD에 기록하고, SAVE STATE / LOAD STATE는 현재 실행 상태를 저장·복원합니다.

게임 ROM, 개인 세이브, SGB 코어·BIOS는 배포물에 포함하지 않습니다. NES·PCE는 향후 조사 대상이며 0.9.0에 포함되지 않습니다.

## 문제 보고와 소스

문제를 보고할 때 제품 버전, 기기, 게임 이름·지역·패치 버전, 재현 순서와 화면·소리·입력 상태를 적어 주세요. 일반 배포판은 진단 로그를 자동 생성하지 않습니다. ROM과 개인 세이브 전체를 공개 이슈에 올리지 마세요.

구현과 개발 기록은 [개발 저장소](https://github.com/hungrysanta-ksc/fpga-cyclone4-game)에서 관리합니다. 각 릴리스에는 해당 바이너리의 고정 소스 커밋, 대응 소스 ZIP, 빌드 지침과 라이선스 고지를 연결합니다.
