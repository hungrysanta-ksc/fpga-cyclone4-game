# MMC893 · 모험도 4 일반 실행

MMC892에서 부팅 진단은 메뉴로 복귀했지만 일반 실행은 검은 화면에 머물렀다. MMC893은 ARM이 ROM 적재용 임시 메모리를 반환한 뒤 첫 화면을 준비한다.

1. 전원을 끄고 ZIP에서 `MMC893-ADVENTURE-60SEC-SD-ROOT` 폴더 **안의 내용물**을 SD 루트에 복사한다.
2. 지난번에 사용한 `sd2snes/nes/mmc892.nes`를 같은 폴더에 `mmc893.nes`라는 이름으로 복사한다.
3. SD 메뉴의 **`NES MMC3 893.nh1`**을 선택한다. 로딩 뒤 첫 화면이 보이는지 확인하고 입력 없이 60초 동안 둔다. 오프닝에서 스테이지 데모로 넘어가는지, 끝나면 메뉴로 복귀하는지 확인한다.
4. 메뉴로 돌아오면 `sd2snes/nes-progress-mmc893.txt`, `nes-budget-mmc893.txt`, `nes-game-last-mmc893.txt`를 따로 보관한다. 검은 화면이 지속되면 첫 화면이나 소리를 한 번이라도 확인했는지와 생성된 로그만 전달한다. 같은 판을 다시 실행하면 진행 로그가 덮어써진다.

게임 ROM과 RESTORE는 동봉하지 않는다. 이번 실기 판정은 첫 화면·60초 종료·메뉴 복귀이며, 완주한 실행만 오프닝 1–30초와 데모 30–60초 FPS 비교에 사용한다.
