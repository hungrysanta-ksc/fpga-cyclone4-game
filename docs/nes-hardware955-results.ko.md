# MMC955 실기 · 모험도 4 무입력 60초

후속 실기 시험의 기준은 MMC955다. MMC925와 MMC955 각 1회를 동일한 화면 공개 시각 기준으로 비교했다. 30초 경계는 데모에 포함한다.

| 구간 | MMC925 표시 수 | MMC955 표시 수 | MMC925 FPS | MMC955 FPS | 변화 |
|---|---:|---:|---:|---:|---:|
| 1–30초 오프닝 | 642 | 675 | 22.14 | 23.28 | +5.14% |
| 30–60초 데모 | 667 | 717 | 22.23 | 23.90 | +7.50% |
| 데모 중 55–60초 | 106 | 121 | 21.20 | 24.20 | +14.15% |
| 1–60초 전체 | 1,309 | 1,392 | 22.19 | 23.59 | +6.34% |

**단계별 비용.** 30–60초에 시작한 budget 6개 구간의 합을 해당 프레임 수로 나누었다(666→716장, 10ms/tick). 화면당 수신 2.81→1.08ms, 계획 9.82→9.48ms, 출력·최종 ACK 32.00→31.06ms였다. 평균 BG 수는 518.06→518.22, OBJ 수는 19.86→21.80, 변경 map 행은 3.96→3.66이었다. 이 집계는 프레임 시작 시각 기준이어서 표의 공개 시각 기준과 경계에서 한 장 차이가 난다.

**같은 작업량의 상세 화면.** 55–60초 BIN의 유효 요약은 105→120개, 양쪽 누락은 0건이다. MMC925의 56.39초(세대 1326)와 MMC955의 56.34초(세대 1393)는 BG 529, OBJ 14, 변경 map 행 0, 타일 9개였다. 네 묶음의 순서와 길이도 BG 16B, OBJ 128B·64B·64B로 같았다. 묶음별 공급 중 ROM 허가는 0·32·16·16→0·0·0·0회, 첫 E9→마지막 OBJ 준비는 25.746→3.511ms, 입력 완료→ARM 첫 유효 최종 ACK는 49.280→31.567ms였다. 두 상세 화면은 타일 공급 개선을 보여준다. 데모 전체의 개선율에는 다른 작업량의 화면도 포함된다.

**남은 지연.** 56.44초(세대 1396)와 56.68초(세대 1400)는 변경 map 행이 0이지만 OBJ가 각각 51·55개였다. 첫 E9→마지막 OBJ 준비가 60.855·60.075ms, 입력 완료→최종 ACK가 80.085·80.335ms였다. 타일별 허가 표본은 위의 세대 1393에만 있다. 이 두 화면의 ROM 허가 대기와 타일 뱅크 반환 대기는 추가 측정이 필요하다.

**종료.** MMC955는 ROM 393,216B 비교 일치, 전송 실패 0건, 실행 중 ROM 오류 0건이다. 마지막 표시는 59.93초, DISPLAY_NEXT→DISPLAY_STOPPED는 60.32초였다. 시간 만료 시 프레임 하나가 열려 있었고 송신·반환은 16,740·16,739건이었다. 종료 스냅샷에는 receiver 27·sink 2가 남았다. STOP 완료, base 복구, 재로딩 가능 플래그와 사용자가 확인한 메뉴 복귀가 일치했다.
