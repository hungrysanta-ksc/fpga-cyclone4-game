# MMC533 첫 레벨 비교 시험

1. `MMC533-TRIAL.zip`을 풀고 `01-MMC533-SD-ROOT` **안의 내용**을 SD 루트에 복사한다. `sd2snes/firmware.stm`도 새 파일로 덮어쓴다.
2. MMC529 때 쓴 SMB3 일본판 ROM `sd2snes/nes/mmc529.nes`를 같은 폴더에 **`mmc533.nes`**로 복사한다. 원본은 393,232B, CRC32 `5a04eed7`이다.
3. 메뉴에서 **NES MMC3 533.nh1**을 실행한다. MMC529 때와 비슷한 시점에 첫 레벨에 들어가 같은 방향으로 진행한다. 40초 이후 적이 많은 장면의 움직임, 타일 깨짐, 입력 반응과 약 60초 뒤 자동 메뉴 복귀를 확인한다.
4. SD의 `sd2snes` 폴더에서 아래 세 로그를 회수한다. 두 번 실행하면 다음 실행 전에 첫 회차 로그를 따로 보관한다.

- `nes-progress-mmc533.txt`
- `nes-budget-mmc533.txt`
- `nes-game-last-mmc533.txt`

표시를 완료한 시각으로 집계한다. 1초 이상 40초 미만은 39초 동안, 40초 이상 60초 미만은 20초 동안의 표시 횟수를 비교한다. MMC529의 같은 구간은 각각 **461회·11.82fps**, **232회·11.60fps**였다. 이번에 동선이 달라지거나 일찍 멈췄으면 그 시점을 함께 적는다.

이 이미지는 MMC529와 같은 보드의 제한 실기 비교용이다. 532에서 선택한 작은 tile 우선·128B map 소비기를 사용한다. 전체 STA에 남은 교차 클록·reset 여유와 미제약 외부 포트는 보드 검증 기록에서 따로 확인한다.
