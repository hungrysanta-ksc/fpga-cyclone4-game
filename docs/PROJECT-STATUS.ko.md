# 현재 개발 상태
기준일: 2026-10-04

## 현재 기준

- 제품명: **sd2snesHST**, HST = HungrySanTa.
- 첫 제품 버전 **0.9.0은 GBC C44**를 기준으로 계획합니다.
- 검증된 구현 커밋: `35ef4aef14fc6abef6495a980b7f00f257e5174f`.
- C44 로그 OFF 최종 실기 검사는 사용자가 정상으로 확인했습니다.
- 이번 정리는 문서·개발 안내·코어 목록·제품 버전 대응표에 한정합니다. 실행 소스, C44 바이너리 및 기존 배포 ZIP은 바꾸지 않습니다.

## 저장소 역할

현재 `fpga-cyclone4-game`은 구현 소스·실험·회귀·재현 빌드·후속 코어 개발을 관리합니다. 일반 사용자를 위한 [sd2snesHST 저장소](https://github.com/hungrysanta-ksc/sd2snesHST)를 생성했고 다운로드·사용 가이드·호환성·문제 보고를 중심으로 운영합니다.

개발 PR #1·#2는 master에 병합됐습니다. 새 사용자 저장소와 **0.9.0 릴리스 초안**을 만들고 자산 4개를 업로드했습니다. GitHub 서버 SHA256이 로컬 자산과 일치합니다. 일반 사용자를 위한 릴리스 공개와 정식 태그 발행은 아직 하지 않았습니다. C44 실행 파일과 기존 ZIP은 유지했습니다.

## 다음 작업

1. [0.9.0 공개 실행 계획](distribution/0.9.0-PLAN.ko.md)의 남은 소스·고지 검토를 마무리.
2. 사용자 저장소의 준비 중 문구와 릴리스 상태·체크섬을 일치시킨 뒤 0.9.0 공개. 이 저장소의 distribution/ 사본은 최초 계획 초안이며 실제 배포 문서는 사용자 저장소에서 관리.
3. GBC 유지보수와 별개로 NES의 독립 합성·자원·출력 경로 조사.
4. 공통 경계가 검증되면 재사용하고 PCE HuCard 경로 조사.

NES/PCE는 아직 구현·실기 검증이 없으며 편입 버전과 일정을 확정하지 않았습니다. 보드 제약/CDC 검토, 지원 밖 매퍼·주변기기, 구성 요소별 라이선스 고지 범위는 기존 자료의 미결 사항을 유지합니다.
