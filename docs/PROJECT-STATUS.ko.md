# 현재 개발 상태
기준일: 2026-10-04

## 현재 기준

- 제품명: **sd2snesHST**, HST = HungrySanTa.
- 첫 제품 버전 **0.9.0은 GBC C44**를 기준으로 계획합니다.
- 검증된 구현 커밋: `35ef4aef14fc6abef6495a980b7f00f257e5174f`.
- C44 로그 OFF 최종 실기 검사는 사용자가 정상으로 확인했습니다.
- 이번 정리는 문서·개발 안내·코어 목록·제품 버전 대응표에 한정합니다. 실행 소스, C44 바이너리 및 기존 배포 ZIP은 바꾸지 않습니다.

## 저장소 역할

현재 `fpga-cyclone4-game`은 구현 소스·실험·회귀·재현 빌드·후속 코어 개발을 관리합니다. 일반 사용자를 위한 `sd2snesHST` 저장소는 다운로드·사용 가이드·호환성·문제 보고를 중심으로 별도 운영할 계획입니다.

**새 저장소, v0.9.0 태그 및 Release는 아직 만들지 않았습니다.** 개발 PR #2와 기존 C44 준비 자산은 그대로 유지하며, 공개 단계에서 제품명으로 포장하고 대응 소스를 연결합니다.

## 다음 작업

1. [0.9.0 공개 실행 계획](distribution/0.9.0-PLAN.ko.md)에 따라 소스·고지 검토 및 배포 준비.
