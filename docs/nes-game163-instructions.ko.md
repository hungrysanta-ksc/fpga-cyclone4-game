# NES163 — 본체 사운드 초기화·SMB3 시험

162의 첫 레벨 플레이와 메뉴 복귀는 통과했지만 소리는 나지 않았다.163은 SNES 본체의 음소거 해제 절차를 추가한다. 실제 소리가 나오는지는 이번 시험으로 확인한다. 화면 끊김·입력 유지 문제를 개선한 판은 아니다.

1. ZIP의 `01-GAME163-SD-ROOT` **안의 내용**을 SD 루트에 덮어쓴다. 펌웨어와 FPGA 파일을 함께 적용한다.
2. `NES GAME 163.nh1`를 실행한다.0바이트 표식이 정상이고 확장자를 바꾸지 않는다.
3. 제목 →1PLAYER →월드맵 →첫 레벨로 진행한다. **음악과 선택·점프 등의 효과음이 들리는지** 확인한다. 가능하면 게임 소리를 포함한 짧은 영상을 남긴다. 무음이어도 소리를 기다리며 머무르지 말고 첫 레벨을 진행한다.
4. 약60초 후 자동으로 메뉴에 돌아오는지 확인한다. 제목·선택·월드맵 시간도 포함한다.
5. `sd2snes/nes-progress-163.txt`, `sd2snes/nes-game-last-163.txt`와 소리·첫 레벨·메뉴 복귀 결과를 전달한다.

적재 시간은 기존 약3분50초를 참고한다. 초기화 실패 때문에 수분을 추가로 기다리는 설계는 아니다. 전체7분 이상 무반응이면 대기를 끝내고 남은 TXT와 상태를 전달한다. 본체 리셋으로 로그를 저장하는 기능은 아직 없다.

로그의 `spc_init_status_hex=a9`와 `spc_unmute_confirmed=1`은 SNES 프로그램이 DSP 상태값0x20을 읽어 확인했다는 뜻이다. 실제 음악이 들렸다는 뜻은 아니다. E1~E5는 초기화 실패 단계이며 실패해도 화면 진행·정상 종료 경로를 유지한다.0이나 알 수 없는 값은 초기화 미확인이다. `screen_error`는163에서 이 초기화 결과 통로로 사용하므로169(A9)를 게임 실행 오류로 해석하지 않는다. 게임 오류는 `run_error`·`run_rom_error`로 구분한다.

FPGA 로직은162를 그대로 사용하므로 내부 식별6B/E5가 정상이다. 내장 SNES 프로그램과 파일명은163이며 두 파일을 함께 적용해야 한다. 화면은 전체 DMA·강제 소거·hold6 그대로다. 사운드·연속 화면을 확인한 뒤60초 제한과 장시간 입력 품질을 개선한다.

044/GBC 복원 재시험은 반복하지 않는다. 정상 사용으로 돌아갈 때 동봉 `02-RESTORE044-SD-ROOT`를 사용한다.
