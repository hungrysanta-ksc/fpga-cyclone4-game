# NES214 시작 실패 확인판

213의 첫 화면 전 시작 실패는 아직 원인이 확정되지 않았습니다. 이번 판은 실패 직전의 준비 대기 종료 이유와 상태를 남깁니다. **게임 화면·FPGA·캐시 구현은213과 같으며 수정 완료판이나60fps 개선판이 아닙니다.**

1. 전원을 끄고 `01-GAME214-SD-ROOT` 폴더 **안의 내용**을 SD루트에 복사합니다. 펌웨어와 이름이 바뀐 FPGA 파일을 함께 복사하고 `NES GAME 214.nh1`을 실행합니다.
2. 처음 파일을 읽고 비교하는 로딩은 기존과 같습니다. 로딩이 끝난 뒤 준비에 실패하면 약5초 후 중단·복귀를 시도합니다.10분씩 기다릴 필요는 없습니다.
3. 화면이 나오면 숫자1 타일에서A로 첫 레벨에 들어가 기존처럼 오른쪽+B/A반복으로 확인합니다. 이 경우 약60초 후 자동 복귀합니다. 게임이 시작되지 않으면 영상은 필요하지 않습니다.
4. `/sd2snes/nes-progress-214.txt`, `nes-game-last-214.txt`, **`nes-budget-214.txt`** 세 파일을 보내 주세요. 메뉴가 다시 보였는지도 알려 주세요. 이번에는 budget 파일에 시작 실패 원인이 들어갑니다.

로딩이 끝난 뒤90초가 지나도 복귀하지 않으면 전원을 껐다 켜고 남은 로그를 전달해 주세요. 반복 실행이나044복원 시험은 필요하지 않습니다. 기존210 패키지는 그대로 보관하며, ZIP의164복원 폴더 역시 이전 바이트 그대로입니다.

로그는 기존처럼 안전한 종료/복원 뒤에만 SD에 씁니다. 보호 조건 자체가 실패한 경우에는 안전을 위해 결과 파일이 없을 수 있으며, 그 경우 남은 progress가 필요합니다. 이번 판은5초 제한을 늘리거나 자동 재시도·실행 중 SD쓰기를 추가하지 않습니다.
