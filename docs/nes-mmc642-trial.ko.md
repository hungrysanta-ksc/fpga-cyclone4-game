# MMC642 실기 시험

MMC639의 두 중단을 구분하기 위한 진단판입니다. MMC639를 시험한 FXPAK Pro / Mk.III를 사용하세요.

1. ZIP의 `01-MMC642-SD-ROOT` **안의 내용**을 SD 최상위에 복사하세요. 메뉴 복귀에 쓰는 base 이미지와 메뉴 파일이 함께 들어 있습니다.
2. 기존 `sd2snes/nes/mmc639.nes`를 같은 폴더에 `mmc642.nes`로 복사하세요. 사용하던 SMB3(J) ROM의 CRC32는 `5a04eed7`입니다.
3. 메뉴에서 `NES MMC3 642.nh1`을 실행하세요. 평소처럼 첫 레벨을 플레이하고 메뉴 복귀를 확인하면 됩니다. 특별한 입력은 필요 없습니다.
4. 메뉴로 돌아오면 SD의 `sd2snes` 폴더에서 아래 세 로그를 보관하세요. 조기에 복귀하면 **재실행 전에** 세 파일을 한 묶음으로 복사하고, 게임 화면이 보였는지 알려주세요. 정상 완주 로그도 비교에 쓸 수 있습니다.

- `nes-progress-mmc642.txt`
- `nes-game-last-mmc642.txt`
- `nes-budget-mmc642.txt`

성능 비교는 완료된 실행의 5–40초·40–55초를 사용합니다. 패키지에는 게임 ROM과 RESTORE가 없습니다.
