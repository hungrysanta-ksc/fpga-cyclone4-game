# NES180 — 첫 레벨 영상 거부 사유 수집

이 안내는 배포 검증을 통과한 `NES180-SMB3-EPISODE.zip`용이다. **이번 시험판은 화면 정지 수정판이 아니라, 유효한 화면 수집 뒤 첫 거부와 정상 회복의 원인을 남기는 판이다.** 첫 레벨 화면은178처럼 멈출 수 있다. 이 결과로 다음 화면 구현을 결정한다.

1. ZIP의 `01-GAME180-SD-ROOT` 안 내용을 SD 루트에 덮어쓴다. 펌웨어와 FPGA를 함께 적용하고 이전 시험판 파일과 섞지 않는다.
2. 메뉴에서 `NES GAME 180.nh1`을 실행한다. ROM 적재 방식은 그대로이므로 로딩에 수분 걸릴 수 있다.
3. START로 플레이어 선택→월드맵으로 진행한다. **숫자1 타일로 이동한 뒤 A**를 눌러 첫 레벨에 들어간다. 영상이 멈추더라도 소리·조작이 계속되는지 관찰한다.
4. 가능하면 게임 오버 뒤 월드맵으로 돌아와 영상이 다시 움직이는지도 확인한다. 이 장면을 반드시 만들려고 기다리거나 재시험할 필요는 없다.
5. 표시 준비 후 약60초의 자동 메뉴 복귀를 기다린다. 화면이 멈춘 직후 리셋하지 않는다. `sd2snes/nes-progress-180.txt`와 `sd2snes/nes-game-last-180.txt`를 전달하고, 첫 레벨 영상·월드맵 회복·메뉴 복귀 여부를 알려준다. 같은 증상이면 새 영상은 필수가 아니다.

실행 후6분이 지나도 메뉴로 돌아오지 않으면 전원을 끄고 남은 로그를 복사한다. 정상 사용으로 돌아갈 때는 `02-RESTORE164-SD-ROOT`를 사용한다.044 복원 확인은 반복하지 않는다.

ROM·메뉴·164 복구 파일은178 패키지와 동일하다. 실행 중 SD 쓰기나 세이브 SRAM을 영상 버퍼로 사용하는 변경은 없다. 종료 후 저장되는 `LAST16_EPISODE180_V3`는 최근16개 거부/회복 사건이며, 화면 표시 횟수나 FPS가 아니다. 최초 오류 위치와 거부가 이어지는 동안의 오류 변화는 수집하지 않는다.
