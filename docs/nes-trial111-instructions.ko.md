# NES111 실기 시험 — 80KiB 1회

이번 패키지는 사용자가 승인한 제한 기능 시험용입니다. 게임 실행 단계가 아니라, 실제 보드에서 진단 데이터를 적재하고 전체 읽기 비교 후 기본 FPGA와 메뉴로 돌아오는지 확인합니다. 정상 전원에서 한 번만 실행합니다.

## 준비와 복사

1. 전원을 끄고 SD를 PC에 연결합니다. 현재 SD 내용과 저장 데이터를 별도 위치에 백업합니다. 기존 `sd2snes/nes-verify-last-094.txt`가 있으면 PC로 옮겨 이번 결과와 구분합니다.
2. ZIP을 PC의 새 폴더에 풉니다. `01-TRIAL-SD-ROOT` **안의 내용**을 SD 루트에 복사합니다. 같은 이름의 파일은 덮어씁니다. 상위 폴더 이름 자체를 SD에 복사하지 않습니다.
3. `02-RESTORE044-SD-ROOT`는 PC에 보관합니다. 시험 파일과 동시에 복사하면 정상044 펌웨어로 다시 바뀌므로 시험이 실행되지 않습니다.
4. SD 루트의 `NES VERIFY 094 80.nh1`과 `sd2snes/firmware.stm`, `sd2snes/fpga_n86.bi3`, `sd2snes/fpga_base.bi3`, `sd2snes/m3nu.bin`, `sd2snes/nes/fine_x.nes`를 확인합니다. 표식 `.nh1`은 **0바이트가 정상**이며 확장자를 바꾸지 않습니다.

111은 전달 패키지 번호입니다. 실행 펌웨어는 검증한 `CF86-CSS108`이고, 선택 파일과 보고서 이름은 기존 계약인 **094**를 유지합니다. 이름이 111이 아니어도 잘못된 파일이 아닙니다. 일반 게임이나 다른 진단 표식은 이번에 실행하지 않습니다.

## 한 번 실행

1. SD를 실기에 넣고 정상 메뉴가 뜨는지 확인합니다. 메뉴가 나오지 않으면 시험 표식을 실행한 것으로 보지 말고 마지막 화면을 기록한 뒤 전원을 끄고 복원합니다.
2. 메뉴에서 `NES VERIFY 094 80.nh1`을 한 번 선택하고 시간을 잽니다. 가능하면 선택 직전부터 영상을 촬영합니다. 중간 화면이 멈추거나 검게 보이는 것만으로 성공·실패를 단정하지 않습니다. 이 후보에는 새 진행 화면을 추가하지 않았습니다.
3. 메뉴가 돌아오면 재실행하지 말고 돌아오는 데 걸린 시간을 기록합니다. 최대 **10분(600초)** 안에 돌아오지 않으면 마지막 화면과 경과시간을 기록하고 전원을 끕니다. 이는 관측 한도이며 동작 시간이나 SD 쓰기 완료를 보장하는 수치가 아닙니다.
4. 정상 종료 후에도 전원을 끈 다음 SD를 꺼냅니다. 실행 중 SD 분리, 의도적인 전원·클록 고장 주입은 하지 않습니다.

## 결과 보존과 정상044 복원

1. PC에서 `sd2snes/nes-verify-last-094.txt`를 별도 위치로 복사합니다. **파일 없음·0바이트도 결과**이므로 다시 시험하지 않고 그대로 알려주세요.
2. 전원이 꺼진 실기의 SD에 `02-RESTORE044-SD-ROOT` 안의 `sd2snes` 폴더를 복사하고 3개 파일을 덮어씁니다. `firmware.stm`, `fpga_base.bi3`, `m3nu.bin`이 정상 복원 대상입니다. 이번에 추가한 진단 표식은 SD에서 치워 혼동을 피합니다. 기존 개인 설정·저장 데이터가 필요하면 독립 백업본에서 복구합니다.
3. 정상 메뉴와 GBC 게임이 동작하는지 확인합니다. 복원 후에도 이상이 있으면 추가 진단을 반복하지 않고 결과를 전달합니다.

보내주실 내용:

- `nes-verify-last-094.txt` 원본 또는 없음/0바이트 여부
- 표식 선택 전 메뉴 표시 여부와 선택 후 실제 메뉴 복귀 여부
- 선택부터 메뉴 복귀 또는 종료까지의 시간, 마지막 화면/영상
- 정상044 복원 후 메뉴·GBC 동작 여부

로그는 직접 해석하지 않아도 됩니다. `PREPARED_RESET_HELD`는 메뉴 복귀를 준비한 기록이며 실제 화면 복귀 증명은 아닙니다. TXT와 화면, 복원 결과를 따로 판정합니다.

## 시험 범위와 파일 구분

시험 ARM108은 183,220바이트, SHA-256 `394c1c442b6d767b5d41f891151eed12e82954b624a0b53a346dad8dc948692c`입니다. 복원044는 169,056바이트, SHA-256 `1c3b40a3459d24114cb4d91ee9d861d1a08025a670ef25317ef489092203693b`입니다. 전체 파일의 크기와 해시는 ZIP의 `manifest.json`에 있습니다.

전기 조건 E1/E2와 8µs 차단 상한은 미확인 상태입니다. 이번 동의는 정상 전원·80KiB·1회 기능 관측이며 전기적 보증이나 전체 NES 배포 승인이 아닙니다. 진단 RAM 데이터 손상, SD 기록 불완전, 멈춤 시 수동 복원이 필요할 수 있다는 조건을 유지합니다. 96KiB·SMB3·NES RUN·고장 주입·반복 시험은 포함하지 않습니다.
