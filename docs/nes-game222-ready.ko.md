# NES222 시작 순서 보강 시험

221의실행실패를조사하기위한시험판이다.리셋전후에화면용통신부준비상태를확인하고,큰프레임작업메모리는SNES준비완료뒤에만확보한다.**실기원인해결이나60fps달성은아직확인하지않았다.** 게임중성능구현은221과같다.

1. 전원을끄고ZIP의`01-GAME222-SD-ROOT` 안 내용을 SD 루트에덮어쓴다.이번`firmware.stm`과`fpga_n222.bi3` 별칭을함께적용한다. FPGA내용은220/221과동일하다.
2. `NES GAME 222.nh1`을실행한다.0바이트파일이정상이다.기존ROM적재·검증시간은그대로다.
3. 게임화면이나오면숫자1타일로이동해A로첫레벨진입,오른쪽+B유지/A반복으로스크롤을확인한다.기존처럼실제runtime시작후약60초에메뉴로돌아온다.
4. `nes-progress-222.txt`, `nes-game-last-222.txt`, `nes-budget-222.txt` 세파일과실행성공여부를보낸다.성공했다면스크롤체감·소리·조작·메뉴복귀도확인한다.실행실패라면다시반복할필요없고영상도필수아니다.

5초READY제한은늘리지않았다.화면이나오기전에종료되어도기존메뉴복귀와로그가정상인지확인하면된다.동일221/044시험은불필요하다.이상시전원을끄고포함된`02-RESTORE164-SD-ROOT`로복원할수있지만매번복원시험을요청하지않는다.

저장SRAM/GBC164/사용자ROM보존.무제한플레이와리셋시로그는이번범위가아니다. 자세한판정은[시작계약](nes-startup222-contract.ko.md)을참고한다.
