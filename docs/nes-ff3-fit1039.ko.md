# FF3 팔레트·매퍼 상태 복원과 배치

FF3의 복원 대기 레지스터를 없애고 전체 보드를 Quartus Lite 25.1로 합성했다. EP4CE15F17C8에서 가장 작은 후보도 1,025 LAB를 요구한다. 칩에는 963 LAB가 있어 FIT를 통과하지 못했다.

| 전체 보드 | 조합 논리 | 전용 레지스터 | LE | 필요 LAB | 부족 LAB |
|---|---:|---:|---:|---:|---:|
| 1038 | 15,286 | 9,060 | 16,371 | 1,040 | 77 |
| 1039 워드 직접 복원 | 15,280 | 8,693 | 16,387 | 1,035 | 72 |
| 1039 팔레트 바이트 포트 | 15,090 | 8,695 | 16,183 | 1,026 | 63 |
| 1039 팔레트·매퍼 바이트 조회 | 15,090 | 8,695 | 16,172 | 1,025 | 62 |

### 바뀐 경로

일시정지·배출 확인과 저장 파일의 워드 번호를 유지한다. 팔레트는 8–11번 워드에 들어 있는 원래 순서대로 32개 셀을 방문한다. 같은 워드의 다음 셀은 주소가 4만큼 증가한다. 기존 RAM 워드 시프트 레지스터를 사용하므로 별도의 192비트 복원 사본이 필요 없다. 평상시에는 PPU의 주소 미러링, 팔레트 쓰기·복사 및 병렬 캡처 경로를 사용한다.

매퍼는 33–35번 워드를 수락할 때 해당 실행 레지스터만 기록한다. 저장할 때는 정지한 레지스터를 바이트별로 읽어 원래 순서의 워드를 만든다. 이전 코드는 두 CHR 뱅크의 하위 비트를 MAP3에 저장한 뒤 MAP1에서 복원했다. 복원 위치를 저장 위치인 MAP3의 비트 48·49에 맞췄다. 이 변경은 FF3용 보드 생성기에만 적용한다.

### FF3 복원과 STOP 시험

첨부한 FF3 ROM을 실행한 혼합언어 RTL에서 팔레트의 32개 원시 셀과 매퍼의 세 워드를 저장 직전 값과 파일 배치로 대조했다. 2,658워드와 배터리 RAM 8,192바이트를 복원했고, 연속 실행 대조군과 재개 후 CPU 명령 경계 64개 및 두 화면의 PPU 픽셀 122,880개가 일치했다. 이 시험 장면의 색 수는 3개다.

부분 복원에서는 팔레트 셋째 워드의 8바이트 중 3바이트를 적용한 시점, 팔레트 두 워드 적용 뒤, 매퍼 첫 워드 적용 뒤, 매퍼 세 워드 모두 적용 뒤에 각각 코어 STOP 리셋을 넣었다. 테스트가 실제로 건드린 셀·레지스터의 값을 확인한 후 중단했다. 네 경우 모두 다음 콜드 부팅에서 원래 팔레트·매퍼 기본값, 첫 64개 명령 경계와 남은 저장 요청이 없는 상태를 확인했다.

일반 PPU 동작은 원본과 2,048개 렌더링 전환을 대조했다. 미러링, 같은 클록에서의 CPU 쓰기와 팔레트 복사, 클록 인에이블 정지까지 내부 32개 셀 및 표시 출력을 비교했다. 첫 워드 직접 복원 후보의 부분 복원 시험에서는 표시용 팔레트의 미러 주소를 내부 셀 주소로 오인해 실패한 기록이 있다. 최종 시험은 원시 셀을 직접 관측하고 표시 출력은 별도 원본 대조 시험에서 확인한다.

SPI의 응답 CRC·워드 에코·재시도·STOP, 부팅 전 배터리 접근, 호스트에서의 저장 파일 손상 복구 및 슬롯·게임 격리도 통과했다. 최종 로그는 `probes/nes-ff3-1039/shared-checkpoint.log`, `palette-sim.log`, `state-spi-sim.log`, `savefile-host.log`에 있다. 보드 생성기를 다시 실행해 RTL·초기값·제약 등 90개 파일이 합성 입력과 바이트 단위로 일치하는지 확인했다.

### 배치와 실기 진입

최종 후보에서 조합 논리 여유는 318개이고 레지스터만 사용하는 LE는 1,082개다. LE 총량은 764개 초과하고 M9K 56개를 모두 사용한다. 전체 STA와 프로그래밍 이미지는 배치 성공 뒤에 생성할 수 있다. 메뉴 연결, 실물 SD에서 게임을 재선택한 뒤의 상태 복원 및 ZIP 배포는 대기 중이다.

워드 직접 복원만으로는 전용 레지스터가 367개 줄어도 LE가 16개 늘었다. 복원 데이터 선택 회로와 레지스터 배치를 함께 측정해야 한다. 전체 MAP 보고서에서 남은 상태 레지스터 하위 모듈 13개의 전용 레지스터 수는 547개다. 다음 면적 비교에서는 이 사본의 개별 삭제 외에 코어 전체의 저장 워드 선택·반환 회로를 함께 대체할 때의 LUT와 LAB 순감소를 확인할 수 있다.

원시 보드 보고서는 작업 루트의 `probes/nes-ff3-1039/lite-direct/`, `lite-port/`, `lite-shared/`에 있다. 1038 비교 기준은 `probes/nes-ff3-1038/lite-mixer/`다. 생성 진입점은 `tools/prepare_ff3_display1037.py`, 코어 시험은 `tools/check_ff3_checkpoint_rtl.ps1`이다.
