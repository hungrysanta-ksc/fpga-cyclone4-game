# NES729 OBJ 소유권·ordinary 공급과 span 비용 공유

## 목표

727의384B 연속 map DMA·BG ROM 마감을 유지하고953의 마지막 OBJ 공급과 이후 ordinary·SEAL 비용을 줄인다. Flash 한도·STOP·독립 검사·최종 ACK·메뉴 경계,951/911/952/957과 입력7블록을 보호하며 두 위상에서 밀집 표시 간격·마지막 ACK를 함께 비교한다. 728 미채택 후보를 시간 기준으로 대체하지 않는다.

## 작업내용

727의 실제 ARM/65816·공유SPI/IRQ·ROM 달력 재생을 분석했다. 마지막 OBJ의 데이터 응답→descriptor 확인→SPI 발행→65816 수락→소비 ACK를 순서대로 분해했다. 이후 ACK→SEAL 수락은 SPI opcode별 실제 점유 시간과 잔여 ARM/callback/대기로 나눴다. 서로 겹치는 packet별 queue/소비 시간을 합산하지 않는다.

새 후보는 이미 발행한 bulk의 소유권이 남아 있고,미발행 E9가 없으며,ordinary 호출이고,보수적으로 기억한 미완료 queue가2개 이하일 때 기존 credit로 ordinary를 추가한다. 최소 한 슬롯을 남긴다. 이 경로에서 같은 descriptor를 다시 E8로 조회하지 않는다. E1의 실제 credit·STOP 검사,새 descriptor의 CRC·generation·token 검사,마지막 FINAL의 실제 완료 검사는 유지한다. bulk 소유권이나 표시 ACK를 조기에 확정하지 않는다. map/BG 생산과719의 DMA 대기 조건은 바꾸지 않는다.

추가 분기 공간은 span/OAM의 중복 비용 계산을 공유해 확보했다. 같은 원본을 두 번 구현하던 split/legacy 비용 계산을 하나로 합쳤다. 계산값의 하위bit는 엄격한 전송량 감소일 때만 split을 선택하고,나머지는 기존 OAM 비용이다. 짧거나 같은 word로 반복되는 OAM tail은4B-tail 후보 비용을 계산해도 항상 기각되므로 그 계산만 생략한다.32B high attributes는64B 반복 구간을 포함할 수 없어 동일한 `data_cost`로 계산한다. 압축 규칙·바이트·packet 경계는 유지한다.

### 후반에 옮겨진 입력 비용

마지막 OBJ ACK→SEAL 수락은5.422/5.194→5.500/5.504ms로 늘었다. 이 안의 E1은2.642→2.529ms로0.114ms 줄었지만,다음 입력 D1/D2/D0가0.457/0.448→0.904/0.885ms로 늘었다. E0도0.757/0.668→0.763/0.763ms다. 잔여 ARM/callback/대기는1.457/1.327→1.195/1.218ms로 줄었으나 이를 전체 이득으로 합산할 수 없다. 줄어든 E1은 패딩 패킷이 마지막 OBJ ACK보다 먼저 발행된 효과이며,전체 동일 작업의 필수 전송을 없앤 것이 아니다.

마지막 데이터 응답→descriptor 확인도1.885/1.965→1.977/2.003ms로 짧아지지 않았다. **기억한 credit가 남아 있다는 것은 저장 공간이 있다는 뜻이지,그 ordinary를 먼저 소비해도 후속 bulk가 빨라진다는 뜻은 아니다.** 다음 입력 서비스를 삭제해 겉보기 후반 시간만 줄이는 방법도7블록·캡처 보호 비용을 감추므로 채택하지 않는다.

## 후속작업

1. 선택707D·기존 ARM/65816과727을 유지한다. 729 전체 및 계산 절감 부분을 검증 없이 합치지 않는다. 같은 cached-credit ordinary 우회·E0 대기·poll 수·고정 지연 변형은 반복하지 않는다.
2. 다음 경계는953의 첫 OBJ64B 실제 소비·bank 반환과 마지막 OBJ256B 생산 사이 약9.1–9.2ms 공백이다. 이미 수락된 map의384B 연속 DMA를 끊지 않는 공급·소비 소유권 변경의 가능 여부와 삭제 예산부터 확인한다. 캐시 적중을 추가 ROM 최적화 성과로 계산하지 않는다.
3. ordinary/SEAL은 패킷마다 ARM 준비·SPI·독립 검사·65816 소비 비용과 다음 입력을 함께 과금한다. 1100B 패딩은 이미545/548의 고정source DMA·64B STOP 검사 경로이므로 ‘DMA로 교체’하는 기존 작업을 다시 제안하지 않는다. 구조를 바꿀 때는 이 완료/검사 경계에서 실제로 삭제할 작업과26B ROM·0B Flash 여유를 먼저 제시한다.
4. 두 위상 전체952–957·951–955·개별 간격·마지막 ACK와 기존908 개선까지 함께 판정한다. 새 설치본은 없다. 다음 전달은 고유 파일명60초/장시간판·RESTORE 제외·5–40초/40–55초 집계를 유지한다.
