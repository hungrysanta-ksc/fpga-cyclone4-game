# NES160 — 첫 레벨 진입 전환 시험

159에서 월드맵 진입·이동은 성공했지만, A로 첫 레벨에 들어갈 때 그래픽 읽기 오류로 종료됐다.160은 화면 출력 재개 시 남아 있는 하위 주소 래치를 반영해 필요한 그래픽을 미리 읽는다. **재현 시험은 통과했으며 실제 첫 레벨 플레이는 이번 실기로 확인한다.** 소리는 계속 진단용으로 차단돼 있다.

1. ZIP의 `01-GAME160-SD-ROOT` **안의 내용**을 SD 루트에 덮어쓴다. MCU·FPGA·ROM을 같은 세트로 적용한다.
2. **`NES GAME 160.nh1`**를 실행한다.0바이트 표식이 정상이며 확장자는 변경하지 않는다.
3. 첫 Start →1PLAYER에서 Start 한 번 후 떼기 →월드맵에서 첫 레벨로 이동 → **A로 레벨 진입**을 시도한다. 시간을 충분히 남기도록 월드맵에서 오래 기다리지 않는다.
4. 레벨 내부가 나오면 방향키·A/B로 이동·점프를 확인하고 짧은 영상을 찍는다. 메뉴 복귀 후 `sd2snes/nes-progress-160.txt`와 `sd2snes/nes-game-last-160.txt`를 전달한다. 같은 오류라면 영상은 생략해도 된다.

적재 방식은 이전과 같고 약3분50초는 기존 실측 참고치이며160 실측은 아니다. 기존 실행 상한 약60초와 오류 시 조기 종료를 유지했다. 전체7분 이상 무반응이면 기다림을 끝내고 남은 TXT와 상태를 전달한다. 159 종료는60초 제한이 아닌 PPU오류였으므로 시간만 늘린 시험판이 아니다.

044/GBC 복원 시험은 반복하지 않는다. 정상 사용으로 돌아갈 때 동봉 `02-RESTORE044-SD-ROOT`를 사용한다. 버튼·오류 직전16클록 기록은 유지된다. 정상 레벨 플레이·속도·오디오·저장은 아직 완료되지 않았다.
