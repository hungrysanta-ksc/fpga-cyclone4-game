# MMC1028 커비 무입력 60초 실기 시험

1. ZIP 안 `MMC1028-KIRBY-60SEC-SD-ROOT` 폴더의 내용을 SD 루트에 복사한다. MMC1024·1025와 같은 일본판 커비 ROM을 `sd2snes/nes/mmc1028.nes`로 둔다.
2. `NES MMC3 1028.nh1`을 실행한다. 로딩 뒤 입력 없이 60초를 기다리고 메뉴 복귀를 확인한다. 지난 실기 기록에서 게임 로딩은 약 7분 25초였다.
3. SD의 `sd2snes`에서 아래 네 파일을 PC에 회차별로 복사한다. 같은 전원 시작 조건으로 두 번 실행하고, 각 회차 파일을 복사한 뒤 다음 실행을 시작한다.

- `nes-budget-mmc1028.txt`
- `nes-progress-mmc1028.txt`
- `nes-game-last-mmc1028.txt`
- `nes-frame-mmc1028.bin`

실기 성능 기준은 MMC1024다. MMC1028은 MMC1025와 같은 횟수와 형식으로 계측하므로 1–30초·30–60초의 실제 표시 FPS와 같은 작업량의 마지막 타일 공개·SEAL·화면 공개·최종 ACK를 MMC1025와 직접 비교한다. 상세 ROM 요청·허가 분리는 MMC1027 자료를 이용한다. 이번 후보가 앞당기는 시각은 E9에 들어 있는 OBJ 행을 기존 ROM 허가에서 읽을 수 있는 때다. 캐시 내용과 앞선 뱅크 인계 시각에 따라 실제 이득이 달라진다.
