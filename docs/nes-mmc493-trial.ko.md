# MMC493 — 부팅 분리·복구 확인본

492는 게임 ROM 적재/검증을 마쳤지만 SNES 표시 클라이언트 준비를5초 동안 확인하지 못해 수신·계획 시작 전에 복귀했다. STOP/base/menu는 정상이다. **원인은 아직 확정하지 못했다.** 이번493은 실기에서 정상 동작한489의 FPGA·SNES 프로그램을 byte 그대로 사용하고,491 ARM 조회 변경만 유지해 부팅 경계를 분리한다. 새 SNES word DMA/MVN은 보류했다. 준비 조건·CRC·STOP·최종ACK·VBlank·메뉴 경로를 우회하지 않는다.493 실기 성공/FPS는 아직 없다.

## 설치

1. **전원을 끈 뒤** 기존 SD·세이브를 보존하고 `01-MMC493-SD-ROOT` **안의 내용물 전체**를 SD 루트에 복사한다. firmware와`fpga_mmc493.bi3`를 함께 갱신한다. FPGA 파일명은493이지만 내용은 정상489와 byte/hash가 같다.
2. 이전 원본 `mmc489.nes` 또는 `mmc492.nes`를 **`sd2snes/nes/mmc493.nes`**로 복사한다. 바이트는 바꾸지 않는다.393232B/CRC32 `5a04eed7`,SHA256 `dbb1cb5e18b091ca9101b1c2f5a5d6bdbeaa4a30ae1a504251310f6765cabb49`. 상용 ROM은 포함하지 않았다.
3. **NES MMC3 493.nh1**을 선택한다. 이번에는 우선 첫 화면이 나타나는지와 약60초 후 메뉴 복귀를 확인한다. 첫 화면이 나오면 기존처럼 조작해도 된다. 별도 성능 반복 시험을 먼저 할 필요는 없다.

## 이번 비교의 의미

493이 정상이어도492의 단일 실패 원인을 즉시 확정하지 않는다. ARM/FPGA 조합·부팅 초기 조건을 단계적으로 좁히는 시험이다.493에는492에서 새로 합성한 표시 ROM·word 복원을 사용하지 않으므로 이전 모델7.25% 개선을493 성과로 적용하지 않는다. 실제 전체 비용/FPS는 부팅을 회복한 뒤 판정한다.

ARM은491과781개 linked함수·주소·크기·명령이 같고 marker/ROM/로그 이름만493이다. 일반/SEAL2020packet·71frame byte 일치를 확인했다. 기존489 FPGA의15272LE/51M9K·관련setup/hold+0.183/+0.168ns를 그대로 사용한다. ARM Flash148B·추가global RAM0B,전체 reset/CDC/IO/full stack·IRQ 승인은 미완료다.
