# SDINFO073 TXT 저장 재시험

072에서 `TXT SAVE FAILED / Save code: 4`와 TXT 미생성이 관측됐다. 진단 중 SD 쓰기는 별도 허용 구간이 필요한데072 수집기가 이를 열지 않았다.073은 **보고서 저장·재읽기 동안만 허용하고 모든 종료 경로에서 회수**한다. 동일 보호를 유지한 실제 FatFS/SD 가드의 FAT16·FAT32 모형에서072 실패와073 저장·전체 재읽기를 확인했다.073 실물 재시험 결과는 아직 없다.

## 원본 백업을 유지하고 펌웨어만 교체

이미 만든 **교체 전 원본 firmware의 독립 백업과 `/sd2snes/firmware.before-sdinfo072.stm` 사본은 그대로 유지**한다. 현재 SDINFO072/073 펌웨어를 원본 백업 위에 덮어쓰지 않는다. 원본 백업을 만들지 않았다면 보관 중인 원본을 먼저 확보하고 전체 SD·게임/GBC·세이브도 독립 백업한다. 원본 파일을 모르겠으면 임의의 다른 펌웨어로 복원하지 않는다.

전원을 끄고 SD를 분리한 뒤 `FXPAK-SDINFO073-SD.zip`의 **`sd2snes/firmware.stm`만** 같은 위치에 복사한다. 크기 **133184바이트**, SHA256 **cd7eea7ae61cca3be60a8c5f876a09dbd29e0c6669ccba53462c035b654de5e7**이다. 기본 FPGA·메뉴·게임·세이브·NES 표식은 교체하지 않는다. 별도 `FXPAK-SDINFO073-SOURCE.zip`에 대응 소스/고지를 제공한다.

## 실행·보고서 회수

실기에 SD를 넣고 켠다. 버전이 **`SDINFO073-BASE069`**인지 확인한다. 정상 완료는 `TXT SAVED + READBACK OK`, `/HW004nnn.TXT`, `Save code: 0`이며, 화면에서 멈춘다. 메뉴나 LINK SCREEN 순환은 이 수집기의 동작이 아니다.

전원을 끈 뒤 루트의 새 **`HW004000.TXT`–`HW004999.TXT` 중 이번 파일**을 복사해 전달한다. 과거HW002/HW003과 구분한다. 실패하면 새 화면의 **Save code / Op / FAT result / Bytes / at**가 보이도록 관측 내용을 전달한다. 표시된 파일명만으로 파일이 저장됐다고 판단하지 않는다. 부분 TXT는 완성한 보고서가 아니다.

Op는1=열기,2=쓰기,3=동기화,4=닫기,5=재읽기 열기,6=재읽기,7=재읽기 닫기,8=크기이다. FAT result는 실제 FatFS 반환값이고 Bytes는 반환/요청 바이트, at는 파일 위치다. 첫 오류 정보를 보존한다. Save code는 기존과 같이1형식/2열기/3이름 소진/4쓰기/5동기화/6닫기/7재읽기/8공유오류 또는 예산이다. 공유오류는 화면 갱신이나 추가SD 접근 없이 RESET/USB를 유지한 채 멈출 수 있다.

수집 예산은6000tick(100Hz60초)/100만poll, 저장 구간은1000tick(10초)/10000poll이다. 기존 초기 file_init/mini 준비는 이 예산 이전이며 전체 부팅시간 보장이 아니다.2분이 지나도 완료 화면이 없으면 전원을 끄고 관측을 전달한다. 멈춘 상태에서 메뉴·게임을 시도하지 않는다.

## 원본 복원

전원을 끈 상태에서 **독립 백업의 원본 firmware**로 `/sd2snes/firmware.stm`을 복원하고 크기·SHA256/전체 바이트를 대조한다. 원래 메뉴와 GBC가 정상인지 관측한다. 실기가 PC에 직접 연결될 필요는 없다.

수집한 입력은 읽기 전용이며, 출력 TXT만 새 파일로 만든다. 성공은 메뉴 호환성·원본 독립 백업·복원·NES CF68 실기 성공을 승인하지 않는다. 원본 firmware 사본 이름은072와 같고 보고서/실행 식별자는073으로 구분한다.071 NES 쌍의 설치 보류 상태와 외부 전기 조건 검토는 그대로다.
