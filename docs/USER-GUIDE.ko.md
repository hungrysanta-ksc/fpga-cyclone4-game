# FXPAK Pro GBC 사용 가이드
**버전 C44 · 2026-10-04**

## 1. 준비물

- FXPAK Pro / Mk.III: STM32 MCU와 Cyclone IV EP4CE15F17C8 보드.
- 정상 동작하는 공식 sd2snes 1.11.2 계열 SD 설치.
- 소유한 GB/GBC 게임 파일. 게임·BIOS·세이브는 배포물에 포함하지 않습니다.

이 패키지는 새 GBC 코어를 추가하는 **업데이트**입니다. 빈 SD에 이것만 복사해서 전체 펌웨어 설치를 완성할 수는 없습니다. 구형 SD2SNES/Mk.II 및 ludufre 포크와의 혼합 설치는 검증하지 않았습니다.

## 2. 처음 설치하기

1. 본체 전원을 끄고 SD를 PC에 연결합니다.
2. 기존 `sd2snes` 폴더를 백업합니다. 특히 `saves`, `gbcstates`, 기존 펌웨어와 설정을 보관합니다.
3. 배포 ZIP의 `sd2snes` 폴더 안 파일을 SD의 같은 폴더에 복사합니다.
4. 아래 RTC 시차 설정을 확인합니다. 이미 설정 파일이 있으면 자신의 값을 유지합니다.
5. SD를 기기에 넣고 실행합니다.

| SD 경로 | 역할 |
| --- | --- |
| sd2snes/firmware.stm | 코어 로더·저장·메뉴·RTC 처리 |
| sd2snes/fpga_egbc.bi3 | GBC FPGA 코어 |
| sd2snes/gbc_snes.bin | 자체 제작 SNES 화면·메뉴 프로그램 |
| sd2snes/gbc-utc-offset.txt | 기기 시각의 UTC 시차. 동봉 값은 한국용 +540 |

**기존 폴더를 통째로 삭제하거나 교체하지 말고 파일을 합쳐 복사합니다.** SGB 파일과 다른 SNES 코어·메뉴는 기존 설치를 사용합니다.

PowerShell에서 동봉 검사 도구로 실행 파일 3개의 해시를 확인할 수 있습니다. E:는 실제 SD 드라이브로 바꿉니다. 시차 파일은 사용자 설정이므로 해시를 강제하지 않습니다.

```powershell
./Verify-SD.ps1 -SdRoot E:/
```

C43에서 업데이트하는 경우에는 `firmware.stm`만 달라졌습니다. 현재 시차 설정과 나머지 파일은 그대로 유지해도 됩니다.

## 3. 게임 실행

원본을 보존하고 게임의 **복사본** 확장자를 `.egbc`로 바꿉니다.

```text
Example.gbc → Example.egbc
```

Windows에서 파일 확장자 표시를 켜고 이름이 `Example.egbc.gbc`처럼 되지 않았는지 확인합니다. ROM 내용을 변환하거나 별도로 패치할 필요는 없습니다. GB 게임도 `.egbc`로 실행할 수 있습니다.

| 확장자 | 실행 경로 |
| --- | --- |
| .egbc | 새 GB/GBC 코어 |
| .gb / .gbc | 기존 SGB 코어 |

`.egbc` 실행에는 별도 SGB BIOS가 필요하지 않습니다. 기존 SGB 경로에는 기존 SGB 코어·BIOS가 필요합니다. **.gbc라는 확장자만으로 기존 SGB 코어가 GBC 전용 게임을 지원하는 것은 아닙니다.**

이 배포물에는 `fpga_sgb.*`, `sgb2_boot.bin`, `sgb2_snes.bin`이 없습니다. 기존 SD에 있는 파일은 삭제하지 않습니다.

## 4. 조작

| 입력 | 기능 |
| --- | --- |
| L + R + Start | 코어 메뉴 열기 |
| 방향키 위/아래 | 메뉴 항목 이동 |
| A | 선택·실행·설정 변경 |
| B 또는 RESUME GAME | 게임으로 복귀 |
| R을 누르고 있기 | 약 3배 빨리감기. 놓으면 정상 속도 |

빨리감기는 화면 갱신을 줄여 속도를 높이므로 화면이 평소보다 끊겨 보일 수 있습니다. 실제 배속은 게임에 따라 달라집니다.

## 5. 메뉴와 저장

| 메뉴 | 동작 |
| --- | --- |
| RESUME GAME | 현재 게임으로 복귀 |
| WRITE SRAM | 현재 배터리 저장 RAM을 SD에 기록 |
| AUTO WRITE SRAM | 배터리 RAM 자동 기록 켜기/끄기 |
| SOUND | 소리 켜기/끄기 |
| STATE SLOT | 강제 저장 슬롯 1~4 선택 |
| SAVE STATE | 선택한 슬롯에 현재 실행 상태 저장 |
| LOAD STATE | 선택한 슬롯의 실행 상태로 복원 |
| RESET GAME | 같은 게임을 처음부터 다시 실행 |

### 게임 저장을 SD에 확실히 남기기

1. 게임 안의 저장 메뉴로 저장합니다.
2. 코어 메뉴를 열어 **WRITE SRAM**을 실행합니다.
3. 상태 영역에 **SAVED**가 표시되는지 확인합니다.
4. 게임으로 복귀하거나 본체 리셋으로 파일 메뉴에 돌아갑니다.

WRITE SRAM은 게임의 저장 RAM을 SD에 기록합니다. 게임 자체에 저장 기능이 없다면 현재 장면을 저장하는 기능은 아닙니다. 자동 기록을 끈 경우에도 직접 WRITE SRAM을 사용할 수 있습니다. 자동 기록·소리 설정은 다음 실행에도 보존됩니다.

### 현재 장면을 저장하고 되돌아오기

1. 빈 슬롯 또는 덮어써도 되는 슬롯을 **STATE SLOT**에서 선택합니다.
2. **SAVE STATE**를 실행하고 SAVED를 확인합니다.
3. 게임을 진행한 뒤 같은 슬롯에서 **LOAD STATE**를 실행합니다.
4. LOADED를 확인하고 B로 복귀합니다.

강제 복원은 게임 RAM과 실행 상태를 과거로 되돌립니다. 이후 WRITE SRAM이나 자동 기록으로 배터리 저장도 그 상태에 맞춰 기록될 수 있습니다. 중요한 진행 상황은 SD 세이브를 별도로 백업합니다.

강제 저장은 코어 전용 형식이며 일반 PC 에뮬레이터 상태 파일과 호환되지 않습니다. ROM 버전·패치가 다르면 사용하지 않습니다. 이중 파일은 슬롯마다 이전 유효 데이터를 보존하기 위한 것이므로 임의로 하나씩 삭제하거나 이름을 바꾸지 않습니다.

### 저장 파일 위치

| 경로 | 내용 |
| --- | --- |
| sd2snes/saves/게임 이름.srm | 게임의 배터리 SRAM 및 해당 게임의 RTC 데이터 |
| sd2snes/gbcstates/ | 4슬롯 실행 상태. ROM CRC·크기·슬롯으로 식별하는 .gst 파일 |
| sd2snes/gbc-settings0.dat, gbc-settings1.dat | 자동 기록·소리 설정 |

게임 파일 이름을 바꾸면 배터리 저장 파일을 찾는 이름도 달라질 수 있습니다. 다른 게임이나 지역판에 같은 세이브를 덮어쓰지 않습니다. PC 에뮬레이터의 raw SRAM 및 지원 RTC footer는 읽을 수 있지만, 확장자를 바꾸는 것만으로 모든 에뮬레이터 형식이 변환되는 것은 아닙니다.

## 6. RTC — 포켓몬 등의 실제 시각

먼저 FXPAK의 날짜·시각이 맞는지 확인합니다. RTC 게임은 전원 종료 중 경과 시간도 기기 시계를 기준으로 보정합니다.

`sd2snes/gbc-utc-offset.txt`에는 **기기에 설정한 시각과 UTC의 차이를 분 단위**로 적습니다.

| 기기 시각 설정 | 파일 내용 |
| --- | --- |
| 한국/일본 현지 시각 | +540 |
| UTC | 0 |

다른 지역은 해당 시차를 사용합니다. 파일이 없으면 0으로 처리합니다. 기존 파일 값이 정확하다면 동봉 파일로 덮어쓰지 않습니다.

RTC는 메뉴를 열어도 흐르고, 빨리감기로 빨라지지 않습니다. LOAD STATE도 현재 배터리 시계를 되감지 않습니다. 다만 게임이 RAM에 보관한 시각 보정값은 상태 파일과 함께 복원될 수 있습니다. 초 미만 위상은 전원 종료 파일에 보존하지 않습니다.

RTC 게임은 SRAM 뒤에 48바이트 메타데이터를 기록합니다. 예를 들어 한국판 포켓몬 금은 총 **32,816바이트**입니다. 이를 32KiB로 잘라내지 않습니다.

## 7. 상태 메시지

메뉴 하단 상태 영역은 선택 가능한 메뉴가 아닙니다.

| 메시지 | 의미·대응 |
| --- | --- |
| READY | 명령 대기 |
| WORKING / PLEASE WAIT | 작업 중. 완료될 때까지 기다립니다 |
| SAVED / LOADED | 해당 저장·복원 작업 성공 |
| NO SAVE RAM | 해당 게임에 배터리 SRAM이 없다는 안내. 그 자체로 실행 오류는 아닙니다 |
| SETTINGS ERROR | 설정 파일 읽기/기록 문제. SD 상태와 설정 파일 백업을 확인합니다 |
| FAILED / RESET IF NEEDED | 작업 실패. 성공으로 간주하지 않습니다. 복귀가 차단되거나 비정상이면 리셋이 필요할 수 있습니다 |

정상 RESET GAME은 재시작 전에 SRAM 기록을 시도하며, 기록 실패 시 재시작을 막습니다. 작업 중 전원을 끄거나 SD를 빼지 않습니다.

## 8. 로그와 문제 보고

C44에서는 다음 로그를 새로 만들지 않습니다.

- `sd2snes/gbcload/loadNNN.txt`
- `sd2snes/gbcdiag/capNNN.g13d`
- `sd2snes/gbcdiag/stateNNN.txt`

이전 버전의 로그가 SD에 남아 있어도 정상입니다. 배포판이 기존 로그를 자동 삭제하지는 않습니다. 게임 저장·강제 저장·설정 파일 기록은 계속됩니다.

문제 보고에는 C44 여부, 게임 이름·지역·패치 버전, 재현 순서, 화면·소리·입력 상태를 적습니다. 로그가 필요하면 별도 진단 빌드를 사용합니다. 게임 ROM·개인 세이브 전체를 공개 이슈에 첨부하지 않습니다.

복구할 때는 전원을 끄고 설치 전 백업의 실행 파일을 복원합니다. C43으로 돌아갈 경우 firmware.stm만 복원하면 됩니다. 배포 ZIP에는 과거 바이너리를 중복 포함하지 않습니다.

## 9. 호환성 범위

주요 구현 매퍼는 MBC1/MBC1M, MBC3+RTC, MBC5이며 ROM-only 경로도 있습니다. 테스트 게임과 확인 범위는 [호환성 기록](COMPATIBILITY.ko.md)을 참조합니다.

일본판 포켓몬 크리스탈은 사용자가 정상 동작을 확인했습니다. 이 결과를 MBC30의 확장 ROM/RAM 전체 지원이나 전체 클리어 검증으로 확대하지 않습니다. MBC2/HuC 계열·카메라·센서·통신·진동·SGB 테두리·치트는 지원 범위 밖입니다.

이 가이드는 C44의 확인된 기능을 설명합니다. 모든 게임·보드·본체 조합의 동작을 보증하는 목록은 아닙니다.
