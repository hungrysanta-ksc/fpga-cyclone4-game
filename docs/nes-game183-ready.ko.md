# NES183 — 중복 상태 조회 절감 시험

182에서 화면 갱신은 조금 나아졌지만 끊김이 남았습니다. 183은 FPGA가 이미 알려준 다음 블록의 준비 완료 응답을 재사용해 중복 상태 조회를 줄입니다. 데이터 CRC와 소비 완료 확인은 유지합니다. **실기60fps 달성을 보장하는 판은 아닙니다.** 초기 ROM 로딩과 약60초 실행 제한은 그대로입니다. 별도 타일 버퍼를 추가하는 후보는 중복 구현으로 판명되어 채택하지 않았습니다.

1. 전원을 끄고 `01-GAME183-SD-ROOT`의 내용을 SD 루트에 복사합니다.
2. 메뉴에서 `NES GAME 183.nh1`을 실행합니다.
3. 월드맵 숫자1타일에서 A로 첫 레벨에 들어가 이동·점프·스크롤을 확인합니다. 가능하면20~30초 영상을 찍어 주세요.
4. 약60초 뒤 메뉴로 복귀하면 전원을 끄고 `sd2snes/nes-progress-183.txt`, `sd2snes/nes-game-last-183.txt`를 보내 주세요. 끊김·소리·메뉴 복귀 여부도 함께 확인합니다.

게임 시작 뒤90초가 지나도 복귀하지 않으면 더 기다리지 않고 전원을 끄고 남은 로그와 증상을 알려 주세요. 044 복원 시험은 반복하지 않아도 됩니다. `02-RESTORE164-SD-ROOT`는 기존 복원 자료이며, 세이브 파일이나 세이브SRAM은 변경하지 않습니다.
