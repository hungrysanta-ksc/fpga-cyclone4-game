# MMC820 모험도 4 무입력 데모 · 60초판

1. 전원을 끄고 ZIP의 `MMC820-ADVENTURE-60SEC-SD-ROOT` **안의 내용물**을 SD 루트로 복사한다.
2. MMC819에 사용한 동일한 일본판 원본 ROM을 `sd2snes/nes/mmc820.nes`로 복사한다. SHA-256은 `9d7402da135fd1290346ccc9332836daee3a9a3cda3789999c3f86efdb5b19c2`다.
3. SD 메뉴에서 `NES MMC3 820.nh1`을 선택하고 버튼을 뗀다. 타이틀에서 기다려 플레이 데모가 나타나는지, 하단 배경과 그 위 캐릭터가 제대로 그려지는지, 약 60초에 메뉴로 돌아오는지 확인한다.
4. 메뉴로 돌아온 뒤 `sd2snes/nes-progress-mmc820.txt`, `sd2snes/nes-budget-mmc820.txt`, `sd2snes/nes-game-last-mmc820.txt`를 보관한다. 비교 구간은 5–40초와 40–55초다. 화면이 멈추면 대략적인 시각과 마지막으로 보인 장면을 함께 기록한다.

MMC819는 마지막 표시가 25.38초였다. MMC820에서는 스프라이트 표시가 도중에 꺼지는 주사선의 합성색을 그대로 저장하고 그 아래에는 배경을 표시한다. 실기에서 두 구간 모두 화면 갱신이 이어진 실행을 무입력 성능 기준으로 쓴다.
