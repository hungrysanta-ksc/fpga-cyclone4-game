# MMC516 제한 실기 시험

이 전달본은 실기 기준 MMC509와 SMB3 첫 레벨의 표시 간격을 비교하는 시험판이다. MMC516의 실기 FPS는 아직 측정하지 않았다.

1. ZIP을 풀고 `01-MMC516-SD-ROOT` **안의 내용**을 SD 카드 루트에 복사한다. 같은 전달본의 firmware.stm과 fpga_mmc516.bi3를 함께 사용한다.
2. MMC509에서 정상 실행했던 `sd2snes/nes/mmc509.nes`를 같은 폴더에 **복사**해 `mmc516.nes`로 이름을 바꾼다. 원본 게임 파일은 393,232B, CRC32 `5a04eed7`이다.
3. 메뉴에서 **NES MMC3 516.nh1**을 실행한다. 가능하면 MMC509 때와 같은 첫 레벨에서 비슷한 동선으로 플레이한다. 화면 일부가 깨지거나 팔레트·스프라이트가 한 프레임 어긋나는지, 입력과 약 60초 뒤 메뉴 복귀가 정상인지 확인한다.
4. 실행 후 아래 세 로그를 전달한다. 다시 실행하면 같은 파일이 덮어써지므로 회차별로 먼저 보관한다.

- `sd2snes/nes-progress-mmc516.txt`
- `sd2snes/nes-budget-mmc516.txt`
- `sd2snes/nes-game-last-mmc516.txt`

기존 MMC509 백업을 그대로 사용한다. 게임 ROM·저장 파일·RESTORE를 포함하지 않는다. 정상 실행과 메뉴 복귀까지 확인한 실기 기준은 MMC509다.
