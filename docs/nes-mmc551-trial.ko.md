# MMC551 제한 실기 시험

1. ZIP 안의 `01-MMC551-SD-ROOT` 폴더를 열고 그 안의 파일을 SD 카드 루트에 덮어쓴다.
2. MMC540에서 사용한 SMB3(J) ROM을 복사해 `sd2snes/nes/mmc551.nes`에 둔다. 기존 시험과 같은 파일의 CRC32는 `5a04eed7`이다.
3. 전원을 켜고 `NES MMC3 551.nh1`을 선택한다. MMC540과 비슷하게 첫 레벨을 약 60초 플레이하고 메뉴 복귀를 확인한다.
4. SD 카드의 `sd2snes` 폴더에서 다음 세 로그를 전달한다. 화면이나 입력에 이상이 있으면 발생한 구간도 적는다.

- `nes-progress-mmc551.txt`
- `nes-budget-mmc551.txt`
- `nes-game-last-mmc551.txt`

표시가 완료된 시각으로 5–40초와 40–55초를 집계한다. 이 두 구간이 첫 진입과 마지막 레벨 클리어 장면을 제외한 비교 기준이다.

이번 시험은 952·953의 공급 순서 변경과 957의 마지막 DMA 진행 비용 감소가 첫 레벨 실기 플레이에도 나타나는지 확인한다. 보드 판정은 승인된 MMC529 동등 제한 조건을 사용했다. 메뉴와 base는 MMC540 전달본과 같은 파일이며 복구에는 기존 백업을 사용한다.
