# MMC805 · MMC806 중간 성 천장 실기 시험

두 판에는 804의 배경 CHR 선행 읽기 수정과 STOP 뒤에 첫 ROM 요청 문맥을 회수하는 펌웨어가 들어 있다. MMC805는 첫 레벨의 60초 비교용이고, MMC806은 중간 성을 여러 번 플레이하는 장시간판이다.

| | MMC805 · 60초 | MMC806 · 장시간 |
|---|---|---|
| SD 루트에 복사할 폴더 | `01-MMC805-60SEC-SD-ROOT` | `02-MMC806-LONG-SD-ROOT` |
| 기존 SMB3(J) ROM의 복사 위치 | `sd2snes/nes/mmc805.nes` | `sd2snes/nes/mmc806.nes` |
| SD 메뉴에서 실행할 항목 | `NES MMC3 805.nh1` | `NES MMC3 806.nh1` |
| 정상 종료 방법 | 60초 후 자동 복귀 | L + R + Start + Select를 함께 길게 눌러 복귀 |

전원을 끄고 **설치할 판 하나의 폴더 안 내용 전체**를 SD 루트에 덮어쓴다. 기존 SMB3(J) ROM을 표의 경로와 이름으로 복사한다. 판을 바꿀 때는 해당 폴더의 펌웨어와 FPGA 파일을 함께 복사한다.

## 플레이 동선

1. MMC805에서 평소처럼 첫 레벨을 플레이하고 60초 뒤 SD 메뉴가 보이는지 확인한다. 이전 60초판과 같은 5–40초·40–55초 구간으로 표시 수를 비교할 수 있다.
2. MMC806에서 월드 1의 1-1과 1-2를 깬 뒤 **성 모양 중간 보스 스테이지의 두 번째 방**으로 간다. 천장이 내려오기 시작할 때부터 해당 구간을 빠져나갈 때까지 확인하고, 가능한 만큼 다시 통과한다.
3. 통과 횟수와 종료 방식을 적는다. 예를 들어 “3회 통과 후 직접 종료, SD 메뉴 보임” 또는 “2회 통과, 3번째 하강 중 자동 복귀, SD 메뉴 보임”처럼 남기면 마지막 화면과 로그를 맞출 수 있다. 멈춘 뒤 메뉴가 돌아오지 않았다면 마지막 화면과 전원을 다시 켰는지도 기록한다.

## 실행 직후 보관할 파일

SD의 `sd2snes`에 기록된다. 같은 판의 다음 실행에서 파일을 다시 쓰므로 **재실행 전에 세 파일을 함께 PC의 회차별 폴더로 복사한다**. 오류가 났을 때는 생성된 파일만 있어도 보관한다.

| 로그 | MMC805 | MMC806 |
|---|---|---|
| 진행과 메뉴 준비 | `nes-progress-mmc805.txt` | `nes-progress-mmc806.txt` |
| 표시 수와 처리 시간 | `nes-budget-mmc805.txt` | `nes-budget-mmc806.txt` |
| 종료 원인과 첫 CHR 요청 | `nes-game-last-mmc805.txt` | `nes-game-last-mmc806.txt` |

천장 구간에서 다시 종료되면 **game-last 원본**에 있는 `run_rom_error`, `fault_context_valid`, `fault_context_hi/lo`, `ppu_state_valid`, `ppu_state_hi/lo`를 함께 사용한다. 유효한 물리 문맥에서는 PPU가 요구한 주소, 처리 중이던 요청의 종류·주소, 응답 유무와 대기 시간을 해독할 수 있다. 유효 플래그가 0이면 해당 문맥은 미수집으로 처리한다. `stop_ok`, `base_restored`, `safe_to_reload`와 progress의 마지막 단계는 사용자가 실제로 SD 메뉴를 봤는지와 함께 대조한다.

부팅 중에만 암전이 반복되면 일반 실행 로그부터 보관한다. 별도 `NES-DIAG` 폴더의 START와 BOOT 항목은 각각 START 수락 직후와 65816 준비 직후에 STOP을 시험하며, 게임 화면 없이 메뉴로 돌아오는 진단용이다.
