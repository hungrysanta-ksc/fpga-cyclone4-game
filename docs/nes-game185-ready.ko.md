# NES185 타일맵 재사용 실기 시험

직전에 표시한 화면과 같은 타일맵 구간은 SNES 쪽에 남아 있는 내용을 복사하고, 달라진 구간만 전송한다. 타일 그림(CHR), 팔레트, 화면 완성 확인은 계속 처리한다. 입력 자동 읽기가 끝난 안정된 값만 전달하는 수정도 포함했다.

보관된 SMB3 두 화면의 비교에서는 타일맵 요청량이 3,952바이트에서 1,214바이트로 줄었다. 다만 작은 복사 명령 수는 늘어나므로 전체 속도와 첫 레벨의 개선 폭은 이번 실기 시험에서 판단한다. 아직60fps 완성판이 아니다. ROM 초기 로딩 방식과 약60초 플레이 제한은 유지한다.

## 설치와 실행

1. 현재 SD 시험 파일을 백업한다. ZIP의 `01-GAME185-SD-ROOT` **안의 내용**을 SD 최상위에 복사한다. `firmware.stm`과 `fpga_n185.bi3`는 반드시 함께 사용한다. 표시 프로토콜이 바뀌었으므로184 파일과 섞으면 안 된다.
2. 메뉴에서 `NES GAME 185.nh1`을 실행한다. 초기 로딩 시간과 게임 화면 이후의 플레이 시간을 구분한다.
3. 스타트로 플레이어 선택·월드맵에 진입하고, 숫자 **1** 타일로 이동하여 **A**로 첫 레벨에 들어간다.
4. 오프닝과 첫 레벨의 화면 끊김을 비교하고 이동·점프·대시·음악을 확인한다. 가능하면 첫 레벨에서20~30초 영상을 촬영한다.
5. 여유가 있으면 큰 마리오로 아래 방향을2~3초 유지해 앉기가 풀리는지 확인한다. 불가능하면 방향키나 대시 버튼을 길게 눌렀을 때 입력이 끊기는지만 관찰해도 된다. 짧게 누르기와 길게 누르기의 구분도 알려주면 좋다.
6. 약60초 후 자동 메뉴 복귀를 확인하고 다음 두 파일을 전달한다.

- `sd2snes/nes-progress-185.txt`
- `sd2snes/nes-game-last-185.txt`

첫 게임 화면 이후90초가 지나도 복귀하지 않으면 더 기다리지 말고 증상과 남은 로그를 알려준다. 화면만 멈췄을 때 음악과 버튼 반응이 이어지는지도 중요하다. 같은044 복원 시험은 반복하지 않아도 된다. `02-RESTORE164-SD-ROOT`는 기존 정상 조합으로 되돌릴 필요가 있을 때만 사용한다.

## 확인 범위

기존4패킷 전송 큐와 안전한 화면 완성 확인을 유지한다. 로그의 `sink_window_schema=184`는 큐 규격이 같다는 뜻이며185 설치 실패를 뜻하지 않는다. 전송·소비 패킷 수는 프레임 수가 아니다. 오류 또는 제한 시간 종료 후 STOP·기본 코어 복원 다음에 로그를 저장한다.

FPGA RTL과 배치·배선은 검증된184 것을 재사용했고 SNES 표시 ROM만 교체했다. 다른 게임의 세이브 SRAM은 사용하지 않는다. 현재 실기 속도·입력 유지 결과는 미확인이다. 오프닝이 빨라져도 첫 레벨60fps 달성으로 판정하지 않는다.
