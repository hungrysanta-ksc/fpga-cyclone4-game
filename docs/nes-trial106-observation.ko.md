# NES106 제한 실기 관측 초안 — 현재 실행 승인 아님

E1/E2가 열린 동안 이 문서를 설치 지시로 사용하지 않는다. 아래는 조건 충족 후 패키지에 넣을 관측 계약이며, 기존084/092 성공 시험을 다시 하라는 요청이 아니다.

## 시험 범위

처음에는105 조합의80KiB 합성 입력 한 번만 적재·전체 비교·STOP·base/menu 복귀를 관측한다.96KiB는 첫 반환 판정 후 별도 실행한다. NES RUN/상용ROM/SMB3를 실행하지 않고 의도적 클록정지/전원고장도 주입하지 않는다. 고장주입 제외는 회로의 공통고장 보호를 뜻하지 않는다.

## 패키지 제공 전에 갖출 것

-105 파일 SHA와역할, 사용자 정상파일의 독립 보존 및정확044복원 경로. 두firmware를 같은대상에 동시에 복사하지 않는다.
-이전 nes-verify-last-094.txt는 먼저 보존·분리해 새 결과와 섞이지 않게 한다. 날짜만으로 신선함을 판단하지 않는다.
-현재 VERSION은CF86-IRQ104, 표식/로그명은094다. 표식 이름만으로 펌웨어 버전을 확인하지 않는다.
-실기SD는 이PC에 연결할 필요가 없다. 사용자가 외부에서 파일복사·실행·TXT/사진/영상 반환한다. LED·카트리지분해·USB 계측을 요구하지 않는다.

## 관측 시계와 종료

80KiB 표식을 선택한 시점부터 사람이 시간을 잰다. 최대600초(10분)까지 관측한다. 정상 메뉴가 돌아오면 그 시점과 마지막화면을 기록하고 추가 반복을 하지 않는다.600초까지 돌아오지 않으면 원인 미확정으로 종료하고 전원을 끈 뒤 SD를 분리해 파일을 보존한다. 전원이 켜진 상태에서 SD를 빼지 않는다.

10분은 운영상 대기 한도다. 코드의 타이머·watchdog·MCU WCET·메모리8µs 보호가 아니다. 이 시간이면 SD메타데이터 저장이 반드시 끝났다는 보장도 없다. 시험 전 독립 보존본이 필요한 이유이며 오류 후 펌웨어에 추가 저장을 강제하지 않는다.

## 반환 자료 판정

|새 관측|해석|
|---|---|
|새TXT에 적재/비교/STOP/base 성공 및PREPARED_RESET_HELD, 실제메뉴복귀|진단 준비보고와메뉴 관측이 둘다 있음. 전체NES/게임 성공은 아님|
|새TXT 준비상태, 메뉴없음|RESET 해제 이후 결과 미확인. TXT는 해제 전 저장이며 반환 성공 아님|
|메뉴있음, 새TXT 없음/0바이트|메뉴 관측만 확인. 저장 성공·전체 비교 성공은 미확인|
|오래된TXT만 있음|이번 실행 결과로 사용하지 않음|
|오류TXT 또는멈춘화면|파일/화면 그대로 보존. 공유IO fault뒤 새보고를 기대하거나 반복실행하지 않음|
|10분 도달/관측불가|시간과마지막화면 기록, 원인 미확정. 특정타이머/SD/FPGA오류로 단정하지 않음|

전원을 끈 상태에서 정확044로 수동 복원한다. 기존 정상base/menu는 그대로 보존한다. 이번새시험의 복원 결과는 사용자의 실제 관측으로 기록하되 과거084/092의 성공을 새성공으로 대체하지 않는다. 다음 판정에 필요한 자료는 새TXT(없으면없음), 메뉴복귀 여부, 선택부터 경과시간, 마지막화면, 복원 결과다.
