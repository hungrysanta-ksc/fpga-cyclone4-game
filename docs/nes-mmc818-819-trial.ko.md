# 무입력 오프닝 60초 시험

**MMC819 타카하시 명인의 모험도 4의 기준 측정을 보류한다.** 첫 무입력 실기에서 25.38초 뒤 새 화면 표시가 끊겼다. 같은 ROM의 다음 실기 시험은 MMC820으로 진행한다. [MMC820 설치 안내](nes-mmc820-trial.ko.md) 기존 MMC818 캡틴 츠바사 II는 별도의 무입력 후보이며 실기에서 두 구간의 화면 갱신을 확인해야 한다. 두 판은 같은 65816·FPGA와 같은 60초 일정을 쓴다. [실기와 주사선 재현 결과](progress/pr-164.md#mmc819-데모-전환)

| | 기본 · 타카하시 | 스프라이트 부하 · 캡틴 츠바사 |
|---|---|---|
| 설치 폴더 | `01-MMC819-ADVENTURE-60SEC-SD-ROOT` | `02-MMC818-TSUBASA-60SEC-SD-ROOT` |
| 제공한 원본 ROM을 복사할 위치 | `sd2snes/nes/mmc819.nes` | `sd2snes/nes/mmc818.nes` |
| SD 메뉴 항목 | `NES MMC3 819.nh1` | `NES MMC3 818.nh1` |

1. 전원을 끄고 **선택한 폴더 하나의 내용물 전체**를 SD 루트에 복사한다. 해당 게임의 원본 ROM을 위 경로에 넣는다.
2. SD 메뉴에서 실행 항목을 선택한 뒤 버튼을 떼고 그대로 둔다. 타이틀에서 Start를 누르거나 데모를 건너뛰지 않는다.
3. 약 60초 뒤 메뉴로 자동 복귀하면 `sd2snes`의 진행·통계·종료 로그를 보관한다. 기본판은 `nes-progress-mmc819.txt`, `nes-budget-mmc819.txt`, `nes-game-last-mmc819.txt`이다. 비교판은 세 파일의 번호가 `818`이다.

무입력 데모가 예정된 장면으로 넘어가고 5–40초와 40–55초 양쪽에서 새 화면 표시가 이어진 실행을 그 게임의 실기 기준값으로 삼는다. 같은 게임과 구간의 표시 수와 FPS를 비교한다. 시작·종료 5초는 집계에서 제외한다. 장시간 SMB3는 기존 MMC817을 사용한다.
