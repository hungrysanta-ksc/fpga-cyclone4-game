# MMC826 모험도 4 무입력 60초판

1. 전원을 끄고 ZIP의 `MMC826-ADVENTURE-60SEC-SD-ROOT` 폴더 안의 내용물을 SD 루트에 덮어쓴다.
2. MMC825에 사용한 일본판 모험도 4 ROM을 `sd2snes/nes/mmc826.nes`로 복사한다.
3. SD 메뉴에서 `NES MMC3 826.nh1`을 선택하고 버튼을 뗀다. 오프닝에서 스테이지 데모로 넘어가는 장면과 약 60초 뒤 메뉴 복귀를 확인한다.
4. 복귀 후 `sd2snes/`의 `nes-budget-mmc826.txt`, `nes-progress-mmc826.txt`, `nes-game-last-mmc826.txt`를 보관한다. 조기에 메뉴로 돌아온 경우에도 같은 파일을 보관한다.

예산 로그의 `display_1_30_60`에는 표시 완료 횟수 두 개가 기록된다. 첫 값은 1초 이상 30초 미만(29초), 둘째 값은 30초 이상 60초 미만(30초)이다. 각 값을 해당 구간의 초로 나누면 표시 FPS가 된다. 경계에 걸친 프레임은 표시 완료 시각으로 한 번만 센다. 시간은 표시 세션 시작 기준이며 게임 장면을 인식해 타이머를 다시 시작하지 않는다.

이번 실기 결과가 새 구간의 첫 기준값이다. MMC825까지의 로그에 기록된 5–40초·40–55초 값은 당시 구간으로 비교한다.
