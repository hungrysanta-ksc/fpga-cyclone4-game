# MMC1035 커비 60초 캡처·타일 뱅크 실기 시험

1. ZIP의 `MMC1035-KIRBY-60SEC-SD-ROOT` 폴더 내용을 SD 루트에 복사한다. MMC1034에 사용한 일본판 별의 커비 ROM을 `sd2snes/nes/mmc1035.nes`로 둔다.
2. 전원을 껐다 켜고 `NES MMC3 1035.nh1`을 선택한다. 입력 없이 60초 재생한 뒤 메뉴 복귀를 확인한다. 두 번 같은 절차로 실행한다.
3. 매회 `sd2snes`에 생긴 `nes-frame-mmc1035.bin`, `nes-budget-mmc1035.txt`, `nes-progress-mmc1035.txt`, `nes-game-last-mmc1035.txt`를 복사하고 회차를 표시한다.

55–60초 표본에서 BG 666·OBJ 16·변경 map 0·타일 15개·4묶음·마지막 OBJ 96B(오프셋 416)·입력 17블록 1,849B를 우선 대조한다. 실행마다 세대와 표시 뱅크가 바뀔 수 있다. 1–30초와 30–60초의 표시 FPS도 각각 비교한다. 같은 작업량에서 공개 간격이 4→3 VBlank로 줄고 직전 공개 기준 최종 ACK도 앞당겨졌는지가 판정 기준이다.
