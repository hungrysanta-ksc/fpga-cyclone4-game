# MMC897 · 모험도 4 무입력 60초 실기판

일반 게임 실행에서 ARM이 입력 블록의 상태를 확인하는 네 곳 모두 SRAM의 같은 8바이트를 SPI로 송신한다. 첫 게임 화면, 오프닝에서 플레이 데모로의 전환, 60초 뒤 자동 메뉴 복귀를 확인한다.

1. 전원을 끄고 ZIP의 `MMC897-ADVENTURE-60SEC-SD-ROOT` 폴더 안의 내용물을 SD 루트에 복사한다.
2. 직전에 사용한 모험도 4 원본 `sd2snes/nes/mmc896.nes`를 같은 폴더에 `mmc897.nes`라는 이름으로 복사한다.
3. 전원을 켜고 **NES MMC3 897.nh1**을 선택한다. ROM 로딩이 끝나면 입력 없이 첫 화면과 플레이 데모를 보고 자동으로 메뉴에 돌아오는지 확인한다.
4. 실행 뒤 `sd2snes`의 `nes-progress-mmc897.txt`, `nes-budget-mmc897.txt`, `nes-game-last-mmc897.txt`를 보관한다. 화면이 계속 검다면 첫 화면이나 소리가 한 번이라도 나왔는지와 생성된 로그만 전달한다. 재실행 전에 로그를 복사하면 첫 시도 기록을 보존할 수 있다.

60초 완주 로그는 1–30초 오프닝과 30–60초 플레이 데모로 나누어 비교한다.
