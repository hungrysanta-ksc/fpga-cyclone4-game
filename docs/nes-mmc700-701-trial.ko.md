# MMC700 60초판 / MMC701 장시간판

두 판 모두 **699의 CHR 뱅크 전환 직전 sprite 읽기 요청 수정**을 포함합니다. MMC700은 기존 MMC695의60초 실행 코드, MMC701은 MMC696의장시간 실행 코드를 유지하고 설치·로그 이름을 바꿨습니다. 이번 목적은 스페이드 보너스 진입 오류의 실기 해소 확인입니다.

## 설치

1. 전원을 끈 뒤, 원하는 **한 폴더의 내용만** SD 루트로 복사합니다.
   - `01-MMC700-60SEC-SD-ROOT`: 약60초 뒤 자동 메뉴 복귀.
   - `02-MMC701-LONG-SD-ROOT`: 고정 플레이 시간 제한 없음.
2. 지금 사용한 게임 ROM(`mmc695.nes` 또는 `mmc696.nes`와 같은 내용)을 `sd2snes/nes/mmc700.nes` 또는 `sd2snes/nes/mmc701.nes`로 복사합니다. 대상은 기존 SMB3(J), payload CRC32 `5a04eed7`입니다. ROM 내용은 수정하지 않습니다.
3. 설치한 판의 `NES MMC3 700.nh1` 또는 `NES MMC3 701.nh1`을 실행합니다. 이전 번호의 메뉴 항목은 선택하지 않습니다.
4. 판을 바꿀 때는 전원을 끄고 해당 폴더의 `firmware.stm`, FPGA 파일, 메뉴 파일을 함께 교체합니다. 두 폴더의 내용을 동시에 덮어쓰지 않습니다.

`fpga_base.bi3`와 `m3nu.bin`은 정상 STOP·메뉴 복귀에 필요한 기본 구성입니다. RESTORE 폴더·이전 펌웨어 복구본·게임 ROM·사용자 세이브는 ZIP에 포함하지 않습니다. 기존 백업·세이브는 그대로 둡니다.

## 권장 시험 순서

1. **MMC700:** 이전과 비슷한 첫 레벨 동선으로 플레이하고, 약60초 뒤 자동 메뉴 복귀를 확인합니다. 프레임 비교는 **5–40초 /40–55초**로 나눕니다.
2. **MMC701:** 월드1의레벨1·2를 클리어한 뒤 아래로 내려가 **스페이드 보너스 게임**에 진입합니다. 안내 화면에서 진행해 회전 게임까지 들어가고, 플레이 후 월드 맵으로 돌아오는지 확인합니다. 이전에 메뉴로 튕겼던 바로 그 진입 구간이 우선입니다.
3. 장시간판으로 다른 스테이지와 적이 많은 화면을 계속 플레이합니다. 가능하면 이전 종료 시점인 약14분11초를 넘겨 확인합니다. 화면 깨짐·멈춤·입력 이상이나 예기치 않은 메뉴 복귀가 있으면 당시 장면과 대략적인 시간을 기록합니다.
4. **MMC701 정상 종료:** `L + R + Start + Select`를 함께 길게 누릅니다. 입력 처리 뒤 기존 STOP→base 복구→메뉴 복귀가 진행됩니다. 이 조합은 장시간판에서 시험합니다. MMC700은 자동 종료를 사용합니다.

실기 ROM에 치트나 자동 진입 코드를 넣지 않았습니다. 스페이드에는 정상 게임 진행으로 접근합니다. 강제 전원 차단 대신 종료 조합으로 복귀하면 종료 로그를 보존할 수 있습니다.

## 돌려줄 로그

메뉴로 돌아온 뒤 `sd2snes` 폴더의 해당 세 파일을 복사합니다. 같은 판을 다시 실행하면 로그가 덮어써지므로 **재실행 전에 회차를 붙여 보관**해 주세요.

| 판 | 로그 파일 |
|---|---|
| MMC700 | `nes-progress-mmc700.txt`, `nes-budget-mmc700.txt`, `nes-game-last-mmc700.txt` |
| MMC701 | `nes-progress-mmc701.txt`, `nes-budget-mmc701.txt`, `nes-game-last-mmc701.txt` |

장시간 로그와 함께 **스페이드 진입 성공 여부, 대략적인 플레이 시간, 자발적 종료 조합인지 오류로 메뉴 복귀했는지**를 알려주시면 됩니다. 실행 실패 때도 세 파일을 보관합니다.

장시간판의 첫5–40/40–55초 집계는 유지됩니다. 상세5초 bin은 약60초 epoch마다 재사용하며 전체 장시간의 모든5초 구간을 보존하는 방식은 아닙니다. RUN 도중 SD 기록은 추가하지 않았습니다.

## 검증 범위

699 수정은 실제 T6524조건·ROM 중재24조건·중간 STOP24조건과 전체 Lite FIT·기존 제약 STA를 통과했습니다. 두 위상의106화면 모델 재생은 기존694의 표시 간격·마지막 ACK와 동일합니다. 이번 변경을 FPS 향상으로 계산하지 않습니다.

전달본은 두 ARM 전체 링크와 함수 바이트 동일성, 정상판의 packed ROM을 넣은 별도 전체 FIT·STA, SOF→RBF→BI3 변환·실제 프로그래머, 설치 marker·로그·STOP/base/menu 경계를 확인한 뒤 패키징합니다. 외부 IO 전체 sign-off와 수정 후 실기 안정성은 아직 확인 단계입니다.
