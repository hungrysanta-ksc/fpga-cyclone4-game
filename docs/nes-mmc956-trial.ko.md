# MMC956 · 모험도 4 후반 OBJ 진단판

1. 전원을 끄고 ZIP의 `MMC956-ADVENTURE-60SEC-SD-ROOT` **폴더 안의 내용물**을 SD 카드 루트에 복사한다.
2. MMC955에 사용한 모험도 4 일본판 ROM을 `sd2snes/nes/mmc956.nes`로 복사한다.
3. **NES MMC3 956.nh1**을 한 번 실행한다. 버튼을 누르지 않고 오프닝·데모를 60초 재생해 메뉴 복귀를 확인한다.
4. 재실행하기 전에 `sd2snes` 폴더의 `nes-progress-mmc956.txt`, `nes-budget-mmc956.txt`, `nes-game-last-mmc956.txt`, **`nes-frame-mmc956.bin`**을 보관한다.

실기 성능 기준은 MMC955다. MMC956은 같은 보드·65816에서 두 화면의 상세 로그를 한 번에 얻는 진단판이다. 1–30초·30–60초 표시 장수도 계속 기록한다. 상세 SPI 조회는 각 화면의 최종 ACK를 확인한 뒤 실행되므로 다음 화면의 일정에는 영향을 줄 수 있다.

55–60초에 화면당 요약을 기록한다. 56.00–57.49초에 시작한 화면 중 변경 map 행이 0이고 OBJ가 40개 이상이며, 마지막 OBJ가 32B인 경우에 staging 오프셋 1,184와 1,216에서 각각 처음 일치한 화면을 고른다. MMC955 기록에서는 56.44초·56.68초에 해당한다. 세대 번호와 초가 달라져도 실제 작업 내용으로 찾는다. 한쪽 조건만 나타나면 해당 상세 기록과 나머지 화면 요약을 사용할 수 있다.

상세 기록은 첫 E9를 기준으로 타일의 첫 ROM 요청·첫/마지막 허가와 각 묶음의 뱅크 반환 시각을 제공한다(약 0.390ms 단위). ROM 허가가 없는 타일에는 요청 시각을 부여하지 않는다. ARM의 연속된 첫 유효 최종 ACK 간격은 별도로 기록한다. 화면 공개 VBlank 번호와 개별 중간 허가 시각은 이 형식에 들어 있지 않다.
