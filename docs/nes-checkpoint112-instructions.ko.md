# NES112 단계 로그 개선판 실기 안내

이번 개선판은 화면 진행 표시 대신 **SD의 단계 로그**를 남깁니다. 정상 전원에서80KiB 시험을 한 번 실행하고 정상044로 복원합니다. 영상은 필요하지 않습니다.

## 복사

1. 전원을 끈 뒤 SD를 PC에 연결하고 현재 SD·저장 데이터를 백업합니다. 이전 `sd2snes/nes-progress-112.txt`와 `sd2snes/nes-verify-last-094.txt`가 있으면 PC로 옮겨둡니다. 새 실행은 단계 로그를 새로 시작합니다.
2. ZIP을 새 폴더에 풀고 **`01-TRIAL-SD-ROOT` 안의 내용만 SD 루트에** 덮어씁니다. `02-RESTORE044-SD-ROOT`는 시험 후 복원할 때 사용합니다. 두 폴더를 동시에 적용하지 않습니다.
3. 선택 파일은 이전과 같은 `NES VERIFY 094 80.nh1`입니다. 0바이트가 정상이며 확장자를 바꾸지 않습니다. 개선판 펌웨어 버전은 `CF86-LOG112`이고 `firmware.stm` 크기는184452바이트입니다. 이번에는 이 새 펌웨어를 반드시 적용해야 합니다.

## 실행과 대기

1. 정상 메뉴에서 `NES VERIFY 094 80.nh1`을 한 번 선택하고 시간을 잽니다.
2. 화면이 계속 로딩 상태여도 **중간 리셋을 누르지 말고 최대10분** 관측합니다. 느린 통신의 설정 대기만 최소 약113초이고 SD·설정·새 로그 저장 시간이 추가됩니다. 10분은 예상 완료시간이나 보장이 아니라 관측 상한입니다.
3. 메뉴가 돌아오면 다시 실행하지 않습니다. 돌아오기까지의 시간을 기록하고 전원을 끕니다. 10분에도 돌아오지 않으면 경과시간과 마지막 화면 상태를 적고 전원을 끕니다. 실행 중 SD를 꺼내지 않습니다.
4. 메뉴가 처음부터 나오지 않거나 표식이 보이지 않으면 해당 상태를 알려주세요. 임의 확장자 변경이나 다른 표식 실행은 하지 않습니다.

## 로그 보존과 복원

전원을 끈 다음 SD를 PC에 연결하고 아래 파일을 보내주세요. 둘 중 하나만 있거나0바이트여도 재시험하지 않고 그대로 전달하면 됩니다.

- **`sd2snes/nes-progress-112.txt`**: 입력 열기, 검증, FPGA 구성, 적재/비교16KiB 진행, STOP, 기본FPGA 복구, 메뉴 복사/준비의 순차 기록입니다.
- `sd2snes/nes-verify-last-094.txt`: 기본FPGA 복구와 메뉴 준비 뒤 작성하는 기존 최종 결과입니다.

그다음 `02-RESTORE044-SD-ROOT` 안의 내용을 SD 루트에 덮어써서 정상044로 복원합니다. 이번 진단 표식은 SD에서 치우고 메뉴와 GBC 게임이 정상인지 확인합니다. **전원 재투입만으로는044 복원이 아닙니다.** 복원044 `firmware.stm`은169056바이트이며 시험112와 파일 이름만 같습니다.

텍스트와 함께 **실제 메뉴 복귀 여부, 기다린 시간, 복원 후 메뉴·GBC 정상 여부**만 알려주세요. 로그 해석은 제가 하겠습니다. 화면이 달라졌을 때 사진 한 장은 도움이 되지만 이번 시험의 필수 자료는 아닙니다.

## 기록을 해석하는 기준

`seq`는0부터 증가하며, `stage`는 마지막으로 도달한 단계, `bytes/total`은 진행량, `elapsed_ms`는 MCU가 읽은 경과시간입니다. 긴 구간은16KiB마다 기록합니다. 기록은512바이트 단위라 빈 공간이 많이 보여도 정상입니다. `OPEN_INPUT`, `CONFIG_START`, `BEGIN_LOAD`, `STOP_START`, `BASE_START`, `MENU_COPY_START`는 해당 작업 **직전**이며 완료 증명이 아닙니다. `CONFIG_READY`, `STOP_DONE`, `BASE_DONE`은 각 경계의 정상 통과 뒤 기록입니다. `MENU_PREPARED`도 RESET 해제 전이므로 실제 메뉴 화면 복귀는 별도로 알려주세요.

각 기록은 쓰기·동기화·닫기를 확인한 뒤 진행합니다. 다만 SD 자체 고장이나 갑작스러운 전원 차단에서 마지막 기록까지 무조건 보존된다고 보장하지는 않습니다. CSS/NMI·공유 고장 이후에는 보호를 위해 새 SD 기록을 중단합니다. 따라서 마지막 남은 기록과 화면·시간을 함께 봅니다.

시험 범위는 이전에 승인한 정상 전원·자체80KiB 1회입니다. 게임 RUN·96KiB·고장 주입은 포함하지 않습니다. 기존 전기 조건 E1/E2·8µs 차단 보장은 여전히 미완료입니다. FPGA와044 복원 파일은 기존 검증본을 그대로 사용했습니다.
