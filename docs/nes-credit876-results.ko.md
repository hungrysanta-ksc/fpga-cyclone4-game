# 950 출력 중 951 첫 입력을 받을 수 있는 시점

실기 기준은 MMC872, 950의 마지막 map 반환과 첫 스크롤의 발행 순서를 보존하는 비교 대상은 874다. 모험도 4의 같은 무입력 기록, dot 0 보정, ROM 허가 일정, 공유 SPI 비용으로 두 시작 위상을 재생했다. 아래의 시각은 링크된 ARM과 65816의 결합 재생에서 얻었다. 950·951·952는 밀집 재생의 세대 번호다.

**MMC872를 유지한다.** 951의 첫 블록을 1.7ms 이상 일찍 받을 수 있었지만, 950의 선행 DMA·표시 3회와 952의 한 VBlank 빠른 공개를 두 위상에서 함께 달성한 후보는 없었다.

## 입력 버퍼와 큐의 소유권

ARM은 raw·팔레트 복사와 행 계산을 마친 뒤에만 `resident->prepared`를 설정한다. 이때 이전 화면의 map·raw·OAM·테이블은 출력 버퍼에 남는다. FPGA는 END를 처리하고 이전 타일 작업을 모두 반환한 뒤 새 입력을 제공한다. 두 조건 사이에 D0를 보내면 빈 응답을 받을 수 있다.

재시도 후보의 950에서는 두 위상 모두 첫 D0 시점에 planner가 버퍼를 놓았지만 타일 작업 두 개가 남아 있었다. 첫 블록을 실제로 받은 시점에는 타일 큐·진행 중인 ROM 읽기·미발행 작업이 모두 비어 있었다. ARM은 D1의 CRC·토큰을 확인하고 D2 반환을 D0로 확인했다. 이전 화면의 최종 ACK·EA 반환 뒤에만 새 입력의 D3 승인과 후속 COMMIT 레코드 수락을 허용한다. 네 슬롯의 기존 credit과 동일한 보드·65816을 사용했다.

## 첫 블록을 옮겼을 때 다음 블록이 받는 영향

874보다 빠르면 음수다. 단위는 µs다. 다음은 section 5의 큐 반환 뒤 빈 D0를 재시도한 실제 링크의 시각이다.

|---|---:|---:|
| 951 첫 블록 D1 완료 | −1,734.0 | −1,796.8 |
| 950 마지막 테이블 E1 완료 | +651.1 | +588.2 |
| 950 SEAL E1 완료 | +649.9 | +587.0 |
| 951 두 번째 블록 D1 완료 | +88.7 | +25.8 |
| 951 END를 담은 블록의 D2 | +49.8 | −13.0 |
| 950 EA 반환 | +48.9 | −13.9 |

같은 SPI에서 첫 블록 뒤에 950의 마지막 테이블 240B와 SEAL 168B를 발행했다. 선행 수신으로 확보한 시각은 두 번째 블록까지 이어지지 않았다. 16개 입력 블록이 950 EA 전에 반환됐고, 17번째인 COMMIT 레코드 반환은 두 위상에서 각각 이전 캡처 시작선보다 6,480·6,725클록 늦었다. 952의 SEAL 수락은 두 위상에서 234선, 독립 검사 후 업로드 진입은 259선이었다. 다음 VBlank에 공개됐다.

## 전체 일정과 채택 조건

각 값은 위상 1 / 위상 2 순이다. 950 열은 1,088B를 직전 VBlank에 DMA하고 표시 간격도 3회였는지를 나타낸다. 공개 열은 화면이 실제로 나온 VBlank 번호다. 952 목표는 147 / 148, 759 마감은 176 / 176이다. 마지막 ACK 차이는 MMC872에 대한 65816 공개 시각의 차이다.

수신 정책을 끄고 Flash 절감만 적용한 212,940B 대조군도 밀집 간격은 141 / 141이었다. 진행 없는 큐 대기를 재사용한 링크는 위상 1에서 951 마지막 D2를 874보다 0.212ms 앞당겼지만 마감까지 947클록(44.1µs)이 남았다. 이 링크의 950은 두 위상 모두 유효한 첫 블록을 SEAL 이후에 얻었다. 위상 2에서는 950 자체가 4 VBlank로 늘었다. 실제 버스가 첫 블록을 언제 제공했는지와 마지막 D2의 절대 시각을 함께 비교해야 한다.

세 후보 모두 오프닝 62장·전환 50장·밀집 62장씩 두 위상에서 MMC872와 map·유효 화면 픽셀이 일치했다. 밀집 작업량과 warm map 전송량도 대조했다. ARM 오류·STOP·메뉴 복귀 경로와 65816의 12개 독립 검사·cold 복구 조건을 각 후보의 링크·패킷으로 검증했다. 실제 보드와 65816 ROM은 기존 것을 사용하며 실기 설치본을 교체하지 않는다.

**다음 측정은 950의 마지막 테이블 발행부터 951의 두 번째 D1까지다.** 첫 D1을 앞당기더라도 두 번째 D1까지의 이득이 사라지면 후보를 일찍 제외할 수 있다. 동시에 재시도 후보에서 950 최종 ACK 공개부터 ARM의 유효 E0까지 0.425 / 0.432ms, EA 반환까지 0.674 / 0.680ms가 걸렸다. 이 구간에 수행하는 951 END를 담은 블록의 D1·D2·확인 D0를 950 공개 전에 마칠 수 있는지가 다음 분기점이다. 마지막 D2가 캡처선 전에 끝나고 952의 절대 공개가 앞당겨졌을 때 전체 장면을 다시 비교한다.
