# MMC1034 커비 60초 입력·타일 묶음 계측판

1. ZIP 안의 `MMC1034-KIRBY-60SEC-SD-ROOT` 폴더 내용을 SD 루트에 복사한다. 사용하던 일본판 별의 커비 ROM을 `sd2snes/nes/mmc1034.nes`로 둔다.
2. 전원을 껐다 켜고 `NES MMC3 1034.nh1`을 선택한다. 무입력으로 60초 재생하고 메뉴 복귀를 확인한다. 같은 조건으로 두 번 실행한다.
3. 매번 `sd2snes`의 `nes-frame-mmc1034.bin`, `nes-budget-mmc1034.txt`, `nes-progress-mmc1034.txt`, `nes-game-last-mmc1034.txt`를 복사하고 회차를 표시한다.

55–57.5초에는 100ms마다, 57.5–60초에는 50ms마다 최대 한 화면을 기록한다. 입력 준비와 첫 D1·마지막 D2 응답·D0 반환 확인, 첫 E9 명령, 최대 네 E9 패킷 수락과 네 뱅크 반환, 마지막 묶음의 첫 plan, SEAL과 화면 공개·최종 ACK를 같은 세대로 대조한다. 15타일·4묶음에 해당하는 화면을 우선 비교한다. 세대 번호는 실행마다 달라질 수 있다.
