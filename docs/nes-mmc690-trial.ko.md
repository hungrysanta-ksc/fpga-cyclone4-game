# MMC690 제한 SMB3 실기 비교

689D 보드·685 65816과 688 ARM을 묶은 시험판입니다. MMC666와 같은 첫 레벨 동선에서 5–40초·40–55초 표시 횟수와 스테이지 진입·STOP·메뉴 복귀를 비교합니다.

## 설치

1. ZIP의 `01-MMC690-SD-ROOT` **안의 내용**을 SD 최상위로 복사하고 같은 파일은 덮어쓰세요.
2. 기존 `sd2snes/nes/mmc666.nes`를 같은 폴더에 **`mmc690.nes`**로 복사하세요. MMC666에서 사용한 동일 SMB3(J), CRC32 `5a04eed7`을 사용합니다.
3. 메뉴에서 **`NES MMC3 690.nh1`**을 선택하세요. 예전 시험판 항목과 구분해 주세요.

설치 파일은 `sd2snes/firmware.stm`과 `sd2snes/fpga_mmc690.bi3`입니다. 메뉴 복귀에 필요한 `fpga_base.bi3`와 `m3nu.bin`도 포함했습니다. 게임 ROM·세이브·RESTORE는 포함하지 않습니다.

## 플레이와 확인

1. MMC666 때와 비슷한 시점에 START를 눌러 **스테이지 선택 화면 진입**과 첫 레벨 1-1 로딩을 확인해 주세요.
2. 첫 레벨을 같은 동선·비슷한 속도로 플레이하세요. 특히 후반의 적이 많이 나오는 구간을 비슷하게 진행해 주세요. 시간 집계는 시험 프로그램의 기존 실행 타이머 기준이며, START를 눌렀다고 다시 시작하지 않습니다.
3. **약 60초 뒤 자동 STOP과 메뉴 복귀**를 기다리세요. STOP을 위한 별도 버튼 입력은 필요 없습니다. 복귀한 메뉴가 표시되고 방향키 입력을 받는지도 확인해 주세요.
4. 검정 화면·조기 복귀·스테이지 진입 중 종료가 있으면 재실행 전에 같은 실행의 로그 세 개를 복사하고 마지막으로 보인 화면을 적어 주세요.

## 반환할 로그

SD의 `sd2snes` 폴더에서 다음 세 파일을 같은 실행의 묶음으로 보내 주세요.

- `nes-progress-mmc690.txt`
- `nes-budget-mmc690.txt`
- `nes-game-last-mmc690.txt`

다시 실행하면 같은 이름으로 갱신됩니다. 여러 번 시험할 때는 PC에 복사한 뒤 세 파일 모두에 `-1차`, `-2차`처럼 같은 실행 번호를 붙여 주세요. 영상은 선택 사항입니다.

## 비교 기준

| 완료 표시 집계 구간 | MMC666 실기 | MMC690 |
|---|---:|---|
| 5–40초, 35초 | 687회 / **19.63 fps** | 반환 로그로 계산 |
| 40–55초, 15초 | 290회 / **19.33 fps** | 반환 로그로 계산 |
| 합계 5–55초, 50초 | 977회 / **19.54 fps** | 반환 로그로 계산 |

처음 5초와 마지막 5초는 성능 비교에서 제외합니다. 시작 실패·조기 종료는 정상 60초 실행과 분리해 진단합니다. 구현의 개선율과 플레이 작업량 차이는 함께 확인합니다.

689D는 전체 Quartus Lite FIT와 기존 보드 제약의 STA를 통과했습니다. 688 ARM·685 65816의 실행 코드를 유지하고 메뉴/경로/로그 이름만 MMC690으로 바꿨습니다. 두 시작 위상에서 951 공개선·955 선행 DMA·7블록 수신·952 표시 3회·957 최종 대기 0회를 유지했습니다. 이는 모델/RTL 검증이며 실기 FPS는 반환 로그로 판단합니다.

현재 LAB 여유는 0, ARM Flash 여유는 8B이고 최소 setup 여유는 +0.104ns입니다. 기존 외부 IO 전체 검증은 미완료여서 이전과 같은 보드의 제한 실기 시험입니다. 게임 ROM·기존 세이브·백업은 변경하지 않습니다.
