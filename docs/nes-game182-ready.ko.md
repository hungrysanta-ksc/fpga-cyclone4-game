# NES182 — DMA 전송 성능 비교 시험

이번 시험판은181에서 정상화된 첫 레벨 표시·사운드·메뉴 복귀를 유지하면서, MCU의 바이트별 전송을 DMA로 바꾼 판입니다. **60fps 달성판이라는 뜻은 아닙니다.** 같은 속도의 SPI에서 소프트웨어 대기를 줄이는 변경입니다.

1. 전원이 꺼진 상태에서 `01-GAME182-SD-ROOT` 안의 내용을 SD 루트에 복사합니다.
2. 메뉴에서 `NES GAME 182.nh1`을 실행합니다. ROM 적재·검증은 그대로여서 이전처럼 수분 걸릴 수 있습니다.
3. 플레이어 선택→월드맵→숫자1타일에서 A로 첫 레벨에 들어가 이동·점프·스크롤을 확인합니다. 화면 시작부터 약60초 뒤 자동 복귀합니다.
4. 메뉴 복귀 후 전원을 끄고 `sd2snes/nes-progress-182.txt`, `sd2snes/nes-game-last-182.txt`를 보내 주세요. 가능하면 게임 화면20~30초 영상도 함께 확인합니다. 화면 부드러움·소리·메뉴 복귀 여부가 핵심입니다.

게임이 시작된 뒤90초를 지나도 복귀하지 않으면 더 오래 기다릴 필요는 없습니다. 전원을 끄고 남아 있는 로그와 증상만 알려 주세요. 전송 오류가 공유 안전 정지로 이어지면 마지막 로그가 없을 수 있습니다.

정상044 복원 시험은 반복할 필요 없습니다. `02-RESTORE164-SD-ROOT`는 기존 복원 자료 그대로 보존했습니다. 세이브 파일을 지우거나 세이브SRAM을 작업공간으로 쓰지 않습니다.
