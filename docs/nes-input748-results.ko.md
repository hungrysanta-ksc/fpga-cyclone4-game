# 748 · 마지막 map 반환 때의 입력 조회 한 번을 OAM 반환 뒤로 이동

727을 유지한다. 두 위상 모두 905의 map 22개 발행 시각과 952·957의 1,536B 선행 DMA를 지켰다. 957 OBJ는 긴 map DMA 도중 이미 큐에 도착했다. 같은 VBlank의 257선까지 OBJ DMA를 시작하지 못했고, 952–957의 밀집 표시 간격과 957 최종 ACK도 함께 줄지 않았다.

## 실제 변경

727의 seal 루프는 마지막 warm map의 E0 반환을 검사하고 DMA 진행 비트가 없으면 reason 4로 입력을 한 번 조회한다. 마지막 BG descriptor가 48B이고 실제 enqueue 경로를 사용하는 경우, 그 루프에서 첫 조회 한 번만 보류한다. 그 자리에서 STOP을 검사하고 이후 E0·입력 조회·마감은 기존 루프에서 처리한다. 재사용 OAM이나 전체 OAM의 발행이 끝나면 최신 패킷이 section 4인지 확인한다. 기존 drain이 카운터·CRC·최신 ACK identity를 검증한 뒤 빈 큐에서 원래 입력 콜백을 한 번 실행한다. 오류는 해당 프레임의 최종 표시 승인을 막는다. 시각·세대에 따른 예외와 고정 지연은 사용하지 않았다.

707D 보드와 694의 5,120B 프로그램 ROM을 사용했다. 실제 65816의 MDMAEN 쓰기와 빔 위치만 관찰했고 WRAM 실행 코드를 주입하지 않았다. 747에서 사용한 E0 재조회 변경·CRC 변경·OBJ 64B 전송 루틴을 이 후보에 가져오지 않았다.

## 957의 수신과 DMA

| 실제 사건(마스터클록) | 위상 1 | 위상 2 |
|---|---:|---:|
| 1,536B map MDMAEN | 65,362,724 | 65,720,630 |
| ARM의 OBJ 발행 완료 | 65,370,174 | 65,727,361 |
| map의 마지막 VRAM 쓰기 | 65,375,440 | 65,733,304 |
| 65816의 OBJ 패킷 읽기 시작 | 65,377,480 | 65,735,346 |
| OBJ 수신 ACK 공개 | 65,394,852 (259선) | 65,752,718 (260선) |

OBJ는 map 종료보다 5,266 / 5,943클록 먼저 도착했지만, 65816은 종료 뒤 2,040 / 2,042클록에 읽기를 시작했다. 그때부터 수신 ACK까지 두 위상 모두 17,372클록이 들었다. 694의 늦은 타일 경로는 최대 160B를 받아들이고, 실제 288B descriptor는 전체 전송을 다음 VBlank에서 실행했다. 957 마지막 map 반환 뒤 OBJ 발행 전 입력 조회 수는 727의 5 / 4회에서 4 / 4회가 됐다. 반복 횟수는 응답과 마감에 따라 달라진다. 두 위상 모두 OAM 수신 ACK와 일치하는 E0를 검증하고 보류한 조회를 한 번 수행했다.

별도 대조에서는 727의 521개 map 시각과 후속 패킷을 고정하고 실제 빈 입력 콜백 한 번에 해당하는 2,183 마스터클록만큼 957 OBJ·OAM을 앞당겨 같은 ROM에서 재생했다. 두 위상의 공개 시각·최종 ACK 모두 727과 같았다. 이 대조는 발행 시각의 효과를 분리한다. 전체 링크 표에는 실제 재조회·OAM 반환·미뤄 둔 입력 처리 비용을 포함했다.

## 자원과 복구

- 장시간판 212,844B, 60초판 212,888B로 ARM Flash 여유는 148 / 104B다. 727에 있던 240B 영 패딩을 초기값 0인 RAM으로 옮긴 비용이 두 판 모두 BSS +240B다. 장시간판의 같은 배치 대조군은 212,708B로 조회 이동 자체의 Flash 차이는 +136B다.
- 65816 ROM은 727과 동일하고 26B 여유다. FPGA RTL 변경이 없어 Quartus 재합성은 수행하지 않았다.
- 각 전체 링크에서 재사용·전체 OAM, 다른 BG, STOP·실패한 반환·잘못된 section 등 8조건, 기존 마감·최종 ACK 17조건과 메뉴·base 복구 5경로를 확인했다. 두 위상의 실제 65816 재생에서 STOP과 오래된 OAM identity는 956 화면을 보존했다. 긴 map DMA 중 새 head를 공개하자 두 위상 모두 다음 DMA보다 먼저 그 OBJ 패킷을 읽었다. 실기 측정이나 설치본은 없다.
