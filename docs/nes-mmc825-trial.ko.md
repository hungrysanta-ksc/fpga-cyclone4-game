# MMC825 모험도 4 무입력 데모 · 60초판

1. 전원을 끈 상태에서 ZIP의 `MMC825-ADVENTURE-60SEC-SD-ROOT` 안의 내용물을 SD 루트에 복사하고 기존 파일을 덮어쓴다.
2. MMC820·824에서 사용한 일본판 모험도 4 원본을 `sd2snes/nes/mmc825.nes`로 복사한다. SHA-256은 `9d7402da135fd1290346ccc9332836daee3a9a3cda3789999c3f86efdb5b19c2`다.
3. SD 메뉴의 `NES MMC3 825.nh1`을 선택하고 버튼을 뗀다. 약 25–30초에 타이틀에서 스테이지 데모로 전환되는지, 게임 화면이 계속 갱신되고 약 60초에 메뉴로 돌아오는지 확인한다.
4. 복귀 후 SD의 `sd2snes/`에서 `nes-progress-mmc825.txt`, `nes-budget-mmc825.txt`, `nes-game-last-mmc825.txt`를 보관한다. 일찍 복귀하면 마지막 장면과 함께 세 파일을 남긴다.

60초를 완료하면 같은 무입력 기준인 MMC820의 5–40초 15.51 FPS 및 40–55초 16.20 FPS와 비교한다.
