# 761 · 955 최종 ACK 이후 65816 유휴 행 검사

## 목표

753의 957 오른쪽 페이지에서, 955 최종 ACK 뒤 시행한 사전 검사가 검사 후 WRAM 손상까지 검출하면서 957 검사·범위 등록·ACK를 0.797ms 안으로 줄이는지 판정한다.

## 작업내용

- 753 패킷 도착 시각과 751 수신기를 재생했다. 두 위상 모두 954까지 원본 이벤트가 일치했다. 955부터 진단용 65816 코드를 WRAM에 설치하고 대상 뱅크 0의 192B map 패킷 8건에서 순서와 길이를 확인하고 독립 참조용 두 합계를 계산했다. 성공한 최종 ACK strobe 이후에만 해당 뱅크·32비트 serial에 이력을 결합했다.
- 큐가 비면 STOP과 새 head를 다시 읽고 32B씩 대상 WRAM을 읽어 별도 1,536B에 복사하며 합계를 누적했다. 48번째 조각까지 끝나고 송신 바이트에서 계산한 두 합계와 일치해야 READY가 된다. 32B는 최대 하나의 중단 불가 작업 단위다. 반대쪽 뱅크의 쓰기는 개입하지 않으며, 겹치는 일반 map 쓰기·STOP·오류는 이력을 무효화한다.
- 957은 760의 직접 위치 형식(231B)을 재사용했다. 대상 뱅크와 serial을 독립 확인한 뒤 **첫 변경 쓰기 전에** READY와 serial을 지운다. 34개 그룹을 적용하며 진단 미러에도 예상 값을 기록한다. 복원 후 실제 WRAM 1,536B를 미러와 대조하고 패킷의 두 합계를 검사한다. 64B마다 STOP을 확인한다. 실제 coverage·DMA descriptor 등록 성공이 최종 패킷 반환의 전제다.
- 정상 재생 두 건에서 53개 화면의 WRAM·VRAM·RGB가 원본과 일치했다. 위상 2에서 ① READY 후 마지막 생략 그룹의 WRAM 1비트 ② 동일 위치의 미러 1비트 ③ 첫 4B 변경 직후 STOP을 각각 주입했다. ①②는 0xE0, ③은 0xE4로 종료했고 모두 52개 커밋과 956 화면을 유지했다. STOP 진입 시 READY·serial이 이미 지워졌으며 957 표시 ACK를 공개하지 않았음을 확인했다.

## 성과

| 계측 구간 (ms) | 위상 1 | 위상 2 |
|---|---:|---:|
| 955 최종 ACK 지연, 753 대비 | +17.481 | +17.470 |
| 955 최종 ACK → 행 이력 READY | 41.019 | 41.019 |
| 유휴 검사 48개 조각 실행 시간 합 | 12.653 | 12.644 |
| READY → 957 map head 수락 여유 | 16.849 | 17.139 |
| 957 수락 → 복원 완료·검사 진입 | 3.079 | 3.075 |
| WRAM·미러 대조 및 합계 검사 | 12.971 | 12.971 |
| 마지막 STOP 확인·범위 등록·ACK | 0.776 | 0.778 |
| **957 검사 진입 → 패킷 ACK** | **13.747** | **13.748** |

사전 검사는 두 위상 모두 묶음 수락 전에 끝났다. 그 참조를 만들기 위해 955에서 받은 패킷을 읽은 비용도 실제 일정에 포함했다. 초기 16B 단위 구현은 957 진입 때 1,456B만 끝나서 두 위상 모두 안전하게 거부했다. 최종 32B 구현의 가장 긴 단일 조각은 0.277 / 0.277ms였다.

위상 2의 기준은 760의 전체 수락→반환 허용 3.060ms에서 760의 진입·복원 비용을 뺀 0.797107ms다. 761의 검사·등록·ACK는 이를 **12.951ms 초과**했다. 미러 갱신 등으로 761의 진입·복원만도 3.075ms가 걸렸다. 동일 복원 완료 시각에서 최종 재대조를 건너뛴 진단 대조군은 0.784085ms로, 기준에서 실제 손상 검사에 남는 시간은 약 13µs였다. 사전 검사와 쓰기 이력만으로는 그 사이 발생한 WRAM 비트 변화를 알아낼 수 없다.

753을 유지한다. 비용 선행 조건에 미달해 새 ARM 발행·공유 SPI·ROM 경쟁을 연결한 첫 248선 반환, 957 표시 2회, 밀집 간격·최종 ACK 판정은 진행하지 않았다. 기존 753의 STOP·메뉴 경로를 유지했다. 진단 코드는 1,321B, 미러는 1,536B이며 실기용 링크·설치본·신규 FIT 대상이 아니다.

## 후속작업

753의 1,536B 단일 DMA를 기준으로 실제 VRAM 전송 중의 바이트를 65816 재순회 없이 독립 검증할 수 있는지, 보드에서 관측 가능한 버스 신호와 마지막 바이트부터 표시·최종 ACK까지의 소유권으로 먼저 판정한다. 행 이력만 신뢰하거나 957에서 전체 WRAM 비교를 되풀이하는 후보는 제외한다. 보드가 실제 전송 데이터를 볼 수 없다면 이 경로를 닫고 753의 기존 검사와 DMA를 유지한 채 입력·ROM 공급 마감을 다시 본다.
