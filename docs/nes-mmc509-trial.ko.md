# MMC509 — 압축 입력·일반 packet 선행 공급 확인본

정상 동작한 MMC502와 같은 슈퍼마리오3로 비교한다. 입력의 같은 값 묶음을 압축하고, tile ROM 대기 중 일반 packet을 공급한다. 준비된 bulk와 credit 처리가 우선이다. 독립 검사·STOP·최종 ACK·VBlank와 약60초 자동 메뉴 복귀 경로를 유지했다. **60fps 달성판이 아니며, 실기 성능과 메뉴 복귀는 이번에 확인한다.**

## 설치

1. 전원을 끄고 ZIP의 **`01-MMC509-SD-ROOT` 안의 내용물 전체**를 SD 루트에 복사한다. 폴더 자체를 복사하지 않는다. 새 firmware와 FPGA 파일을 함께 적용한다.
2. 기존 정상 실행한 `sd2snes/nes/mmc502.nes`를 **`sd2snes/nes/mmc509.nes`**로 복사한다. 이름만 변경한다. 게임 ROM은 포함하지 않았다.
3. **`NES MMC3 509.nh1`**을 실행한다. 첫 레벨에서 이동·점프·스크롤을 확인하고 약60초 자동 메뉴 복귀까지 기다린다.

대상 ROM은393232바이트, CRC32 `5a04eed7`인 기존 원본이다. 새 문양 ROM이나 다른 판본으로 바꾸지 않는다. 요청대로 RESTORE 폴더는 넣지 않았다. 복구가 필요하면 전원을 끄고 보관 중인 MMC502 백업을 사용한다. 사용자 세이브 파일은 포함하지 않았다.

## 비교와 로그

가능하면 MMC502와 MMC509를 같은 첫 레벨·비슷한 동선으로 각각 실행한다. 메뉴 대기와 실제 플레이를 서로 비교하지 않는다. 기준 실행이 어렵다면509의 정상 실행·입력·화면·메뉴 복귀부터 확인한다.

- `sd2snes/nes-progress-mmc509.txt`
- `sd2snes/nes-budget-mmc509.txt`
- `sd2snes/nes-game-last-mmc509.txt`

실행별로 로그를 보존한다. 반복 실행하면 같은 이름의 로그가 덮어써진다. 첫 레벨 진입 여부와 체감 변화, 화면 깨짐·멈춤 여부를 함께 알려주면 된다. 영상은 이상이 있거나 비교 동선을 남길 때 도움이 된다.

## 확인 범위

ARM의 진행·완료 처리와 전송 순서를 검증하고 실제65816의12개 최종 화면이 같은지 비교했다. 실제 NES CPU·PPU·MMC3·ROM 중재의 부팅 구간 시험과 게임 capture를 이용한 연속 일정 모형은 범위를 구분한다. 부팅 ROM 허용 시각을 재생한 비교를 실제 첫 레벨 FPS로 환산하지 않는다.

전달용 ARM은 시험한509 실행 함수와 주소·크기·명령이 같고 메뉴·ROM·FPGA·로그·버전 문자열만 바뀐다. Flash 잔여36B, BSS18576B다. FPGA는507의 source와 FIT/관련 timing 결과를 그대로 사용한다.15164LE/51M9K, 관련 setup+0.078ns/hold+0.139ns다. 전체 reset/CDC/외부IO와 IRQ 최대 stack 승인 및 새 실기 성능은 아직 아니다. profile7b/status3/client ABI4891을 유지하며 입력 압축 ABI는2233이다. 기존502 firmware와 새 FPGA를 섞지 않는다.
