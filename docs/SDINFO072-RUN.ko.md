# SDINFO072 외부 실기 정보 수집

이 패키지는 **FXPAK Pro Mk.III Rev.D / STM32F401RCT6**의 SD 파일 정보를 수집하는 시험용 펌웨어다. CPU/PPU 게임 실행과 CF68 FPGA 설치는 진행하지 않는다. 실물 실행은 아직 확인하지 않았으며, 정상 저장 뒤에도 메뉴로 복귀하지 않고 수집 결과 화면에서 멈춘다.

## 1. 원본을 먼저 보관

1. 전원을 끄고 SD를 분리한다. 게임·GBC·세이브를 포함한 SD 전체를 별도 저장장치에 백업한다. 가능하면 여분 SD의 복사본으로 진행한다.
2. **교체 전** `/sd2snes/firmware.stm` 원본을 독립 백업에 보관하고, 같은 SD의 `/sd2snes/firmware.before-sdinfo072.stm`에도 복사한다. 이미 이 이름이 있으면 덮어쓰지 말고 어느 원본인지 먼저 확인한다. 새 진단 펌웨어를 이 백업 이름으로 복사하면 원본 확인이 무의미해진다.
3. 원본 `fpga_base.bi3`, `m3nu.bin`, 기존 진단 로그도 독립 백업에 보관한다. 복사 전후 크기·SHA256 또는 모든 바이트를 대조한다. SD 안의 사본만으로 독립 백업이 완료되지는 않는다.

## 2. 펌웨어 하나만 교체하고 실행

`FXPAK-SDINFO072-SD.zip`의 `sd2snes/firmware.stm` 하나를 SD의 같은 위치에 복사한다. 크기 **132768바이트**, SHA256 **8215d81dd84a07f3dfffe5163163c07ef1166fcbfab25b95cbc4942dbc42f724**다. `fpga_base.bi3`, `m3nu.bin`, 게임·세이브·다른 FPGA 파일은 교체하지 않는다. 대응 소스는 별도 `FXPAK-SDINFO072-SOURCE.zip`으로 제공한다.

SD를 실기에 넣고 켠다. 예상 화면은 `SDINFO072 READ ONLY INPUTS` → `READING SD - WAIT FOR TXT` → `TXT SAVED + READBACK OK`, `/HW003nnn.TXT`, `Save code: 0`이다. 1→2→3 화면 순환이나 게임 메뉴는 이 수집기의 동작이 아니다. 화면 이름·저장 코드·대략적인 소요 시간을 함께 기록한다.

하위 SD/SPI/TIM2/FatFS 오류와 수집 예산 초과는 RESET/USB를 보호 상태에 둔 채 멈춘다. 이 경우 TXT가 없을 수 있다. 논리적인 파일 오류는 TXT에 상태로 남을 수 있고, 저장 실패는 `TXT SAVE FAILED`로 표시한다. 저장 코드 1=형식, 2=열기, 3=1000개 이름 소진, 4=쓰기, 5=동기화, 6=닫기, 7=재읽기, 8=공유 오류/예산. 부분 TXT가 생겨도 완료한 보고서로 취급하지 않는다.

수집 예산은 SysTick100Hz의 6000tick(60초) 및 100만 poll이다. 초기 파일/하드웨어 초기화와 내장 mini 화면 준비는 이 예산 이전의 기존 코드이며, 전체 전원 투입 시간이 60초 이내라고 보장하지 않는다. 2분이 지나도 완료 화면이 없으면 전원을 끄고 관측 내용을 전달한다. 멈춘 상태에서 메뉴·게임을 시도하지 않는다.

## 3. TXT 전달 후 원본 복원

전원을 끈 뒤 SD 루트에 새로 생긴 **`HW003000.TXT`부터 `HW003999.TXT` 중 이번 파일**을 복사해 전달한다. 기존 보고서는 덮어쓰지 않는다. 화면 사진이나 시간·코드도 있으면 함께 전달한다.

다시 게임을 실행하기 전에 **독립 백업의 원본**으로 `/sd2snes/firmware.stm`을 복원하고 파일 크기·SHA256/전체 바이트를 대조한다. 전원을 다시 켜 원래 메뉴와 GBC가 정상인지 확인한다. 정상 복원 관측은 별도로 알려준다. PC가 실기에 직접 연결될 필요는 없다.

## 수집 결과의 의미

원본 사본·실행 중 펌웨어·기본 FPGA·메뉴의 크기/전체 CRC, STM3 본문 CRC, FPGA RLE 복원 길이/CRC, 메뉴 후보 헤더 6개와 reset byte를 담는다. 입력은 읽기 전용이며, 출력 TXT는 새 파일 생성·sync·close·재열기·전체 바이트 대조를 거친다.

`TXT SAVED`는 입력 파일 모두의 승인이나 메뉴 호환성·실제 독립 백업/복원·NES 실기 성공을 의미하지 않는다. CRC는 일관성 검사이며 SHA256/인증을 대신하지 않는다. 실제 메뉴 분류 코드 대조와 CF68 외부 조건 검토는 TXT를 받은 다음 단계다. **071 NES 쌍의 installable=false 상태는 그대로다.**
