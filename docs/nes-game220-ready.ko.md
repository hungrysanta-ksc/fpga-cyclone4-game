# NES220 정상 대기 수정·게임 재시험

215에서 스테이지 선택으로 넘어갈 때 발생한 조기 종료와 같은 오류를 로컬에서 재현하고, 정상적인 ROM 승인 대기·화면 소비 대기를 실행 시간 초과로 오판하는 부분을 수정했습니다. FPGA 전체 타이밍과 현재 SNES 출력 ROM 결합 검사를 마친 실기 시험판입니다. **실기 해결이나60fps 달성을 확인한 판은 아닙니다.**

1. 전원을 끈 상태에서 `01-GAME220-SD-ROOT` **안의 내용**을 SD루트에 복사하고 `NES GAME 220.nh1`을 실행합니다. 펌웨어와FPGA를 함께 교체합니다.
2. 플레이어 선택→스테이지 선택→숫자1 타일에서A로 첫 레벨에 들어갑니다. 진행되면 오른쪽+B를 누른 채A를 반복해 스크롤을 확인합니다. 프레임이 낮아 죽는 경우 그대로 진행하며 어느 장면이었는지만 알려 주세요.
3. 오류가 없으면 게임 시작 후 약60초에 메뉴로 복귀합니다. 로딩 시간은 별도이며 이번 변경의 개선 대상이 아닙니다. 게임 화면 진입 후90초가 지나도 복귀하지 않으면 전원을 껐다 켜고 남은 로그를 보관해 주세요.
4. `/sd2snes/nes-progress-220.txt`, `/sd2snes/nes-game-last-220.txt`, `/sd2snes/nes-budget-220.txt` 세 파일과 메뉴 복귀·소리·조작·첫 레벨 진입 여부를 알려 주세요. 파일이 일부만 생기면 있는 것만 전달하면 됩니다.

진행이 정상이라면 영상은 게임 화면이 뜰 때부터 촬영하면5초 구간별 로그와 실제 스크롤을 맞추는 데 도움이 됩니다. 같은 조기 종료라면 영상은 필수가 아닙니다. 동일215/044 반복·복원 시험은 필요 없습니다. 기존 시험판과 이번 ZIP의164복원 폴더는 보관해 주세요.

정상 전송 중 새 SD쓰기를 추가하지 않았습니다. 승인된 읽기의 미응답·주소/세대 오류·STOP 보호와60초 종료는 유지하고, 정상 backpressure를 타일 실행 시간에서만 제외했습니다. 로그는 기존 종료 경로 뒤에 작성하므로 전원 차단이나 종료 경로 실패 시 마지막 파일이 없을 수 있습니다. 저장SRAM과GBC164는 변경하지 않았습니다.
