# 550. 957의 DMA 진행과 246행 마감

549 연속 OBJ 후보의 ARM을 고정하고 65816의 SEAL 업로드 루프만 바꿨다. 952의 5 VBlank를 유지하면서 두 번째 위상에서 281 master clock 늦었던 957의 최종 검사를 제시간에 마치는 것이 목표다.

## 957에서 늦어진 구간

957의 전체 PPU DMA는 3,584B다. 549 세 행 후보는 두 위상 모두 SEAL 전에 528B를 보냈지만 연속 OBJ 후보의 두 번째 위상에서는 400B를 보냈다. 이때 업로드 중 두 번째 DMA가 576B에서 704B가 됐다. 첫 DMA 시작에서 최종 검사 함수 진입까지 정확히 1,024클록 늘었으며, 이는 128B의 DMA 시간과 일치한다. 검사 함수 진입에서 빔 latch까지는 1,128클록으로 같았다.

기존 65816은 일반 명령마다 목록에서 목적지를 읽어 compact raw 주소인지 검사하고 DMA 설정 시 같은 목적지를 다시 읽었다. 다음 명령의 목록 위치도 WRAM에서 다시 읽었다. 550은 16비트 A에 있는 목적지를 주소 판별과 VRAM 설정에 함께 쓰고, 일반 명령 사이에서는 X에 다음 위치를 유지한다. WRAM의 진행 위치는 매 명령 뒤에 기록한다. VBlank 대기와 raw 서비스는 X를 바꿀 수 있어 그 경계에서만 다시 읽는다. 두 raw 목적지의 모드 검사, 실제 DMA, raw의 STOP 서비스, 최종 246행 검사와 표시 ACK를 보존했다. 본문은 4,956→4,954B다.

## 동일 도착 시각 대조

549 연속 OBJ의 두 PUSH 기록을 각각 새 65816에 고정 재생했다. 위상 1은 같은 일곱 DMA를 같은 크기로 실행하면서 첫 DMA→검사 진입이 27,160→26,472클록으로 688클록 줄었다. 위상 2는 같은 입력 도착 시각에서도 128B를 SEAL 전에 보낼 기회가 생겨 28,184→26,472클록으로 1,712클록 줄었다. 이 가운데 1,024클록은 DMA 위치가 앞당겨진 몫이다. 두 위상의 957 latch는 246행 h=182 / 186이었고 최종 대기는 0회였다. 이 고정 재생에서는 ACK 시각이 다음 입력 발행을 바꾸지 않는다.

550의 밀집 합계는 28 / 28 VBlank다. 549 세 행 대비 마지막 ACK는 0.042 / 16.615ms 빨라졌다. 같은 5–55초 집계만 적용한 MMC540 대비 밀집 평균은 6.663 / 9.981ms 단축됐다. 첫 BG가 549 연속 OBJ보다 늦은 상대 ROM 구간으로 밀린 세대는 없었으며 952·954 최종 대기도 0회였다.

위상 2에서 957은 549 연속 OBJ와 같은 400B를 SEAL 전에 보냈고, 첫 DMA→최종 검사 진입이 28,184→27,544클록으로 640클록 줄었다. 빔 읽기 콜백은 247행 h=0을 기록했다. 같은 PUSH를 별도로 재생하고 실제 65816의 `CMP #247` 직전 누산기를 읽어 보니 위상 1은 **245**, 위상 2는 **246**이었다. 기존 검사를 그대로 통과했으며, 위상 2의 시간을 넉넉한 마감 여유로 볼 수는 없다.

두 위상 각각 53개 화면에서 RGB·map·tile·최종 ACK, ROM 읽기 5,616회, VRAM DMA 114,352B와 두 bulk 슬롯을 대조했다. 독립 재생은 CPU 이벤트·시각과 RGB를 재현했다. 별도 8화면 raw 개수·마스크 검사, SEAL·raw STOP 7건, 양 뱅크의 부분 수신·DMA 취소 후 전체 6행 복원 6건을 통과했다. 사용한 ROM 허용표는 부트 코어에서 기록한 8프레임을 반복한 것이며 실기 FPS는 MMC551 로그로 확인한다.

## 제한 실기 전달

MMC551은 550 소비 ROM과 549 연속 OBJ ARM을 사용한다. 이름만 바꾼 ARM에서 모든 실행 함수의 바이트가 동일하며 Flash 212,720B, 여유 272B, BSS 18,592B다. 정상 메뉴 복귀와 program·done·busy·token 오류 차단, 5–40초·40–55초의 끝점과 미완료 화면 제외를 전달 ELF에서 검사했다.

73개 보드 입력 중 소비 ROM만 달라졌다. Quartus Lite 전체 FIT는 15,164 LE, 조합 14,172개, FF 8,394개, RAM 264,816비트와 M9K 51개다. 구현·명목 관련 setup / hold는 +0.078 / +0.139ns다. 전체 STA 요약과 미제약 포트 수는 MMC540과 같다. 전체 최저 setup −7.081ns와 recovery −8.480ns를 포함한 기존 제한 실기 기준으로 판정했다.
