# NES177 — 화면 정지 경계 확인

174에서 마지막 화면 이후 다음 전송이 시작되지 않는 이유를 구분하는 시험판이다. 기존 로그에 수집·소유권·전송·공유 메모리 상태를 담는다. **화면 정지나 끊김을 고쳤다는 뜻은 아니며, 같은 증상이 재현되어도 필요한 시험 결과다.**

1. `NES177-SMB3-BOUNDARY.zip`의 `01-GAME177-SD-ROOT` 안 내용을 SD 루트에 덮어쓴다. 펌웨어와 FPGA를 함께 적용한다.
2. 메뉴에서 `NES GAME 177.nh1`을 한 번 실행한다. 기존 ROM 적재 절차는 유지하여 로딩에 수분 걸릴 수 있다.
3. 가능하면 스타트로 진행한다. 화면이 멈춰도 음악·버튼 반응이 남는지 확인하고, 표시 준비 후 약 60초의 자동 메뉴 복귀까지 기다린다.
4. 메뉴 복귀 뒤 `sd2snes/nes-progress-177.txt`와 `sd2snes/nes-game-last-177.txt`를 전달한다. 화면·음악·입력·메뉴 복귀 상태도 알려준다. 이전과 같은 증상이면 영상은 없어도 된다.

메뉴 실행부터 6분이 지나도 복귀하지 않으면 전원을 끄고 남은 로그를 복사한다. 정상 사용으로 돌아갈 때는 `02-RESTORE164-SD-ROOT`를 사용한다. 044 복원 검증은 반복하지 않는다.

게임·메뉴·164 복원 파일은 174 패키지와 동일 바이트다. 실행 중 SD 쓰기와 세이브 SRAM 영상 버퍼 사용은 없다. 로그는 정지 뒤 기록한다. 기존 시간 계측은 유지하며, 마지막 16개 기록은 16프레임이 아니라 **정지 시점에 가까운 NES 클록 표본**이다.
