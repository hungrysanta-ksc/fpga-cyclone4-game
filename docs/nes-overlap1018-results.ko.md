# MMC1018 실험 — 23행 화면에서 일반 패킷과 OBJ 뱅크 반환 겹치기

MMC1012를 실기 기준으로 유지한다. 23행 화면의 확정 패킷 3개를 마지막 OBJ 뱅크 반환 전에 모두 SPI로 보냈다. SEAL 수락은 앞당겼지만 두 시작 위상 모두 화면은 같은 VBlank에 공개됐다.

## 무엇을 비교했나

MMC1012 ARM을 기준으로 201B만 선행, 201B·240B·116B 모두 선행, 같은 세 패킷에 기존 큐 credit 사용, map 머리 192B를 먼저 발행하고 세 패킷을 보내는 네 경우를 각각 최종 링크했다. 201B와 240B는 section 5, 116B는 OAM 재사용 명령이다. 대상 뱅크의 ACK 이력과 재사용 조건을 확인하고, 동일한 독립 검사·retire·STOP을 거친다. FPGA·65816은 MMC1012를 사용했다.

모험도 4의 연속 원본 화면 3450–3478에서 8개 캡처를 재생했다. ARM과 65816을 함께 실행하고, 동일 ROM 허가 일정에서 두 시작 위상을 비교했다. 대조군의 두 계측 실행은 기존 MMC1012 재생과 일치했다. 아래 수치는 원본 3462에 해당하는 세대 908이다. 23행·BG 526·OBJ 46·실제 공급 타일 14개였다. 이전 실기의 세대 1499·1531은 23행·BG 521·OBJ 17·공급 타일 15개였다. 해당 세대에는 패킷별 원본이 남아 있지 않다. 이전의 3.93·2.76ms는 실기와 별도 ROM 허가 재생을 조합한 부족분 추정치이므로 이번 측정과 합산하지 않았다.

## 두 위상의 결과

양수는 MMC1012보다 빠르고 음수는 늦다. 시간 단위는 ms다. DMA 종료는 마지막 PPU 데이터 쓰기, 공개는 화면을 켜는 PPU 쓰기, ACK는 그 뒤의 표시 확인이다.

| ARM 발행 방식 | SEAL 수락 개선 ① / ② | DMA 종료 개선 ① / ② | 세대 908 최종 ACK 개선 ① / ② | 공개 간격 ① / ② |
|---|---:|---:|---:|---:|
| 201B만 선행 | +0.338 / +0.503 | −0.086 / −0.069 | −0.086 / −0.067 | 2 / 2 |
| 세 패킷 선행 | +0.740 / +0.958 | −0.092 / −0.075 | −0.092 / −0.073 | 2 / 2 |
| 세 패킷 선행 + 기존 credit | +0.513 / +0.435 | −0.059 / +0.012 | −0.060 / +0.014 | 2 / 2 |
| map 192B 먼저 발행 | +0.250 / +0.475 | −0.018 / −0.115 | −0.018 / −0.113 | 2 / 2 |

기존 credit을 활용한 경우 두 위상에서 마지막 116B까지 SPI 전송이 OBJ 반환보다 0.458 / 0.413ms 먼저 끝났다. 65816은 201B·240B를 반환 전에 수락했고, 116B는 반환 후 0.082 / 0.081ms에 수락했다. 큐 전송 완료와 소비 순서를 분리해 관측했다.

대조군은 VBlank 38에서 map 768B와 192B를 DMA했다. 세 패킷을 먼저 보낸 경우 192B가 다음 VBlank로 밀렸다. 192B 발행을 앞세운 경우 위상 1은 245선에 해당 DMA를 시작했으나 위상 2는 이 기회를 놓쳤다. 네 후보 모두 잔여 DMA는 VBlank 39에 종료됐다. map 머리 선행에서 연속 재생의 마지막 세대 912 ACK가 0.114 / 0.068ms 빨라졌지만, 목표인 세대 908 공개는 두 위상 모두 그대로였다.

## 보존 조건과 다음 작업

각 후보·위상에서 8세대의 일반 패킷 내용, 타일 token·데이터, 출력 map과 화면 해시가 대조군과 일치했다. 재생에서 배정된 ROM 읽기는 모두 3,136회였다. 실기 15타일 표본의 캐시 적중 수는 이번 재생에서 다시 측정할 수 없다. ARM Flash는 212,884–212,980B로 모두 212,992B 한도에 들어갔다. 네 링크 모두 SRAM 송신·retire·메뉴 해제와 base 복구 시험을 통과했다. 잘못된 SEAL과 복원 중 STOP에서는 이전 화면을 보존했다. 메뉴 복귀 시험은 실제 ARM 코드와 모델링한 외부 보드를 사용했다.
