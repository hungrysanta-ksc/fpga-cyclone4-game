# C44 호환성 기록

2026-10-04 C44 로그 OFF 최종 검사까지 사용자가 보고한 실기 결과입니다. C44에서는 요청된 시작·폴리오·메뉴/배속·저장/복원·리셋·로그 미생성 검사가 정상이라고 확인했습니다. 게임 전체 클리어, 모든 지역판, 모든 강제 저장 슬롯의 검증을 뜻하지 않습니다. 이전 후보에서 통과한 검사는 당시 범위로 기록하며 C43에서 전부 다시 했다고 확대하지 않습니다.

## 지원 경계

구현된 주요 매퍼는 MBC1/MBC1M, MBC3, MBC5입니다. MBC3는 7비트 ROM 뱅크 및 RAM 0~3 뱅크와 RTC 08~0C를 처리합니다. 일반 ROM-only 경로도 있습니다.

**일본판 크리스탈의 실행 성공과 MBC30 완전 지원은 별도입니다.** MBC30의 추가 ROM/RAM 주소 범위를 이번에 구현한 것은 아닙니다. 해당 성공은 그대로 기록하되 64KiB 전체 저장 영역, 장시간 진행·전체 클리어를 보증하지 않습니다.

MBC2/HuC1/HuC3/MBC7/카메라 등은 로더가 헤더를 식별하는 것과 실제 FPGA 지원을 구분해야 합니다. 통신, 적외선, 센서, 진동, SGB 테두리·멀티플레이, 치트는 지원 범위 밖입니다.

현재 표본에서 알려진 미해결 공통 실행 결함은 보고되지 않았습니다. 무한히 상용 게임 목록을 늘리는 대신 이 범위를 배포 안내에 명시하고, 이후 재현 가능한 보고를 기준으로 수정합니다. 장시간 RTC 날짜 전환과 다양한 기기 조합은 추가 검증 범위입니다.
