# MMC1024 별의 커비 무입력 60초 실기판

MMC1023은 커비 ROM 768 KiB를 적재한 뒤 읽기 검증 중 129번째 진행 기록에서 중단됐다. MMC1024는 진행 기록을 최대 256개까지 허용한다. MMC1023의 속도와 같은 경우 ROM 검증 완료까지 약 7분 26초가 예상된다. 게임 실행 후 무입력 60초를 측정한다.

1. ZIP의 `MMC1024-KIRBY-60SEC-SD-ROOT` 폴더 내용을 SD 루트에 복사한다.
2. MMC1023에 사용한 일본판 커비 ROM을 `sd2snes/nes/mmc1024.nes`로 복사한다. 확인한 파일은 헤더 포함 786,448바이트이며 SHA-256은 `56901e11f6fe812e0a049c747fa0b0d6fc42a336c502ca94fb5282229853347d`다.
3. 전원을 켜고 **NES MMC3 1024.nh1**을 선택한 뒤 게임 입력 없이 기다린다. 60초 자동 종료와 메뉴 복귀를 확인한다.
4. 메뉴로 돌아오면 SD의 `sd2snes`에서 아래 네 파일을 PC의 `1차` 폴더로 복사한다. 첫 실행이 정상이면 같은 전원 시작 조건으로 한 번 더 실행하고 `2차`에 복사한다. 실행이 중단되면 다시 실행하기 전에 생성된 파일만 보관한다.

- `nes-progress-mmc1024.txt`
- `nes-budget-mmc1024.txt`
- `nes-game-last-mmc1024.txt`
- `nes-frame-mmc1024.bin`

각 실행에서 [1, 30)초의 공개 프레임 수를 29초로, [30, 60)초의 공개 프레임 수를 30초로 나눠 표시 FPS를 비교한다. 모험도 4 대조군은 MMC1012다.
