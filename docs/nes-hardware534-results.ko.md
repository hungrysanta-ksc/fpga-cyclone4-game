# MMC533 첫 레벨 실기 결과

사용자는 MMC529 때와 비슷하게 첫 레벨을 플레이했고 실행과 메뉴 복귀를 확인했다. 두 실행 모두 표시 관측 시간은 60.07초였다.

| 표시 완료 시각 | MMC529 | MMC533 | 변화 |
|---|---:|---:|---:|
| 1초 이상 40초 미만 (39초) | 461회 · 11.82fps | 467회 · 11.97fps | +6회 · +1.30% |
| 40초 이상 60초 미만 (20초) | 232회 · 11.60fps | 253회 · 12.65fps | +21회 · +9.05% |
| 전체 | 708회 · 11.79fps | 735회 · 12.24fps | +27회 · +3.81% |

집계에는 budget의 `display_1_40_60`을 사용했다. 두 구간 밖의 최초 1초에 두 실행 모두 15회가 표시됐다. 입력 commit 736회 중 최종 EA는 735회였고, 59.94초 이후의 미완료 입력은 표시 수에서 제외했다. 전송 실패·CRC 오류는 0건이며 STOP, base 복원, MENU_PREPARED를 확인했다.

전체 실행의 완료 표시당 수신은 20.00→19.95ms, 계획·공급은 16.06→16.17ms, 출력·최종 ACK는 48.10→44.97ms였다. 두 실행의 동선은 비슷하지만 입력과 적 배치가 동기화되지는 않았다. [MMC529 비교 기준](nes-hardware530-results.ko.md) · [원본 로그 해시와 집계](../analysis/hardware534-mmc533.json)

원본 세 로그는 저장소 부모의 `probes/nes-hardware534/run01`에 보존했다. `python tools/analyze_nes_hardware521.py --trial 533 --raw <로그 폴더> --out <결과.json>`으로 재현한다.
