# NES 1065 실기 확인

DEBUG와 RELEASE 중 하나를 선택해 ZIP의 `sd2snes` 폴더를 SD 루트에 덮어쓴다. SD 메뉴에서 기존 `.nes` 파일을 직접 선택한다. DEBUG는 로그를 기록하고 RELEASE는 시간 제한 없이 실행된다.

- **젤다 2 한글판**을 새로 실행하고 타이틀 그림과 음악이 함께 나올 때까지 입력을 기다린다. START로 게임에 들어간 뒤 기존 퀵세이브를 불러와 화면이 전환되는지 확인한다. 젤다 1·2의 기존 슬롯 형식은 1064와 같다.
- **Final Fantasy 1 & 2 (J)**의 선택 화면에서 각각의 게임으로 들어간다. FF1에서 게임 내 저장 후 코어 메뉴의 SRAM 저장을 실행하고, FF2에서도 다른 진행을 저장한다. SD 메뉴에서 ROM을 다시 선택해 두 게임의 기록이 함께 남는지 확인한다. 퀵세이브도 두 게임에서 서로 다른 빈 슬롯에 저장한 뒤 재실행해 각각의 장면으로 돌아갈 수 있다.
- 코어 메뉴는 `L+R+START`로 연다. `EXIT TO MENU`로 SD 메뉴에 복귀한다. DEBUG 로그는 게임을 바꾸기 전에 `nes-progress-debug1065.txt`, `nes-game-last-debug1065.txt`, `nes-frame-debug1065.bin`, `nes-stop-debug1065.bin` 중 생성된 파일을 게임별로 복사해 둔다.
