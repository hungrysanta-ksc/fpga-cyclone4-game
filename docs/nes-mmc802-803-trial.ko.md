# MMC802 · MMC803 중간 성 재시험

MMC802는 60초 뒤 자동으로 메뉴에 돌아오는 판이고, MMC803은 직접 종료할 때까지 플레이하는 판이다. 두 판 모두 중간 성 천장 구간에서 놓쳤던 배경 타일 읽기를 직전 주사선에서 시작한다.

| | 60초 확인 | 중간 성 재시험 |
|---|---|---|
| SD 루트에 복사할 폴더의 내용 | `01-MMC802-60SEC-SD-ROOT` | `02-MMC803-LONG-SD-ROOT` |
| 기존 SMB3(J) ROM을 복사할 위치 | `sd2snes/nes/mmc802.nes` | `sd2snes/nes/mmc803.nes` |
| SD 메뉴에서 선택할 항목 | `NES MMC3 802.nh1` | `NES MMC3 803.nh1` |

1. 전원을 끈 상태에서 원하는 판의 **폴더 안 내용 전체**를 SD 루트에 덮어쓴다. 같은 판의 펌웨어와 FPGA 파일을 함께 사용한다.
2. MMC802에서 평소와 같은 첫 레벨 동선으로 플레이한다. 60초 후 메뉴 복귀를 확인한다. 표시 속도 비교 구간은 5–40초와 40–55초다.
3. MMC803으로 바꿔 1-1과 1-2를 클리어한 뒤 **중간 성 두 번째 방**에 들어간다. 천장이 내려오기 시작할 때, 내려오는 동안, 다시 올라갈 때를 지나 계속 플레이할 수 있는지 확인한다. 이전에는 같은 방에서도 몇 차례 지나간 뒤에 멈춘 적이 있어 가능하면 여러 번 지나가 본다.
4. 장시간판은 **L + R + Start + Select**를 함께 길게 눌러 종료한다. 메뉴가 돌아왔는지, 도중에 자동 복귀했는지와 마지막으로 본 장면을 함께 기록한다.

각 실행 직후 SD의 `sd2snes` 폴더에서 아래 파일을 보관한다. 같은 판을 다시 실행하면 같은 이름을 사용한다.

| MMC802 | MMC803 |
|---|---|
| `nes-progress-mmc802.txt` | `nes-progress-mmc803.txt` |
| `nes-budget-mmc802.txt` | `nes-budget-mmc803.txt` |
| `nes-game-last-mmc802.txt` | `nes-game-last-mmc803.txt` |

부팅 암전이 다시 생기면 전원을 껐다 켠 뒤 생성된 로그부터 보관한다. `NES-DIAG` 폴더의 해당 번호 BOOT 항목은 65816 준비 직후에, START 항목은 START 수락 직후에 STOP을 시험한다. 이 두 진단은 게임 화면 없이 메뉴로 돌아오는 것이 정상이다.
