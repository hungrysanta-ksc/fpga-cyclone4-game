# MMC643 실기 완주와 표시 속도

SMB3(J) ROM 393,216 B 적재·비교와 START를 통과했다. DISPLAY_NEXT부터 DISPLAY_STOPPED까지 60.33초에 1,152화면을 표시했다. 최종 EA 1,152회, STOP, base 복구와 MENU_PREPARED를 확인했고 사용자도 메뉴 복귀를 확인했다. MMC642에서 4.40초에 발생했던 FINISH fault의 재발 없이 완주했다. [세 로그 해시 및 계산 결과](../analysis/hardware644-mmc643.json)

| 최종 표시 완료 시각 | MMC613 횟수 / fps | MMC643 횟수 / fps | 차이 |
|---|---:|---:|---:|
| 5–40초 | 559 / 15.97 | 636 / 18.17 | +77 / +13.8% |
| 40–55초 | 224 / 14.93 | 280 / 18.67 | +56 / +25.0% |
| 5–55초 | 783 / 15.66 | 916 / 18.32 | +133 / +17.0% |

빈 캡처의 거부 뒤 정상 캡처로 돌아온 사례가 세 쌍이다. 이력의 세대 하위 8비트는 40→41, 66→77, 202→217이며 세 거부 모두 BG 그룹·팔레트·표시 마스크가 0이었다. 이력은 거부 구간의 시작과 회복만 보존하므로 각 쌍을 게임의 특정 화면에 대응시키기는 어렵다. [MMC642의 실패와 수정 범위](nes-hardware643-results.ko.md)

전체 시간 기준 평균 표시 간격은 61.75→52.37 ms다. 전체 ARM 단계 누적 시간을 완료 횟수로 나누면 수신 18.82→10.75 ms, 계획·공급 10.65→11.35 ms, 출력·최종 ACK 31.63→29.51 ms다. 여기에는 IRQ와 대기가 포함된다. 40–55초 작업 시작 기준 변경 map 행은 화면당 10.85→16.90이었다. 두 판의 입력과 장면은 동기화하지 않았고 MMC639·642는 조기 종료했으므로, 누적 개선에서 643의 폐기 순서 수정만의 fps 효과를 분리할 수 없다.

마지막 표시는 59.97초였고 종료 결과는 60초 제한 도달이다. 입력 COMMIT 1,153회 중 마지막 세대 1191의 SEAL은 ACK 대기 상태로 끝났다. 큐 23,767건 중 23,766건 반환, receiver/sink/window 잔여 코드 21/2/2를 그대로 보존했다. 해당 요청은 완료 표시에서 제외했다. 전송 CRC 오류·실패 전송·trace abort·plan 오류는 0회였다. 다음 비교에서는 MMC643을 기준으로 map 행·OBJ 작업량을 맞추고 출력·최종 ACK 29.51 ms를 발행·DMA·VBlank 대기로 나눈다.
