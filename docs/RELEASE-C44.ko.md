# C44 배포 준비 및 변경 사항
2026-10-04

C44는 SD 진단 로그를 기본 비활성화한 최종 실기 확인 후보입니다. 사용자가 요청된 최종 검사를 정상 확인했습니다. 이번 배포 준비에서 실행 바이너리는 변경하지 않습니다.

## 사용자 변경 사항

- .egbc 전용 GB/GBC 코어와 기존 .gb/.gbc SGB 경로 공존.
- 빠른 로딩, SRAM·자동 기록, MBC3 RTC.
- 메뉴 복귀·소리·게임 리셋, 4슬롯 강제 저장·복원, R 유지 빨리감기.
- 정리된 메뉴 UI와 별도 상태 메시지 영역.
- C44: load/cap/state 진단 파일 기록 OFF. 게임 저장·설정은 유지.

C43 → C44는 firmware.stm만 변경했습니다. FPGA와 SNES renderer는 C43 성공본과 같습니다. 기존 코어 통신·저장 경로를 선택하는 컴파일 플래그는 제거하지 않았습니다.

## 패키지

`FXPAK-GBC-C44-update.zip`은 기존 1.11.2 설치용 4파일 업데이트입니다. 사용 가이드·호환성·출처 고지·설치 해시 검사기를 포함합니다. SGB 코어·BIOS·게임·세이브·실험 덤프·도구 설치본은 제외합니다. 시차 파일의 +540은 한국/일본 설정 예제이며 기존 사용자 값은 유지합니다.

대응 소스 ZIP과 SHA256SUMS를 함께 준비합니다. SOURCE.txt는 해당 소스 커밋을 가리킵니다. GitHub 소스 브랜치와 검토용 PR을 준비하며, 이번 요청에서 최종 Release 발행이나 기본 브랜치 병합은 하지 않습니다.

## 검증

- C44 사용자 실기 정상 보고: 2026-10-04.
- 공개 MCU overlay를 새 빌드 폴더에서 재생성·컴파일하고 성공본과 비교.
- 헤더의 시간 기반 버전 ID 4바이트를 제외한 모든 바이트가 일치할 때만 C44 ID로 고정. 결과 SHA256 완전 일치.
- 로그 ON/OFF 6개 호스트 검사. OFF에서 파일 접근 없음, ON의 오류 처리 유지.
- 변경 없는 FPGA와 renderer는 C43 정리 단계에서 전체 재빌드 SHA256 일치. RTC RTL 검사 통과.
- FPGA constrained STA 48개 통과, 최소 setup +0.056ns / hold +0.072ns. 15,155/15,408 LE, M9K 56개.

상세 해시는 release/c44-artifacts.json, 검증 범위는 release/c44-verification.json 및 release/c44-rebuild-verification.json을 참조합니다.

## 최종 공개 릴리스 전 항목

- 자체 작성 파일의 재사용 라이선스 범위와 개별 헤더 없는 upstream 파일의 고지 정리. 기존 GPL/MIT/Intel 조건을 단일 라이선스로 덮지 않습니다.
- 타이밍·CDC·보드 문서의 미확인 범위를 유지합니다. 제약된 경로의 양수 slack과 실기 표본을 전체 보드 signoff로 표시하지 않습니다.
- 소스 PR 검토 후 태그·릴리스 본문·소스와 바이너리 해시를 같은 후보로 게시합니다.
