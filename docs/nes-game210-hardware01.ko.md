# NES210 실기 결과: 안정 동작 유지, 표시 속도 개선은 확인되지 않음

사용자 보고: **소리 정상, 메뉴 복귀 성공, 프레임은 여전한 것으로 보임.** 세 TXT 원본을 `probes/nes-game210-hardware01/raw`에 바이트 그대로 보관하고 SHA-256을 [분석 JSON](../analysis/game210-hardware01-verification.json)에 기록했다. [재현 분석기](../tools/analyze_nes_game210.py)는 원본·단계 순서·명령별 합계·선택 ARM 소스 해시를 대조한다. 추가 사용자 설명(hardware02)과 [최종 정정(hardware03)](../analysis/game210-hardware03-context.json)을 별도 기록으로 보관했다. 마지막5초의 장면은 hardware03을 따른다. 이번 결과는 기존 PR119에 추가하며 새 펌웨어/FIT/ZIP은 만들지 않았다.

전체 평균은 3.26회/초이며 CRT 주사율이나 특정 스크롤 장면의 FPS가 아니다. 장면·입력·계측 비용이 달라 -4.39%를 회귀율로 판정하지 않는다. 이진 검색만의 효과도 분리할 수 없다. 사용자 체감과 함께 **60fps 미달, 개선 미확인**으로 기록한다. 최대 표시 간격은 560ms이며 초기 표시 지연도 포함한다.

ROM 적재/대조393216B, RUN/STOP/base 복원 정상. 표시 시작232910ms→종료292970ms, STOP 완료293000ms, base 완료293800ms, 메뉴 준비296160ms. 이번에는 사용자가 실제 메뉴 복귀까지 확인했다. SPC A9/unmute1과 사용자 관찰로 소리 정상. 조작 품질은 이번 보고에서 별도로 확인되지 않았다.

첫 종료 원인은 `native_result=1`(시간 제한)이다. 마지막 표시59.87초/gen262, producer BEGIN/END/COMMIT197회, display196회, ABORT0이며 다음 gen263이 처리 중이었다. `plan_error=3`은 전송 callback의 false, `native_video_error=14`는 해당 계획 callback 실패의 전파다. 실제 선택 소스는 전송 전후에 deadline을 검사하며 첫 오류를 보존한다. 하위 전송 실패 집계0과 함께 보면 **정상 deadline에 의한 다음 계획 중단과 부합**한다. 정확한 E8/E9 중단 위치나 별도 CRC 장애를 이 로그로 확정하지 않는다.

window7608 sent=retired/error0. 마지막 ACK0은 처리 중 프레임의 표본이며 이전196회 표시 완료를 무효로 만들지 않는다. untrusted screen_frames0도 표시 실패로 해석하지 않는다.

12개 bin 합계는 기존 game 로그의7,543,494B 및196회와 정확히 일치한다. E8=99817회, E0=140451회(각20B), 기타1372B=196×7B retire. TX/RX를 이중 합산하지 않았다. 별도 service/audio SPI와 직접 SNES aperture 데이터는 이 표에 포함되지 않는다.

E8+E0은 **63.70%의 집계 SPI 바이트**다. 경과 시간의63.70%가 아니며, 반복 조회가 원인인지 소스 생성·SNES 처리 대기의 결과인지 분리되지 않았다. 집계 바이트의2.625MHz 순수 clock 시간만22.99초이며 나머지를 전부 CPU 계산 시간으로 간주하지 않는다.

E8/E0 바이트만 가상으로 모두 제거해도 현재 나머지 프로토콜의 전체 평균 wire 비용은42.58ms/완료다. 마지막 미완료 프레임을 제외한 b00–b10도 약31.03–52.23ms/완료다. **이것은 순수 유효 payload의 불변 하한이 아니다.** D0–D3의 조회·헤더와 기타 프로토콜 비용이 남으며, 실제 대기 제거도 모델링하지 않는다. 따라서 E8/E0 조회만 줄이는 변경으로16.67ms가 된다는 근거는 없다. ingress 형식·맵/명령·소비 작업까지 함께 줄여야 한다.

256-entry 정확키 재사용 모델은 output367136B 중216880B, **59.07%**를 프레임 간 동일 패턴으로 관찰했다. 일부5초 bin은70–79%지만 장면별 시각이 없으므로 스크롤 적중률이라고 부르지 않는다. 모델은 실제 계획을 생략하지 않았으며 활성 slot/bank/base/퇴거 안전성도 검증하지 않았다. 모델의 reusable plan payload90539B는 전체 clock 바이트의1.20%에 해당한다. 단, 실제 재사용은 원본 읽기·타일 생성·SNES 갱신·대기까지 줄일 수 있으므로1.20%를 최종 개선 상한으로 사용하지 않는다.

## 해석 제한

- 5초 bin은 프레임 **시작 시각** 기준이다. 완료가 bin 경계를 넘을 수 있어 bin별 완료 수/5초를 순간 FPS로 사용하지 않는다.
- b11에는 마지막 미완료 프레임이 포함되어 전송량·미flush 계획의 정확한 상쇄 계산에서 제외한다. 전체59.07%도 관찰 모델 비율이며 실제 절감률 예측이 아니다.
- receive bin 합계11.22초와 기존 합계11.20초의20ms 차이는 별도로 읽는10ms tick의 양자화 차이다. plan/seal 합계는 일치한다.
- E1은 map 전용 데이터가 아니다. 높은 재사용률과 큰 E1 비용이 공존하는 bin이 있어도 그 자체로 map만을 병목으로 확정하지 않는다.
- 실제 PSRAM miss, SNES 비교/fallback/VBlank, 전체 입력·장면 시각은 없다. 마지막16개 버튼 변경은 NES clock 기준 일부 기록으로 host5초 bin에 직접 대응시키지 않는다.
- 추가 설명: 화면 시작 약6–7초 후 첫 레벨에 진입했으나 끊김으로 정상 조작이 불가능해 사망과 스테이지 선택 복귀를 반복했다. **종료 전 약5초는 첫 레벨 내부였다(사용자 최종 정정).** 이 구간의 지속적인 카메라 스크롤 여부까지 확인된 것은 아니다. **지속 스크롤 시험으로 분류하지 않는다.** 사용자 화면 기준과 DISPLAY_NEXT의 정확한 시간차, 각 사망 시각이 없으므로 b01/b11을 포함한 개별 bin을 특정 장면으로 확정하지 않는다. 원래 분석의 질문 대기 상태는 hardware02 설명과 hardware03 정정으로 보완하며 동일210/044 재시험은 요청하지 않는다.

## 작업 의미와 다음 작업

이번 실기는 기본 동작을 유지하면서 **기존 패턴 재사용만이 아니라 수신·맵·SNES 소비까지 연결해서 줄여야 한다**는 설계 판단 근거를 확보했다. 60fps 가능성을 입증하거나 부정하는 최종 결과는 아니다. 원본의 물리 패턴을 유지하는 계획은 유효한 후보지만 실제 스크롤에 맞춘 정확한 슬롯·맵 자료와 자원 예산이 더 필요하다.

1. 기존 자료로 영속 physical-pattern slot, 원래 좌표 기반 scroll-map, 최종 소비까지 전달되는 dirty 목록을 하나의 변경 계약으로 작성한다. 같은 원본이 매번 다른 slot을 받거나 전수 비교되는 비용을 함께 없애는 것이 목표다.
2. 활성/작성 중 bank와 slot 보호, 마지막 표시 ACK에 따른 base 확정, epoch/CHR-RAM 내용 변화, row/alt/mask, MMC4/5 호환 조건을 먼저 명시한다. 저장 SRAM은 사용하지 않는다.210의 관찰 모델 메모리를 생산 캐시와 단순 중복 할당하지 않는다.
3. 실제 수신 형식과 E1 명령, qualified source 읽기 및 SNES 비교·VRAM 비용을 포함한 제한된 재생으로16.67ms 예산을 계산한다. 현재 TXT만으로 복원할 수 없는 슬롯/좌표·장면 자료는 실제 성능 변경에 필요한 범위만 함께 수집한다. 조회 간격만 바꾸거나 별도 관측기/FIT 반복으로 진행하지 않는다.
4. 최소 기능 검증 후 개선된 SMB3 첫 레벨에서 실기 비교한다. 현재는 끊김으로 연속 조작 자체가 불가능하므로 개선 전 동일 주행 재시험을 요구하지 않는다. 프레임 간격·소리·메뉴 복귀를 확인하고,60fps 이전 장기 플레이/추가 매퍼 확장은 후순위로 유지한다.

FPGA207 여유148LE/1LAB, SNES 본문 여유1B,210 ARM 여유5744B는 별도 예산이며 단순 합산하지 않는다. 최종 표시 ACK/불변 lease/코어 우선권과186/GBC164 및 모든 기존 증거·배포물을 보존한다.
