# MMC643 스테이지 선택 전환 확인

1. ZIP의 `01-MMC643-SD-ROOT` 폴더 안의 내용을 SD 최상위에 복사하세요. `sd2snes/nes/mmc642.nes`를 같은 폴더에 `mmc643.nes`로 복사하세요. 기존 SMB3(J)의 CRC32는 `5a04eed7`입니다.
2. 메뉴의 `NES MMC3 643.nh1`을 실행하고 지난번처럼 START로 스테이지 선택에 진입해 주세요. 통과하면 1-1을 평소처럼 플레이하고 메뉴 복귀를 확인해 주세요.
3. 메뉴로 돌아오면 `sd2snes`의 `nes-game-last-mmc643.txt`, `nes-budget-mmc643.txt`, `nes-progress-mmc643.txt`를 같은 실행의 묶음으로 보관해 주세요. 조기 복귀한 경우에는 재실행 전에 복사하고 마지막으로 보인 화면을 알려주세요.

목표는 전환 시 거부된 다음 캡처가 앞 화면을 중단시키던 문제가 실기에서도 해결됐는지 확인하는 것입니다. 5–40초와 40–55초 성능 비교는 완주한 경우에만 합니다. 메뉴 복귀에 쓰는 base·메뉴 파일은 포함했고, 게임 ROM과 RESTORE는 제외했습니다.
