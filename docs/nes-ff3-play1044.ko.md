# FF3 1044 실기 시험

SD 카드 루트에 설치본의 `sd2snes` 폴더를 병합하고 같은 이름의 설치 파일을 덮어쓴다. 파일 선택 메뉴에서 평소 사용하는 한글판 Final Fantasy III의 `.nes` 파일을 선택한다. 파일 이름과 폴더는 자유롭게 정할 수 있다.

## 게임 저장과 장면 저장

플레이 중 **L+R+START**를 함께 눌러 NES 코어 메뉴를 연다. 위·아래로 이동하고 A로 선택한다. **B** 또는 **RESUME GAME**으로 게임을 계속한다.

| 항목 | 동작 |
| --- | --- |
| WRITE SRAM | 게임 안의 세이브 기능으로 만든 배터리 RAM 8,192바이트를 SD에 기록한다. 다음 실행 때 읽는다. |
| STATE SLOT | A를 눌러 장면 저장 슬롯 1–4를 선택한다. |
| SAVE STATE | 선택한 슬롯에 현재 NES 상태를 저장한다. 같은 슬롯을 다시 쓰면 최신 저장이 바뀐다. |
| LOAD STATE | 선택한 슬롯을 불러온다. 선택한 ROM 전체를 다시 대조한 뒤 실행을 재개한다. |
| EXIT TO MENU | 게임을 종료하고 SD 파일 선택 메뉴로 복귀한다. |

부하 장면을 찾으면 슬롯 번호를 확인하고 **SAVE STATE**를 선택한다. **EXIT TO MENU**로 나와서 같은 `.nes`를 다시 선택한 뒤 같은 슬롯에서 **LOAD STATE**를 선택한다. 지형·캐릭터 위치와 뒤이은 화면 움직임, 입력 반응을 비교한다. 일반 세이브를 확인하려면 게임 안에서 저장하고 **WRITE SRAM**을 실행한 뒤, 다시 실행한 게임의 세이브 목록에서 불러온다.

슬롯을 저장한 ROM과 같은 내용이면 파일 이름이나 폴더를 바꿔도 같은 슬롯을 사용한다.

SD 저장 경로는 `/sd2snes/nesstate/`다. ROM 내용과 슬롯별로 두 파일을 번갈아 사용한다. 이 판의 대화형 메뉴는 시험한 FF3 방식의 MMC3·CHR RAM 구성에 연결했다. 파일 선택기는 지원하는 CHR ROM 구성도 식별한다.

실기 결과를 남길 때에는 `nes-progress-ff31044.txt`, `nes-game-last-ff31044.txt`와 생성된 경우 `nes-frame-ff31044.bin`을 함께 보낸다. 장면 저장·복원 결과와 메뉴 복귀 여부도 함께 기록한다.
