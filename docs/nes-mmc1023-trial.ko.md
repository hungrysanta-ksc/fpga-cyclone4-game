# MMC1023 별의 커비 무입력 60초 기준판

1. ZIP 안의 `MMC1023-KIRBY-60SEC-SD-ROOT` 폴더 내용을 SD 루트에 복사한다.
2. 보유한 `Hoshi no Kirby - Yume no Izumi no Monogatari (J).nes`를 SD의 `sd2snes/nes/mmc1023.nes`로 복사한다. 이 판에서 확인한 파일은 iNES 헤더 포함 786,448바이트이며 SHA-256은 `56901e11f6fe812e0a049c747fa0b0d6fc42a336c502ca94fb5282229853347d`다.
3. 전원을 켜고 **NES MMC3 1023.nh1**을 선택한다. 게임 입력 없이 60초 자동 종료와 메뉴 복귀를 기다린다. 화면이 멈추거나 타일이 달라 보이면 장면과 대략적인 시각을 함께 기록한다.
4. 첫 실행 후 SD의 `sd2snes` 폴더에서 다음 네 파일을 PC의 `1차` 폴더에 복사한다. 같은 설치본과 같은 전원 시작 조건으로 두 번째 실행 후 `2차` 폴더에 복사한다. 재실행 시 같은 로그 이름을 사용한다.

- `nes-budget-mmc1023.txt`
- `nes-game-last-mmc1023.txt`
- `nes-progress-mmc1023.txt`
- `nes-frame-mmc1023.bin`

두 회차 각각 [1, 30)초의 공개 프레임 수를 29초로, [30, 60)초의 공개 프레임 수를 30초로 나눈다. 두 회차 값과 차이를 함께 보관한다. 모험도 4의 실기 기준은 MMC1012다. 이후 커비에서 채택한 변경은 같은 조건에서 모험도 4로 되돌려 검증한다.
