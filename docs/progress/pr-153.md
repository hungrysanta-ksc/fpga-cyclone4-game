## 목표

MMC643 출력·최종 ACK 실측 29.51 ms의 계측 경계를 확인하고, 같은 map·OBJ 작업에서 어느 구간을 먼저 줄일지 정한다.

## 후속작업

656 ingress를 기준으로 남은 100 LE·17 LAB를 줄일 삭제 예산을 먼저 잡는다. 96비트 ordinary/source record의 생성·보관·전송과 SPI 수락 제어를 한 경계에서 검토한다. 대체 비용에는 CDC·원본 복구·STOP을 포함한다. 같은 두 위상과 보드 전체 FIT를 다시 통과한 후보에만 STA와 실기 전달을 진행한다.
