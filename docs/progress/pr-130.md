# PR130 — NES256–298 실제 출력 경계와 전체 비용

[GitHub PR130](https://github.com/hungrysanta-ksc/fpga-cyclone4-game/pull/130), master 병합 `d7a96c5652d7c511d061ae5035277027c14ec597`.

## 목표

ARM 계획·FPGA 독립 검사·SNES DMA/표시를 실제 packet부터 최종 ACK까지 연결하고 시간·회로 비용을 함께 판정한다.

## 작업내용

bank/token/4credit/STOP, map 묶음 전송, byte echo 제거, HDMA bank 재사용, ARM producer·IRQ/ROM·65816 경계를 단계별 검증했다. 마지막에는 국소 FSM 통합 반복을 중단하고 구조 재검토를 계획했다.

## 성과

staging 공유·묶음 전송·byte echo 제거·HDMA 재사용은 해당 경계에서 검증됐다. 전체 Lite MAP은 최초267의18399comb에서298의17683comb로 줄었지만 장치 적합성과60fps를 함께 달성하지 못했다. 후반268→298은 조합+4/RAM+4096bits로 정체됐다. 조건부 시간·실제 CPU 시험을 물리 전체 FPS로 승격하지 않는다.
