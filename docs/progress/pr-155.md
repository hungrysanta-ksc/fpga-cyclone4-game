## 성과

**MMC666을 유지한다. 아직 두 시작 위상의 종단 동시 개선을 달성하지 못했다.** 실기 출력·최종ACK26.84ms를 모델 비율로 임의 분할하거나 이번 수치를 실기FPS로 보고하지 않는다.

680 최종 후보는956 선행map128→512B,911마감·951공개선·952표시3회·957최종대기0회·큰plan묶음을 두위상에서 유지했다. 밀집951–955평균은MMC666 대비 **−0.046784/−0.054662ms**, 마지막ACK는 **+0.010430/−0.213062ms**다. 밀집15VBlank는 동일하고 위상1마지막ACK가 늦어 채택하지 않았다. MMC666의 위상1은 이미956map640B+tile16B를 선행했으므로678 대비 회복을 제품 대비 개선으로 계산하지 않는다.

ARM은212,828B/여유164B,staticRAM동일이다. 65816body5,948B/여유36B,물리ROM5,120B/여유16B,추가persistentWRAM0B·DMA중stack최대3B다. 압축 복원 후 첫poll은22.496619ms 늦지만 동일 시험 시작 전에는 준비된다.

전체 보드 MAP은조합논리14,390(+35)·레지스터8,389(+3)·RAM305,264bits(동일)다. 시간탈락으로 새FIT/STA를 실행하지 않았으므로 순증84LE·1LAB의 실제 배치 통과를 주장하지 않는다. 실제CPU/RTL 안전 검사는 통과했고 새설치본·실기시험·자동병합은 없다.
