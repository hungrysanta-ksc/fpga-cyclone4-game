## 후속작업

R1 기존자료 분석은 완료했다. 다음은 선택 fixture의 section별 canonical/압축/실제 변경량과 generation·준비·SEAL/ACK 연결을 한 차례 조사하고 누락 계측 비용을 확정한다. 물리 경계가 없으면 결측으로 남긴다.
