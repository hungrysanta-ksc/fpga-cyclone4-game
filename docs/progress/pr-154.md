## 작업내용

확정된 scroll/padding만 먼저 보내는 prefix와 section 5 전체를 기존 ordinary credit 경로로 공급하는 all을 분리했다. bulk/plan 우선과 최종 SEAL의 END·소비 완료 조건을 유지했다. 665에서는 all을 유지하고 65816 DMA 채널 설정을 VBlank 대기 앞으로 옮겼으며 불필요한 대기 종료 카운터 재설정을 없앴다. 두 위상 106화면을 추가하고 STOP/timeout 10조건, ROM 결합 전체 Lite FIT·STA를 검증했다. 실제 링크 ARM의 입력 오류·최종 ACK·메뉴 및 base 복구 근거를 유지했다. 현재 등록부/재개 문서의 오래된 기준을 MMC662로 맞추고 AGENTS 누적 기록은 원문으로 보존했다.

## 성과

실기 평균과 별개인 고정 52 warm 화면의 출력은 29.242/29.263ms였다. 약 15.8ms는 SEAL까지의 발행, 9.4ms는 업로드 VBlank 대기다. 밀집 구간의 최종 추가 대기는 이미 0회다.

선택 665는 두 위상 모두 952를 4→3 VBlank, 밀집 합계를 16→15회로 줄였다. 평균 간격은 53.244→49.921/49.917ms, 957 ACK는 16.880/16.652ms 빨라졌다. 951 공개선 239/239, 954·955 3 VBlank, 957 추가 대기 0회를 유지했다. Flash 212,496B(원본보다 12B 감소), 여유 496B, data/BSS 증가 없음. 65816 본문은 32B 늘었으나 물리 ROM 5KiB를 유지한다. ROM 단독 교체 전체 FIT는 15,324 LE·962 LAB·56 M9K로 동일하고 STA도 setup +0.511/hold +0.149/recovery +1.828/removal +0.393ns로 무회귀다.

664 위상 1의 914 추가 대기는 665에서 제거됐다. 246번 검사선을 유지하고 첫 DMA가 21.51/10.43µs 빨라졌다. 664 대비 위상 1 밀집 평균은 약 1µs 증가했으므로 모든 연속 시간의 개선으로 표현하지 않는다. 두 위상에서 VBlank 횟수 회귀 없이 MMC662 대비 이득과 마지막 ACK 개선을 유지한 제한 전달 준비 판정이다. 외부 IO 전체 sign-off와 새 실기 FPS 결과는 없으며 MMC662 실기 기준·ZIP은 보존한다.
