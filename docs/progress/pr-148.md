## 목표

MMC551의 957에서 확정된 map 세 개가 마지막 tile ACK 뒤에 남는 이유를 확인하고, tile 우선·credit·독립 검사·STOP·최종 ACK를 유지하면서 두 시작 위상의 밀집 표시와 전체 마지막 ACK를 함께 줄인다.

## 작업내용

PR147 병합본에서 분기했다. 새 tile을 먼저 발행하고 확인된 큐 슬롯 두 개 이상이 남으면 확정된 map 하나를 뒤에 넣도록 ARM을 변경했다. 보고서 수정만 적용한 대조군을 분리하고 패킷별 PUSH·실제 수락·ACK·credit 반환을 추적했다.

554는 END 대기 중 팔레트·OAM·HDMA를 선행 발행하는 경로와, HDMA 앞에서 END를 우선하는 경로를 분리했다. 954의 18개 패킷 각각의 준비·SPI 발행·실제 수락을 추적했다.

555는 65816의 연속 map 전송 상한을 512B로 넓힌 경로와 ARM이 OAM 앞에서 END를 우선한 경로를 분리하고, 각각과 결합 후보의 실제 DMA를 패킷 수락 ACK에 대응시켰다.

556은 ARM의 E1 송신 CRC와 65816의 범위·비트맵 순회를 각각 교체했다. 고정 PUSH와 네 가지 연속 일정, 독립 재생 및 Quartus Lite 전체 보드를 비교했다.

557은 보드의 두 plan RAM과 E8 샘플 경계를 연결하고 Questa에서 실제 SPI·RAM·CDC를 검증했다. 이전 단일 묶음 일정과 수정 일정, 추가 확인 ARM을 분리하고 MMC551도 같은 조건에서 재실행했다.

## 성과

957에서 첫 두 map이 마지막 tile ACK 전에 전송됐고 마지막 tile ACK→SEAL 수락이 1.98 / 1.87ms 줄었다. 53화면의 마지막 ACK는 49.91 / 33.30ms 단축됐다. 밀집 합계는 두 위상 모두 28 VBlank여서 새 실기 전달본은 만들지 않았다. 952의 SEAL 전 5회와 957의 최종 대기 0회를 유지했다. [측정과 재현](../nes-map553-results.ko.md)

제한 선행은 954의 SEAL 수락을 두 위상 모두 5→4 VBlank로 앞당겼다. 그 VBlank에 남은 DMA가 증가해 246행 검사를 넘겼고 표시 간격은 6회, 밀집 합계는 28회로 같았다. 마지막 ACK는 각 0.015ms 빨랐다. 953은 두 위상 모두 5 VBlank, 957 map 2개 선행과 대기 0회를 유지했다. [18개 패킷 시각과 전체 결과](../nes-prelude554-results.ko.md)

512B 후보는 954의 표시를 첫 위상에서 6→5 VB로 줄였고, 두 번째 위상은 6 VB였다. 밀집 합계 27 / 28 VB, 마지막 ACK는 554 제한 선행보다 83.525 / 33.825ms 빨랐다. 2,432번 map의 192B가 두 번째 위상에서 256행에 수락돼 254행 허용선을 놓쳤다. [명령별 대조와 안전성 시험](../nes-grant555-results.ko.md)

결합 후보는 954의 192B map 수락을 229 / 225행으로 앞당겼고 53번째 ACK가 555보다 216.452 / 216.297ms 빨랐다. 마지막 OBJ ROM 읽기 중 18 / 8개가 다음 구간으로 넘어가 954의 표시는 6 / 6 VB였다. 독립 검사·STOP·957 최종 대기 0회는 유지했다. [556 처리 시간과 보드 비용](../nes-admit556-results.ko.md)

두 뱅크 일정에서 최종 E9는 마지막 OBJ 요청보다 약 24ms 먼저 수락됐다. 추가 polling은 채택하지 않았다. 556 결합 경로는 MMC551 대비 두 위상 모두 밀집 합계 28→26 VB이고 마지막 ACK는 349.885 / 366.310ms 단축됐다. 위 556의 77 / 24µs 예산은 이전 모델에만 적용된다. 검증한 556의 라벨 빌드를 MMC558로 전달한다. [557 비교](../nes-end557-results.ko.md) · [실기 안내](../nes-mmc558-trial.ko.md)

## 후속작업

MMC558로 같은 첫 레벨 동선을 플레이한 뒤 시작 성공·실패와 메뉴 복귀를 분리하고 5–40초·40–55초 표시 수를 MMC551과 비교한다. 다음 일정 분석은 두 뱅크 모델에서 952의 직전 표시→SEAL과 첫 BG·OBJ ROM 공급을 대조한다.
