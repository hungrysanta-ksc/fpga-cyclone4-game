## 목표

60초 비교판과 장시간판을 제공하고, 장시간 실기의 스페이드 보너스 진입에서 발생한 CHR 읽기 마감 오류를 수정한다. sprite 요청은 대기 중인 mapper 쓰기를 미리 반영하되 실제 소비는 확정된 주소로 독립 검사한다. STOP·최종 ACK·캡처 회복·메뉴 복귀와 기존 표시 일정을 보존한다.

## 작업내용

PR155의 master 병합 c5a25a448e856ce9eddeb86d90965d2ae804a966을 확인했다. 두 위상의104개 warm 비용과799개 ARM 함수 일치를 확인하고 기존 시간 제한7경계를 실행했다. 실제 ARM·65816에 L+R+Start+Select→기존 stage/SPI snapshot→STOP/base/menu 종료를 연결하고 정상 tick 때 누적step 제한을 해제했다. 첫5–40/40–55초 집계와 유한 epoch 통계를 분리했다.

packed reset 시험에서 발견한19.94ms 부팅 증가를 기존 압축 형식의 최적 분할로4.70ms까지 줄이고 tick 감시 갱신을 실제step으로 옮겼다. 세대65535→0·DMA 중 취소·두 위상106화면 일정과 변경 ROM을 포함한 전체 Quartus Lite FIT·STA를 검사했다. 새 이름의 MMC695 60초판과 MMC696 장시간판을 전체 링크하고 설치·로그·프로그래머·메뉴/base를 검증해 ZIP을 준비했다. RESTORE와 게임 ROM은 제외했다.
