## 후속작업

1. 사용자 확인 동선(월드1의 1·2레벨 클리어 후 아래쪽 스페이드 슬롯머신 보너스 게임 진입)에서 오류를 재현한다. 선행 클리어가 필요하므로 동일 ROM의 최소 RAM 치트 또는 검증된 진입 직전 세이브로 준비하고,반복 치트를 끈 뒤 실제 진입 코드를 실행한다. 주소·단축 진입은 아직 미검증이다. 출력 최적화에 앞서696의 sprite fetch257–264dot에서 주소/ALE/mapper tag와 CPU/PPU/tile request·grant·response를 같은 시간축으로 연결해 최초 마감 실패를 재현한다. 캐시 miss·CHR bank변경·경쟁 읽기를 분리한다.
