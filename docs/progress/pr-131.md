# PR131 — NES299–364 연구 개선과 실기 검증 순서 수정

[GitHub PR131](https://github.com/hungrysanta-ksc/fpga-cyclone4-game/pull/131), master 병합 `914138969246387162bf2c909159824e72a3666d`.

## 목표

descriptor/manifest·주소·source/host 제어와 ARM/ROM 일정을 줄여60fps와 실제 보드 적합성에 접근한다.

## 작업내용

read-event CRC/coverage, aligned queue/D4 재사용, host 제어와 ARM raw-group/compact/raster 준비를 비교했다. BG/OBJ 선행 공급 및 기능 시험과 합성 wrapper의 source/lease 시작 연결 차이도 조사했다.

## 성과

최소 면적 host359는17213comb, 빠른 source338/ARM355/host359+BG5/OBJ2는17724comb로 서로 다른 구성이다. 일부 ARM warm 모델 시간과 동위상 ROM 대기는 개선됐지만 두 구성 모두 실기60fps/전체 보드 적합성을 달성하지 못했다. 기능 TB가 합성 source/lease 시작 오류를 우회한 문제를 확인해 실제 연결·연속 capture gate를 먼저 하도록 방향을 바꿨다.
