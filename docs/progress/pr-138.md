# PR138 — bounded word 복원과 plan 공급 경계의 조회 통합

[GitHub PR138](https://github.com/hungrysanta-ksc/fpga-cyclone4-game/pull/138), 초안·진행 중. 현재 실기는489이며 새 설치본은 없다.

## 목표

MMC489 실기(플레이 포함9.60fps)의 반복 상태 조회와65816 복원·소비 비용을 함께 줄인다. 독립 검사·STOP·credit/실제 소비 구분·최종ACK·VBlank·메뉴 복귀 경계를 유지하고 전체 비용으로 판정한다.

## 작업내용

PR137 merge29815faa3887a035091e3169ffa0f751dda3de44의 master 도달을 확인하고 새 브랜치에서 진행했다. ARM local plan append 뒤의 중복 E8 조회를 삭제하되 guard·첫 BG 선행 flush·15개/240B flush·finish/END·실제 E0 ACK·EA retire를 유지했다.

65816 word 반복은 encoded 두 byte를 모두 읽은 뒤 동일 byte는 fixed-source DMA,서로 다른 byte는 overlap MVN으로 복원한다. seed2B 후와 매64B 이하마다 STOP/서비스를 확인하고 DBR을 복원한다. 기존 DP scratch만 사용하며 CRC/coverage/manifest/HDMA 검사를 유지한다. ABI4891은 같다.

## 성과

- 실제 M4 71개 canonical 상태/계획/serializer 일치,12 ownership/STOP/token/ACK guard와8 burst 경계 통과.61개 fixture에서 E8 268→236회, E9 바이트/순서 동일. 물리 시간으로 환산하지 않는다.
- 실제65816 71개 전체 픽셀/raw VRAM/VBlank/최종ACK 일치. 같은 시작clock의 최종 표시 **3903.397→3620.517ms(7.25%)**.12개49.91ms,시작+4ms33.28ms 절감으로 VBlank 위상 효과도 구분했다. reset부터813.733→763.822ms.
- 108개 길이/word/bank/부분STOP,5거부+3STOP+행변경clear/DMA/final STOP 통과. 실제 C/source·ROM/SPI RTL/65816 첫 화면57344픽셀·34ACK·STOP과5124개 코드/header/vector bus읽기도 통과했다. 한 FLOAT 좌석 순차 사용.
- matching whole Lite1회 **15272LE/14078comb/8392FF/51M9K**,489와 동일. 관련 setup/hold+0.183/+0.168ns,nominal+0.224/+0.168ns.136LE/5M9K 여유. ARM Flash148B(24B 절약),새 global0B·RUN31848B 동일,emit static stack32→16B. SNES body4425B/program5KiB,새 persistent/frame RAM0B.

**491 실기 가속·60fps·공통 물리 ARM/IRQ/ROM 시간은 미입증이다.** 7.25%는 고정 입력의 실제CPU/전송 모델이며 ARM endpoint 감소율과 합하지 않는다. 현재 설치본과 실기는489 그대로,새 ZIP은 없다. 전체 reset/CDC/IO/full stack·IRQ는 미완료다.
