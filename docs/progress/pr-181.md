# PR181 · 별의 커비 무입력 데모의 타일 공급과 입력 시작

## 목표

커비 무입력 60초에서 표시가 한 VBlank 늦어지는 원인을 찾는다. MMC1024의 두 회 평균 26.09 FPS(1–30초), 27.32 FPS(30–60초)를 실기 기준으로 유지한다. 변경의 효과는 같은 계측량과 비슷한 작업량에서 화면 공개와 최종 ACK로 판단한다.

## 작업내용

- MMC1025–1028에서 앞쪽 ROM 요청과 첫 허가, 마지막 타일 완료, 뱅크 공개 및 첫 E8을 구분했다. 비어 있는 캐시 슬롯을 이용해 확정된 OBJ를 먼저 읽는 경로를 구현하고 기존 캐시와 대조했다. [계측 경계](../nes-kirby1027-observer.ko.md) · [선행 읽기](../nes-kirby1028-prefetch.ko.md)
- MMC1029–1032에서 입력 D1·복원·D2/D0와 첫 블록이 준비된 뒤 D1까지의 지연을 기록했다. 계측이 같은 두 판으로 ARM과 FPGA 시각의 오차 범위를 포함해 비교했다. [입력 계측](../nes-kirby1029-input.ko.md) · [최종 실기·FIT·STA](../nes-kirby1031-input-offer.ko.md)
- 1033 분석에서는 MMC1027 두 실기 기록을 다시 읽었다. 같은 회차에서 2초 이내이고 BG·OBJ·map·타일 수·묶음 수와 마지막 descriptor의 종류·길이·오프셋이 같은 화면을 짝지었다. 소비용 ROM 요청이 확인되고 표시 간격이 약 한 VBlank 이상 차이 난 조합은 1차 2쌍, 2차 3쌍이었다. 일부 쌍은 한 화면을 공유한다. [세대별 시각과 원본 해시](../../analysis/kirby1033-supply.json) · [재분석 도구](../../tools/analyze_nes_kirby1033.py)

## 성과

- MMC1029→1030에서 오프닝 26.90→27.90 FPS, 데모 27.60→28.70 FPS였다. 입력량까지 일치한 30쌍에서 5쌍이 한 VBlank 앞당겨졌고 25쌍은 같았다. 첫 블록 대기까지 계측한 MMC1032 기본 캐시→1031 선행 읽기에서는 오프닝 27.76→27.24 FPS, 데모 28.40→28.60 FPS였다. 각 한 회의 결과로 선행 읽기를 기본 설정으로 채택할 근거는 부족하다.
- MMC1031·1032 모두 60초 STOP·base·메뉴 복귀에 성공했다. ARM Flash 여유는 각각 316B, Quartus Lite의 57개 STA 항목 중 최소 여유는 각각 +0.131ns·+0.125ns였다. MMC1032의 36–37초·53–54초에 기록된 다섯 표본은 모두 2 VBlank였다. 화면 픽셀이 없어 순간 깨짐의 원인은 미확정이다.
- MMC1027 2차의 58.03초(세대 1526)와 59.63초(1561)는 15타일·4묶음·마지막 OBJ 192B였다. 표시 간격은 49.93→66.32ms, 직전 공개→최종 ACK는 50.32→66.32ms였다. 직전 공개→첫 E9와 첫 E9→마지막 묶음 계획 시작이 **각각 8.19ms** 늘었다. 마지막 계획 시작→뱅크 공개는 16.77→16.38ms였다.
- 세대 1526의 입력은 직전 공개 **4.10–5.74ms 전**, 1561은 **7.72–9.36ms 후**에 끝났다. 입력 완료→첫 E9는 오히려 15.41–17.05→10.15–11.78ms였다. 마지막 묶음의 첫 ROM 요청→첫 허가는 15.21ms에서 한 눈금(0.39ms) 미만으로 줄었다. 이후 허가별 시각과 캐시 적중은 이 측정에 없으며, 두 화면은 사용 뱅크도 다르다.

## 후속작업

1. 입력 완료가 직전 공개를 넘기는 화면에서 첫 블록 준비·첫 D1·마지막 D2를 같은 세대로 대조한다. 앞선 화면의 SPI 점유와 입력 자체가 늦게 준비된 경우를 구분한다.
2. 첫 E9부터 마지막 묶음 시작까지 각 묶음의 E9 수락·타일 완료·뱅크 반환 시각을 대조해 두 번째 8.19ms가 생긴 위치를 찾는다. MMC1031·1032와 MMC1027 사이에는 이 구간의 작업량까지 정확히 일치한 느린 표본이 없어 회차 간 시각을 이어 붙일 수 없다.
3. 원인이 좁혀지면 해당 경계만 바꾼 판으로 커비의 두 구간과 모험도 4 대조군을 확인한다. 독립 검사·STOP·메뉴 복귀를 유지한다. 깨짐은 표시 이상과 연결할 증거가 생길 때 다시 조사한다.
