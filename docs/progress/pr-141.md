## 목표

실기 기준 MMC509에서 입력·출력 바이트를 줄이면 초기 두 화면 이후에도 최종 표시가 빨라지는지 확인한다. 독립 검사, STOP, 최종 ACK, VBlank와 메뉴 복귀를 유지하고 ARM·65816·FPGA 전체 비용으로 판단한다.

## 작업내용

- 511에서 기존 ARM·SPI·IRQ·ROM 일정의 65816 출력 비용을 분리했다. 보존된 상태 조회 두 건의 시각을 바로잡고 조기 응답을 거부하도록 공동 시험기를 수정했다.
- 512에서 ARM map 압축→기존 E1 큐→65816 WRAM 직접 복원과 FPGA D1 generation 공유→ARM 수신 파서를 각각 연결했다. map 빌드의 Flash를 확보하기 위해 종료 로그의 16진수 출력과 중복 CRC 실행 코드를 공유했다.
- 원본·map만·입력만·둘 다 적용한 경우를 동일한 시작 시각과 ROM 캘린더로 실행했다. 원본을 포함한 두 D1 형식의 온전한 응답을 실제 SPI RTL에서 대조했다. 변경 3개 보드는 Quartus Lite로 전체 합성·배치했다.

- 513에서 실제 MMC509 ARM으로 71화면의 map 행을 대상 뱅크와 대조했다. 플래너의 변경 쓰기와 ACK 이력을 기록해 패킷 수를 유지하는 8·16·32B 그룹의 ARM·RAM·전송 예산을 비교했다.

## 후속작업

MMC509를 실기 기준으로 유지하고, 행 전체 이력 저장은 보류한다. 8B 변경 마스크가 기존 ARM 범위 계산을 대체할 때 Flash 안에 들어가는지 먼저 확인한다. 65816은 생략되는 앞뒤의 대상 뱅크·행 이력이 유효할 때만 부분 literal을 받아들이고 cold·STOP 뒤에는 완전한 행을 요구한다. 독립 검사·최종 ACK·VBlank를 유지하며 905~916의 후반 표시 간격과 전체 보드 비용으로 실기 진입을 판단한다.
