4credit·2bulk는 수신 모델의 입장 제한이다. 공급 예약이 credit 때문에 지연된 뒤 새 SPI 거래를 다시 과금하지 않으므로,전체 공유SPI에 실행 가능한 일정은 아직 아니다. 실제 생산·credit 조회·ROM과 연결하기 전에는 낙관적 수락 한계로만 사용한다.

BG/OBJ 공급도 실제 기록보다 약7–15ms 먼저 요구한다. 비단조 결과이므로15.75ms를 전역 최소값이나 실제 구현 성과로 주장하지 않는다.
