## 후속작업

707D·기존ARM/65816에서952·954·955의 map 최종 쓰기·주소/CHR bank 확정·BG/OBJ 공급을 같은 일정으로 연결한다. 기존 map 배열·진행 cursor를 활용한 생산→발행 소유권 대체를 검토하며,이미 구현한7블록 수신·BG 선행·map 두 묶음·압축/캐시를 새 절감으로 계산하지 않는다. 별도 packet buffer·새 E1 ABI·새 FPGA 상태는 우선하지 않는다. 실제 준비가 늦으면 입력 복원/계획 경계까지 확대할 근거를 먼저 잡는다.
