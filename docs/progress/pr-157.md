## 목표

MMC705의 배경 CHR 마감 오류를 수정하고, 같은 map·OBJ 작업량에서 출력·최종 ACK 병목을 줄인다. 독립 검사·STOP·최종 ACK·메뉴 복귀와 기존 표시 조건을 유지한다. 스페이드는 사용자 실기 해결로 인정하고 반복 깨짐·stage0 timeout은 별도 관찰로 보존한다.
