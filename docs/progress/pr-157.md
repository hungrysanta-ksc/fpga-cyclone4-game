## 후속작업

새 retired를 주지 않는 E1 응답의 실제 검사 횟수·비용을 먼저 계측한다. raw retired는 응답 검사 필요성의 비신뢰 힌트로만 사용하고,상태 변경은 반드시 전체CRC/counter/identity 검사를 통과해야 한다. 필수E0·현재E1 수락 검증·최종 표시ACK는 유지한다. 아직 구현하거나 절감을 검증한 후보는 아니다.

실제 삭제 가능한 조회·ARM 비용과86LE/1LAB/0M9K 안의snapshot 제어 교체 예산을 먼저 확정한다. 이득이 모자라면 E1 조회 후보를 보류하고 큰 출력/DMA 병목으로 돌아간다. 현재후보·opcode/seed/고정지연 변형을 반복하지 않는다. 두 위상 밀집 간격·마지막 ACK가 함께 개선되고 기존911/951/952/957·7블록·STOP/독립검사/메뉴 조건을 유지할 때만 채택한다.
