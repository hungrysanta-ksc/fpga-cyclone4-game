# PR129 — NES248–255 역할 분담과 국소 통합 검토

[GitHub PR129](https://github.com/hungrysanta-ksc/fpga-cyclone4-game/pull/129), master 병합 `2978f04aef65987c615d62ca54576e68fc946637`. 아래는 과거 결과이며 현재 작업 지시가 아니다.

## 목표

ARM 화면 계획·FPGA map 해석/독립 검사·SNES DMA/표시의 역할 분담과 전체 경로 비용을 검토한다.

## 작업내용

query/source·CRC/receipt·phase RAM과 선행 읽기·소비 제어를 단계별 결합했다. 기록71frame와 오류/취소 조건을 비교하고 회고·다음 전체 경로 관문을 정했다.

## 성과

255는 같은 standalone 기능 경계에서3414→3362LE,1046→985FF로 줄었고 SPI polling 포함 입력 평균0.060074ms가 개선됐다. 이는 전체 보드490LE/40LAB 부족 해소나 실기60fps 성과가 아니다. 실제 출력 parser·SNES 표시·전체 ARM/ROM 비용이 남았다.
