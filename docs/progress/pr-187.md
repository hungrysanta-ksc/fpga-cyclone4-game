## 목표

조사한 NES 헤더와 카트리지 배선의 호환성을 한 PR에서 확장한다. SD에서 사용자가 선택한 ROM의 메모리 구성으로 보드를 결정하고, 대표 게임의 부팅·표시·IRQ·소리·저장·재실행·STOP·메뉴 복귀를 각 배선에서 확인한다. 검증 기준과 원자료는 [기존 조사](../nes-cartridge-compatibility-plan.ko.md)에 둔다.

## 작업내용

PR186이 병합된 master `3322565e`에서 시작했다. 첫 변경은 실제 디버그·배포 로더의 SD 선택과 재검사에서 같은 iNES/NES 2.0 판독기를 사용하는 것이다. NES 2.0의 12비트 매퍼·서브매퍼, 두 가지 ROM 크기 표기, RAM/NVRAM 필드, 512B trainer의 위치, 추가 데이터, 미러링·기종·타이밍·장치를 분리한다. 구형 헤더의 정확한 DiskDude! 서명만 별도로 처리한다.

## 성과

| 범위 | 현재 근거 | 완료에 필요한 다음 검증 |
|---|---|---|
| iNES·NES 2.0 | 두 ARM 최종 링크 각각 44건 통과. 모아이군의 지수형·DiskDude! 헤더 두 종류에서 실제 배포판 ARM과 FatFS로 128블록씩 적재하고 메뉴 복귀 확인 | 보드별 수용 가능한 메모리·배선 조합과 실기 실행 대조 |
| NROM·UxROM·CNROM·AxROM | 모아이군·테트리스·배틀토드의 기존 개별 구성 실기 | 용량·미러링·버스 충돌 조합과 모든 뱅크, 게임 실행 |
| MMC1, SXROM | 젤다 1·2 쓰기 기록과 매퍼 RTL 대조 | 실제 보드 CPU·CHR·저장 연결, FF1&2 상위 PRG·32KiB 배터리 RAM |
| MMC3·191·192 | 커비·모험도 4·FF3의 개별 구성 실기 | 용량 확장, MOTHER·메탈 맥스 혼합 CHR의 쓰기/캐시와 IRQ |
| MMC5·VRC4·VRC6a | 드퀘4·와이와이2 기존 구성 실기 | MMC5 제한 조건 판별, 악마성 전설 IRQ·펄스 2개·톱니파·상태 복원 |
| 특수 형식·환경 | 헤더 있는 UNIF·FDS 시그니처 및 카트리지의 특수 기종·타이밍·장치 요구 식별 | UNIF 보드명/청크, FDS 디스크·BIOS, VS·PlayChoice·확장 기종, PAL·Dendy·주변기기 실행 지원을 각각 추적 |

## 후속작업

1. 정상·오염·절단·큰 크기·trainer·추가 ROM 시험과 기존 여섯 실행 경로 회귀를 유지한다. trainer를 수용할 때는 PRG 시작 위치와 CPU `$7000–$71FF` 초기화까지 확인한다.
2. 젤다 1·2의 보드 통합과 SRAM·퀵세이브 재개를 먼저 진행하고, SXROM의 네 저장 뱅크를 따로 확인한다. 단순 보드·혼합 CHR·VRC6a와 특수 형식은 위 표에서 이어간다.
3. 각 보드의 전체 Quartus Lite FIT·STA와 대표 실기 결과를 기록하고 DEBUG·RELEASE를 함께 준비한다. 추가 게임에서 재현되는 스크롤·스프라이트 부하 장면은 별도 성능 비교용으로 남긴다.
