# PR133 — 제한 NROM loader·보드·실기 진입

[GitHub PR133](https://github.com/hungrysanta-ksc/fpga-cyclone4-game/pull/133), master 병합 `8d472d50df7c396efac8426bb4de62cca8ce0346`.

## 목표

현재 보드에서 실제 구동 가능한 제한 NROM 경로와 독립 검증·STOP·base·메뉴 복귀를 묶어 사용자 실기에 진입한다.

## 작업내용

mapper0 PRG/CHR/mirroring·loader CRC/SPI/readback·START·run136·observer·65816 표시·복구를 연결했다. reset/CDC·조건부 IO·같은 산출물의 source/hash·programmer/ROM identity를 확인하고467 설치본과 복원물을 전달했다.

## 성과

FPGA457/ARM418/자체 정적428의 제한 실기에서60.06초899표시,평균14.97fps·A 유지/해제·자동STOP·base·메뉴 복귀를 확인했다. 전체 Lite FIT14770LE/13637comb/8037FF/185824bits. 제한 기능 성공이지 일반 NES/60fps·전체 CDC/IO signoff가 아니다. 이 시점에는 연구 PR131–132의 최적화 대부분이 설치본에 승격되지 않았다.
