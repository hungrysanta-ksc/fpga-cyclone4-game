## 이전 PR와 원문

- [전체137개 PR 색인](merged-history.md) · [기계 판독 JSON](pull-requests.json): 실제 merge commit/PR 메타데이터. 과거 PR의 GitHub 본문은 바꾸지 않았다.
- [정리 전 누적 문서·주요 PR 원문](archive/README.md): 기존 정보는 삭제하지 않고 별도 보존했다.
- 초기 PR의 상세는 색인의 merge SHA와 full Git history, 기존 analysis/계약에서 찾는다. 확실하지 않은 옛 성과를 새로 만들어 요약하지 않는다.

## 앞으로 기록하는 방식

1. `pr-NNN.md` 파일 하나를 만든다. **목표 → 작업내용 → 성과 → 후속작업** 네 절을 쓴다.
2. PR 링크/상태·선택 구성과 관련 분석/계약을 연결한다. 성과는 모델/실기/제품 여부와 미달성을 구분한다.
3. 같은 PR에서 후속 실기가 나오면 그 파일을 갱신한다. 루트 README에는 현재 핵심 상태만 교체한다.
4. 과거 기각 후보/전체 raw를 인계에 복사하지 않는다. 다시 필요할 때만 근거 링크를 따라간다.

PR137 병합 뒤 PR138에서 개발한다. 현재 게임 실기는493 플레이 포함9.57fps, 이전4899.60fps와 다른 입력이라 지속 가속은 미확인이다. 실험495는 전달 보류이며 문양476/477의23.84fps는 별도 회귀다. 모델·명령·전송량 절감을 실기 FPS 개선으로 표시하지 않는다.
