## 목표

마지막 전체 회고499의 A1–A4 계획과 PR139–149의 실제 진행을 대조하고, 다음 구현 전에 60fps 전체 예산과 검증 순서를 보완한다. 실기 기준은 MMC577이며 이번 PR은 회고·분석·인계 문서만 변경한다.

## 작업내용

PR149의 master 병합6094a7c와 head 포함·tree 일치를 확인했다. 기존 실기·동일입력 모델·FIT/STA 근거를 구분하고 MMC577의 SPI 바이트를 원본 로그 해시와 대조해 재계산했다. 구형 계획의 상태 불일치, 반복된 국소 최적화, 늦은 CDC 경로 분류, 대표 장면·capture/게임 진행·재현성 공백을 기록했다.

## 성과

493→577 전체 관측 FPS는9.57→13.95로 개선됐지만 동일 장면의 인과적 가속률은 아니다. 최신5–55초는55813.72→57713.86fps(+1.02%)다. 조회D0/E0/E8을 모두 제외한 관측 wire도5963.90B/표시·18.18ms이며 잠정12ms까지 약2026B 추가 절감이 필요하다. 이는 현재 작업량 투영이며 보편적 하한이 아니다.

A1의 제한 수정과 A3의 공급·선행DMA 개선은 유효하다. A2 전체60Hz 예산과 A4 동일장면 지속성 검증은 미완료다. PR149의 성능 성과와 CDC/reset 안정성 성과를 분리했다. 펌웨어·RTL·새합성·시뮬레이션·전달본 변경은 없다. 근거 해시·wire 합계·문서 링크와 계획 일관성을 검증한다.

## 후속작업

R1 기존53개·두 위상/최신577의 전체 비용표와 필요한 누락 계측 → R2 반복 본문 제거 구조와 실제 삭제·자원 예산 선택 → R3 한 후보 구현 → R4 의미 있는 후보만 실기 비교 순서로 진행한다. R2 전에는 작은 DMA/poll 후보를 바로 구현하지 않는다.

독립 검사·STOP·최종 ACK·VBlank·메뉴 복귀를 유지한다. 같은 가설의 두 변형에 전체 이득이 없으면 새 증거 전까지 보류한다. 기존 양수timer/epoch/seed 반복을 재개하지 않고 외부IO·capture무손실·60fps는 별도 미완료로 남긴다.
