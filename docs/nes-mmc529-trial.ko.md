# MMC529 실기 시험

1. `MMC529-TRIAL.zip`을 풀고 `01-MMC529-SD-ROOT` **안의 내용**을 SD 루트에 복사한다. 이번 펌웨어 `sd2snes/firmware.stm`도 덮어쓴다.
2. MMC524에서 사용한 `sd2snes/nes/mmc524.nes`를 같은 폴더에 **`mmc529.nes`**라는 이름으로 복사한다. SMB3 일본판 원본 393,232B, CRC32 `5a04eed7`을 사용한다.
3. 메뉴에서 **NES MMC3 529.nh1**을 실행한다. MMC524와 비슷한 시점에 첫 레벨에 들어가 같은 방향으로 진행한다. 적이 많아지는 40–60초 구간의 움직임·타일 표시·입력과 약 60초 뒤 메뉴 복귀를 확인한다.
4. 실행 후 SD의 `sd2snes` 폴더에서 아래 세 파일을 복사한다. 두 번 시도했다면 회차를 구분한다.
   - `nes-progress-mmc529.txt`
   - `nes-budget-mmc529.txt`
   - `nes-game-last-mmc529.txt`

세션 경과 시간 1초 이상 40초 미만과 40초 이상 60초 미만에 각각 완료된 표시 횟수를 비교한다. MMC524의 같은 구간은 12.31fps와 11.00fps였다. 다른 동선을 택했거나 일찍 멈춘 경우 그 시점도 함께 적어 준다.
