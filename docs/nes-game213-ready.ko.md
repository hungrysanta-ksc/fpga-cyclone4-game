# NES213 실기 시험

이번판은 **이미 보관한 타일을 재사용하고 바뀐 범위만 SNES 화면에 반영하는 첫 실기판**입니다. 스크롤 개선 여부를 확인하려고 합니다. 로컬 검증은 통과했지만 실기60fps는 아직 확인하지 않았습니다.

1. 본체 전원을 끈 뒤 ZIP의 `01-GAME213-SD-ROOT` 안 내용을 SD루트에 덮어씁니다. **`NES GAME 213.nh1`** 을 실행합니다. 펌웨어와 FPGA 파일을 함께 복사해 주세요.
2. 영상은 **로딩이 끝나기 직전부터 메뉴로 복귀할 때까지** 촬영해 주세요. 긴 로딩 전체를 촬영할 필요는 없습니다.
3. 플레이어 선택→월드맵→숫자1 타일에서A→첫 레벨로 들어갑니다. **오른쪽+B를 누른 채 A를 반복**해서 스크롤해 주세요. 끊김으로 죽거나 조작하기 어려우면 그 상태도 그대로 기록하면 됩니다. 무리해서 일정 구간을 유지할 필요는 없습니다.
4. 게임 화면부터 약60초 후 자동으로 메뉴에 돌아옵니다. 소리·입력 유지·스크롤 끊김과 메뉴 복귀를 확인해 주세요.
5. `/sd2snes/`의 **`nes-progress-213.txt`, `nes-game-last-213.txt`, `nes-budget-213.txt`** 와 영상을 전달해 주세요.

로그는 실행 중 SD에 쓰지 않고 종료 후 저장합니다. 화면이 멈추거나 메뉴 복귀가 안 되면 약90초까지 관찰한 뒤 전원을 껐다 켜고, 남은 로그를 보내 주세요. 같은 시험을10분씩 기다릴 필요는 없습니다.

문제가 생기면 기존210 동작판을 다시 복사할 수 있습니다. ZIP의164복원 폴더는 이전과 동일한 복구용이며 반복 복원시험은 필요하지 않습니다. 초기 로딩 최적화·60초 제한 해제는 이번 변경에 포함하지 않았습니다.
