# MMC1020 실험 결과 — 23행 화면의 201B 선행 발행과 240B 전송

MMC1012를 실기 기준으로 유지한다. 모험도 4 원본 화면 3462(재생 세대 908, BG 526·OBJ 46·map 23행)에서 201B를 직전 VBlank 전에 보내고도 화면 공개는 두 위상 모두 VBlank 39의 242선이었다. 목표는 VBlank 38의 246선까지였다.

## 실제 ARM 링크와 65816의 공동 실행

BG 마지막 행이 확정되면 raw 192B와 HDMA 데이터를 기존 작업 공간에 조립했다. 기존 큐 credit으로 201B, 오프셋 768의 map 192B, 240B를 순서대로 발행했다. OBJ 검사에 쓰는 448B는 완성된 raw 데이터와 겹치지 않도록 옮겼다. 실험 링크는 212,976B로 Flash 여유가 16B였다.

| 세대 908 | 위상 1 | 위상 2 |
|---|---:|---:|
| 201B SPI 전송 완료부터 VBlank 38 진입까지 | 1.720ms | 1.831ms |
| 192B를 포함한 map 960B 선행 DMA | 242–248선 | 240–246선 |
| 240B SPI 전송과 이 DMA가 겹친 시간 | 0 | 0 |
| 화면 공개 | 39회차 242선 | 39회차 242선 |
| MMC1012 대비 세대 908 최종 ACK | 0.018ms 늦음 | 동일 |

240B는 양쪽 모두 map DMA 시작 전에 이미 전송을 마쳤다. map 반환까지 기다린 대조군(`stream_ack`)에서는 두 위상 모두 SEAL 전 map DMA가 사라졌다. 201B 반환도 기다린 결과와 각 패킷의 발행·도착·수락·반환 클록은 [원시각 비교표](../analysis/split1020-results.json)에 기록했다.

## DMA 시작을 즉시 알 수 있는 송신기로 분리 검증

같은 ARM 링크가 발행한 201B까지의 시각을 보존했다. 이후에는 65816의 실제 VRAM DMA 시작 쓰기에서 768B DMA에 맞춰 map 패킷을, 192B DMA에 맞춰 240B 패킷을 SPI에 올렸다. 이 실험은 DMA 시작을 ARM에 알리는 왕복 비용을 0으로 둔다.

| 세대 908 | 위상 1 | 위상 2 |
|---|---:|---:|
| 192B 단독 선행 DMA | 249–250선 | 250–252선 |
| 240B 전송 18,024클록 중 DMA와 겹친 구간 | 1,604클록 | 1,602클록 |
| MMC1012 대비 SEAL 수락 단축 | 1.196ms | 1.125ms |
| SEAL 수락부터 검사 후 업로드 진입까지 | 31,478클록 | 31,476클록 |
| 마지막 PPU DMA 바이트 / 공개 / 최종 ACK | VBlank 39의 240 / 242 / 244선 | VBlank 39의 240 / 242 / 244선 |

DMA 시작을 즉시 알아도 240B SPI 전송 0.839ms 가운데 약 0.075ms만 겹쳤다. 225선 시작부터 246선 끝까지는 30,008클록이다. 관측된 SEAL 수락 후 경로만으로도 이 구간보다 약 0.068ms 길고, 이후 팔레트·OAM 등 잔여 DMA와 화면 공개가 남는다. 다음 후보는 세대 908의 마지막 패킷 수락부터 업로드 진입까지를 나눠, 수락 시 미리 끝낼 수 있는 검사·준비와 SEAL에서 다시 확인해야 하는 identity·coverage를 측정한다.

## 검증 범위

두 위상에서 세대 905–912의 RGB·WRAM map과 순서에 무관한 패킷 내용·작업량을 MMC1012와 비교했다. 양쪽의 ROM 읽기 할당은 3,136회로 같았다. 보드·65816·캐시 입력은 고정했고 ROM 허가와 공유 SPI는 공동 실행 모델을 사용했다. DMA 시작에 맞춘 재생에서도 세대 905–908의 RGB와 WRAM map이 대조군과 일치했다.

Flash 한도 안의 `stream`·`gap` 링크에서 SRAM 송신, 정상 반환, 잘못된 CRC, 손상된 SEAL, 디코드 도중 STOP과 메뉴·base 복구를 시험했다. 두 65816 오류 시험 모두 직전 화면을 보존했다. 메뉴 복구는 실제 ARM 정리 코드와 보드 응답 모델로 검증했다. 이번 후보의 실기 설치본은 발행하지 않았다.
