# NES H0 VISUAL030 실기 확인

029의 top/fine/bottom 점무늬는 실기에서 정상 여부와 차이를 판단하기 어려웠다.
사용자 결과는 **실행됨, 화면 떨림 없음, 정상 출력 판정 불가**로 기록했다.
029 ROM을 다시 비교할 필요 없이 이번에는 nes-h0-visual-030.sfc 한 개를 사용한다.

1. 압축을 새 폴더에 풀고 Verify-Package.ps1을 실행해 PASS를 확인한다.
2. 콘솔 전원을 끄고 SD의 새 NES-H0-030 폴더에 nes-h0-visual-030.sfc만 복사한다.
   기존 정상 펌웨어와 FPGA 파일은 유지한다.
3. 일반 SNES 게임처럼 실행한다. 화면 위에 **NES H0 030**이 보여야 한다.
   약1초 간격으로 **1 / GRID**(바둑판), **2 / BARS**(세로 막대), **3 / CROSS**(십자)가 반복된다.
   아래 SCREEN 1 OF 3 → 2 → 3 표기도 함께 바뀐다. 정상 비교 이미지는 expected-1/2/3.png다.
4. 약10초 동안 글자 가독성,1→2→3 반복,선/도형 깨짐·줄무늬·흔들림 유무를 확인한다.
   전체 표시1→2→3은 진행 여부 표시이며 자동 하드웨어 PASS 판정 문구가 아니다.
5. 평소 RESET/메뉴 복귀 방법으로 돌아온 뒤 한 번 다시 실행하여 같은 화면이 나오는지 확인한다.

결과는 다음 세 항목이면 충분하다.
- NES H0 030과 페이지 글자가 읽히는가?
- 바둑판→막대→십자가 약1초마다 반복되는가?
- 화면 깨짐 또는 멈춤이 있는가? RESET/메뉴 복귀 뒤 재실행도 같은가?

문제가 있으면 화면 전체와 현재 페이지를 기록한다. 읽을 수 없는 색 점무늬는 이번 진단의 정상 화면이 아니다.
이 진단은 세이브·음향·버튼 입력을 사용하지 않는다. 일반 메뉴 복귀가 안 되면 전원을 끄고 시험 ROM 폴더를 제거하면 된다.

범위: 자체 SNES 224줄 화면·PPU DMA·주기적 CHR bank 변경의 육안 확인이다.
NES FPGA/CPU/게임 실행이나 제품240줄 출력 정책을 검증하지 않는다.
Mesen에서 확인한 PNG에는224줄 그림 위7줄·아래8줄 검은 캡처 여백이 있다.
TV의 확대·색감·외곽 표시 범위에 따라 여백은 다를 수 있다.
기존 사진의 대각선 어두운 영역은 현재 자료만으로 원인을 확정하지 않았다.

실기 보고 날짜/콘솔·지역/카트리지/설치 버전/표시 연결과 cold·warm 결과를 results.tsv에 적을 수 있다.
