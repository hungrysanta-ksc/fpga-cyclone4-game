# NES159 — 매퍼 쓰기 중 불필요한 ROM 읽기 차단 시험

158에서는 새 그래픽 주소를 미리 알았지만 다른 읽기가 먼저 처리돼 오류로 종료했다.159는 실제 CPU/DMA가 읽는 경우에만 조기 ROM 읽기를 허용한다. 매퍼 쓰기 의미·클록·화면·패드·오류 보호는 유지했다. **경계 시험은 통과했지만 실제 스테이지 진입 성공은 이번 실기로 확인해야 한다.** 소리는 계속 진단용으로 차단돼 있다.

1. ZIP의 `01-GAME159-SD-ROOT` **안의 내용**을 SD 루트에 덮어쓴다. MCU·FPGA·ROM을 한 세트로 적용한다.
2. 메뉴에서 **`NES GAME 159.nh1`**를 실행한다.0바이트 표식이 정상이며 확장자는 변경하지 않는다.
3. 첫 Start로 선택 화면에 들어간 후 **1PLAYER에서 Start를 한 번 누르고 뗀다.** 진행되면 방향키와 A/B로 이동·점프를 확인한다. 플레이가 되면 짧은 영상도 전달한다.
4. 메뉴 복귀 후 `sd2snes/nes-progress-159.txt`, `sd2snes/nes-game-last-159.txt`를 전달한다. 같은 실패라면 영상은 생략해도 된다.

적재 방식은 이전과 같으며 약3분50초는 기존 실측 참고치다.159를 새로 실측한 값은 아니다. 게임 실행 상한은 기존 약60초, 오류 시 조기 종료한다. 전체7분 이상 무반응이면 더 기다리지 말고 화면 상태와 남은 TXT를 전달한다.

044/GBC 복원 시험을 다시 보고할 필요는 없다. 정상 사용으로 돌아갈 때 동봉 `02-RESTORE044-SD-ROOT`를 사용한다. 버튼·오류 직전16클록 기록은 유지했다. 정상 플레이·속도·오디오·저장은 아직 완료되지 않았다.
