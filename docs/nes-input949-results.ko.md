# NES949 · 세대 910 마지막 입력 반환과 911 캡처

## 목표

948의 4행 ARM 대조군과 같은 909 OBJ 묶음·910의 288B 공급을 유지하면서 911 캡처를 한 프레임 앞당긴다. 906 공개부터 912 공개까지 여섯 표시 간격의 목표는 두 위상 모두 기존 캐시 13 VBlank, 빈 캐시 14 VBlank다. 기준 D2는 910의 COMMIT 레코드를 읽고 반환한 마지막 D2다. 그 앞의 데이터 17블록과 구분한다.

## 작업내용

기존 재생은 이전 세대의 두 staging 슬롯이 모두 반납되어야 다음 입력을 열었다. 914I RTL의 시작 조건은 plan END 수락과 ROM reader drain이다. 기존 649 시험을 현재 모듈로 다시 실행했다. 세대 97의 슬롯을 유지한 채 세대 98의 헤더 하나와 데이터 레코드 68개가 나왔고, 이어서 97의 32B를 읽고 원래 토큰으로 반환한 후 STOP을 통과했다. 이 RTL 시험은 두 세대의 소유권을 확인한다. 전체 프레임 시간은 별도의 ARM·65816 공동 재생에서 측정했다.

보정한 공동 재생에서는 같은 출력 세대의 CRC 검사된 E8이 END와 유효 descriptor를 함께 반환하고, 캡처 준비와 ROM 읽기 종료를 모두 확인한 경우에만 입력을 연다. 열린 staging 슬롯의 세대·토큰·바이트가 그대로인지 확인한다. 935·946·948의 원본 최종 링크도 이 조건에서 다시 실행했다. 승인된 입력의 D3는 이전 표시 최종 ACK와 EA 뒤에만 나간다.

후보 `held_stage`의 ARM은 출력 OBJ의 큐 credit에 변화가 없을 때 입력 한 블록을 처리한다. 서로 다른 팔레트·OAM 이력을 미리 복사할 때에는 두 뱅크의 기존 serial을 먼저 무효화하고, 검증된 표시 ACK가 온 뒤 표시한 뱅크의 serial만 공개한다. Flash 사용량은 212,956 / 212,992B다.

원래 948의 빈 캐시에서 부족했던 19,843·23,541클록 중 **18,185·23,623클록**을 줄였다. 위상 1은 77.2µs 늦고 위상 2는 3.8µs 여유로 통과했다. 보정한 948 자체도 위상에 따라 캡처를 다르게 잡는다. 같은 입력 허가의 948과 비교하면 후보의 빈 캐시 최종 ACK는 위상 1에서 398클록 늦고 위상 2에서 715,220클록 빠르다. 전체 타일 목적지를 935와 대조하면 빈 위상 1에서 909 token 21의 32B가 1,014클록 늦다.

두 빈 위상 모두 세대 909의 token 23·24를 보유한 상태에서 910을 받았다. 910의 17번째 데이터 반환은 이전 공개보다 각각 10,835·12,317클록 빨랐다. 양쪽 모두 65816의 최종 ACK는 공개 후 2,896클록에 발생했다. 유효 응답을 내는 첫 E0 조회는 이 ACK 뒤 각각 2,361·879클록에 시작했다. D1을 더 일찍 시작한 양만으로 마지막 D2 단축을 계산할 수 없는 이유다.

SRAM의 네 D0 송신 지점, 입력 CRC 오류 거부, 두 위상의 288B 뒤 32B 선행 DMA, 새 패킷·STOP 우선권, 복사·descriptor·중복·SEAL 오류, 60초 부팅 및 base·메뉴 복귀를 최종 링크에서 확인했다. 하드웨어 측정값과 설치 ZIP은 이번 실험의 산출물에 포함하지 않았다.

같은 최종 링크를 함수 진입 시각만 기록하도록 다시 실행한 결과, 두 빈 위상 모두 표시 계측 함수 진입부터 EA를 보내는 retire 함수 진입까지 2,243클록(104.4µs)이 걸렸다. 이 중 진단용 SPI 헤더 조회 진입부터 다음 타이머 읽기까지가 2,119클록(98.7µs)이었다. 계측을 켜고 끈 두 실행의 D1·D2·E0·EA 시각은 같았다.

표시 계측 전체를 EA·D3·마지막 D2 뒤로 옮긴 별도 ARM 링크는 213,088B로 Flash 한도를 96B 넘겼다. 이 순서에서는 재생기의 입력 세대가 먼저 바뀌어 진단 페이지의 세대 대조에서도 중단됐다. 이 후보의 표시 간격과 최종 ACK는 미검증이다.

## 후속작업

위상 1에 필요한 추가 단축은 1,658클록이다. 다음 비교에서는 이전 표시 세대와 마지막 토큰을 보존한 채 16B 진단 헤더 읽기만 D2의 임계 경로에서 옮긴다. 현재 링크의 Flash 여유는 36B다. SPI 조회의 2,119클록에서 추가 세대 확인·기록 비용을 뺀 순이득이 1,658클록을 넘어야 한다. 동일한 입력 허가로 기준과 후보를 비교하고, 909 OBJ 토큰별 준비 시각도 함께 대조한다. 두 위상의 13·14회와 912 최종 ACK를 모두 만족할 때까지 MMC925를 실기 기준으로 유지한다.
