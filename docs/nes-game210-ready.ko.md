# NES210 실기 시험

이번판은 **스크롤 구간의 전송 비용과 타일 재사용 가능량을 확인하는 판**입니다. 타일 검색도 개선했지만 큰 프레임 향상이나60fps를 보장하는 판은 아닙니다. 소리·입력·60초 종료·메뉴 복귀 동작은209와 같습니다.

1. 본체 전원을 끈 뒤 ZIP의 `01-GAME210-SD-ROOT` 안 내용을 SD루트에 덮어씁니다. 기존210이 아닌 marker와 혼동하지 않도록 이번에는 **`NES GAME 210.nh1`** 을 실행합니다.
2. 게임이 나오면 플레이어 선택→월드맵→숫자1 타일에서A→첫 레벨로 들어갑니다.
3. 첫 레벨에서 **오른쪽+B를 누른 채 A를 반복해서 눌러** 지속 스크롤을20–30초 이상 만들어 주세요. 가능한 한 같은 구간을 유지합니다. 실제 조작과 화면을 확인하면서 진행하면 됩니다.
4. 가능하면 첫 게임 화면부터 메뉴 복귀까지 촬영해 주세요. 영상이 없으면 게임 화면이 뜬 후 첫 레벨에 들어가기까지 걸린 대략의 시간과, 스크롤을 지속한 구간을 알려 주세요.5초 구간별 기록에 장면을 대응시키는 데 사용합니다.
5. 약60초 시험이 끝나 메뉴로 돌아오면 `/sd2snes/`의 **`nes-progress-210.txt`, `nes-game-last-210.txt`, `nes-budget-210.txt`** 세 파일을 전달해 주세요. 소리·조작·메뉴 복귀 여부도 함께 알려 주세요.

게임 로딩은 기존 방식입니다. 추가 기록은 플레이 중 SD에 쓰지 않고 종료 후 저장합니다.210의부팅·화면·소리·조작에 문제가 생기면209 동작판으로 돌아갈 수 있습니다. 반복044복원 시험은 필요하지 않습니다. ZIP의 기존164복원 폴더는 보존된 복구용이며 이번시험의 필수단계가 아닙니다.

`nes-budget`의 재사용 수치는 실제타일전송을 건너뛴 양이 아닌256항목 캐시모델의 추정가능량입니다. 아직 실제캐시·맵스크롤 최적화나60fps 달성으로 해석하지 않습니다.
