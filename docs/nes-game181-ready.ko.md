# NES181 — 첫 레벨 화면 복구와 연속 영상 시험

`NES181-SMB3-ROW-VIDEO.zip`은 부분 행 영상 처리, 압축 전송, OAM RAM 구현을 합친 첫 실기 시험판이다. **첫 레벨 화면 정지 해결과 60fps 달성은 아직 실기에서 확인되지 않았다.** 이번에는 진단 패턴 대신 같은 SMB3(J) ROM으로 확인한다.

1. ZIP의 `01-GAME181-SD-ROOT` 안 내용을 SD 루트에 덮어쓴다. `firmware.stm`과 `fpga_n181.bi3`는 반드시 이번 묶음으로 적용한다.
2. 메뉴에서 `NES GAME 181.nh1`을 실행한다. 기존 ROM 적재·검증 방식이라 로딩에는 수분 걸릴 수 있다. 이 시간은 게임 실행 FPS와 별개이며 이번에 단축하지 않았다.
3. START로 플레이어 선택과 월드맵으로 진행한 뒤, **숫자1 타일로 이동하고 A**를 눌러 첫 레벨에 들어간다.
4. 첫 레벨에서 화면이 계속 움직이는지, 소리가 정상인지, 이동·점프가 가능한지 확인한다. 가능하면 첫 레벨 진입 전부터 약20~30초를 촬영한다. 사진의 CRT 주사선·대각선 띠·촬영 색 변화는 판단 대상이 아니다.
5. 표시 준비 뒤 약60초의 자동 메뉴 복귀를 기다린다. 화면이 멈춰도 곧바로 리셋하지 않는다. 게임 오버 후 월드맵으로 돌아왔다면 영상 회복 여부도 알려주되, 이를 위해 재시험할 필요는 없다.
6. `sd2snes/nes-progress-181.txt`, `sd2snes/nes-game-last-181.txt`와 메뉴 복귀 여부를 전달한다. 파일이 없거나0바이트이면 그 상태도 알려준다.

실행 후6분이 지나도 메뉴로 돌아오지 않으면 전원을 끄고 남은 로그를 복사한다. 정상 사용으로 돌아갈 때는 동봉한 `02-RESTORE164-SD-ROOT`를 사용한다. 별도의044 복원 시험은 필요 없다.

이번 영상 경로는 먼저 완성된 화면을 유지하면서 비표시 뱅크를 갱신하며, 변경량에 따라 표시 간격이 달라질 수 있다. **끊김이 없어졌다고 가정하지 않는다.** 첫 레벨 정지 여부와 연속 표시 품질을 함께 확인한 뒤, 남은 전송량·프레임 소유권 병목을 개선한다. 무제한 플레이와 오류/리셋 시 로그 전환은 이후 단계다.

세이브 SRAM을 영상 버퍼로 사용하지 않는다. 실행 중 SD 쓰기는 없고 STOP 뒤 기존 로그를 저장한다. `LAST16_EPISODE180_V3`라는 로그 항목은 기존 거부/회복 사건 형식을 유지한 이름이며 FPS나 표시 프레임 수가 아니다. 원본 ROM·메뉴·164 복원 파일은180 패키지와 동일하다.
