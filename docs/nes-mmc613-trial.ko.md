# MMC613 제한 실기 시험

MMC577과 같은 첫 레벨 동선에서 비교하는 시험판입니다. BG 캐시를 유지한 OBJ 선행 공급·ARM 발행 일정·SNES 팔레트 DMA와 보드 ROM 출력 타이밍 수정을 함께 포함했습니다. 실제 프레임 개선은 이번 로그로 확인합니다.

1. ZIP의 **01-MMC613-SD-ROOT** 폴더 안 내용을 SD 카드 루트에 덮어쓰세요.
2. MMC577에서 사용한 SMB3(J) ROM을 내용 변경 없이 **sd2snes/nes/mmc613.nes**로 복사하세요. 비교 ROM의 CRC32는 **5a04eed7**입니다. ROM과 세이브는 ZIP에 포함하지 않았습니다.
3. 메뉴에서 **NES MMC3 613.nh1**을 실행하세요. 이전과 비슷하게 첫 레벨을 플레이하고 적이 많은 구간과 약 60초 뒤 메뉴 복귀를 확인해주세요.
4. 아래 새 로그 세 파일을 보내주세요. 실행 실패가 있으면 재실행 전에 해당 파일들을 따로 복사해 보존해주세요.

- nes-progress-mmc613.txt
- nes-budget-mmc613.txt
- nes-game-last-mmc613.txt

비교 구간은 **5–40초 / 40–55초**입니다. 처음과 마지막 5초는 제외합니다. 이전 로그의 파일명만 바꾸지 마세요.

RESTORE 묶음은 제외했습니다. 포함된 fpga_base.bi3와 m3nu.bin은 실행 후 메뉴 복귀에 필요한 기존 MMC577과 같은 파일입니다. 기존 백업은 그대로 보관해주세요.

대상은 이전 MMC577을 실행한 동일한 FXPAK Pro / Mk.III입니다. 전체 FIT·저장소의 제한 보드 STA와 기능 검사를 통과했지만, 외부 IO 전체 전기적 검증이나 새 실기 동작을 완료한 것은 아닙니다. 화면·입력·메뉴 복귀에 문제가 있으면 해당 로그와 증상을 남겨주세요.
