# MMC695 60초 비교판 / MMC696 장시간 시험판

MMC695는 실기에서 동작한 MMC690과 같은 실행 코드·보드이며 파일명만 바꾼 대조군입니다. MMC696은 같은 성능 구현에 시간 제한 해제와 정상 종료 조합을 추가한 시험판입니다. 새로운 프레임 개선판으로 보지 않습니다. RESTORE와 게임 ROM은 포함하지 않습니다.

## 설치

1. 전원을 끄고 원하는 **한 폴더의 내용만** SD 루트로 복사합니다. `01-MMC695-60SEC-SD-ROOT`는 60초 비교판, `02-MMC696-LONG-SD-ROOT`는 장시간판입니다. 두 폴더를 동시에 덮어쓰지 않습니다.
2. 기존에 사용한 `mmc690.nes`와 같은 게임을 `sd2snes/nes/mmc695.nes` 또는 `mmc696.nes`로 복사합니다. 대상은 같은 SMB3(J), CRC32 `5a04eed7`입니다. 파일명만으로 다른 ROM을 지원하게 되지는 않습니다.
3. 메뉴에서 설치한 판의 `NES MMC3 695.nh1` 또는 `NES MMC3 696.nh1`만 실행합니다. 이전 marker가 남아 있어도 선택하지 않습니다. 판을 바꿀 때는 전원을 끄고 해당 폴더의 firmware·FPGA·menu 파일을 함께 교체합니다.

`fpga_base.bi3`와 `m3nu.bin`은 실행 종료 때 필요한 기본 메뉴 구성입니다. 별도 RESTORE 폴더나 이전 펌웨어 복구본은 넣지 않았습니다. 기존 백업·세이브는 유지합니다.

## 시험과 종료

- **MMC695:** 기존과 같은 첫 레벨 동선으로 약60초 플레이합니다. 자동 메뉴 복귀를 확인합니다. 첫·마지막5초를 제외한 **5–40초 / 40–55초**를 비교합니다.
- **MMC696:** 첫60초를 비슷하게 플레이한 뒤 원하는 만큼 계속 진행합니다. **L + R + Start + Select를 함께 길게 눌러** 종료합니다. 이 조합은 실제 joypad 서비스가 완료될 때 채택되고 기존 STOP·base·메뉴 복귀를 실행합니다. 고정60초 제한은 없지만 하드웨어·전송 오류 검사는 유지하므로 오류 때는 메뉴로 돌아올 수 있습니다.
- 장시간판에서도 첫5–40초 /40–55초 비교 값은 고정 보존합니다. 상세5초 bin은 약60초 epoch마다 재사용하며 `epoch_tick`이 구간을 구분합니다. 전체 장시간을 모두5초 단위로 저장하는 로그는 아닙니다. RUN 중 SD 기록을 추가하지 않았으므로 기록 확보에는 정상 메뉴 복귀가 필요합니다.
- 스테이지 진입, 적이 많은 장면, 장시간 후 화면/입력 이상, 종료 조합과 메뉴 복귀를 확인해 주세요. 실행 실패도 로그를 보존합니다. 강제 전원 차단은 정상 종료 시험을 대신하지 않습니다.

## 돌려줄 로그

각 실행의 메뉴 복귀 후 아래 세 파일을 복사합니다. 재실행 전에 PC에서 회차를 붙이면 덮어쓰기를 피할 수 있습니다.

| 판 | SD의 파일명 |
|---|---|
| 60초 | `nes-progress-mmc695.txt`, `nes-budget-mmc695.txt`, `nes-game-last-mmc695.txt` |
| 장시간 | `nes-progress-mmc696.txt`, `nes-budget-mmc696.txt`, `nes-game-last-mmc696.txt` |

위 파일은 `sd2snes` 폴더에 생성됩니다. 장시간판은 대략적인 플레이 시간·어느 장면까지 진행했는지와 종료 조합으로 복귀했는지도 함께 알려주시면 됩니다.

## 확인 범위

같은 두 시작 위상의 실제 ARM·65816 재생에서 911/951 마감,952 표시3회,957 최종대기0회·마지막 ACK를 유지했습니다. MMC690 대비 장시간판의 밀집 표시 간격 변화는 첫 위상 **+0.010728ms**, 두 번째 **−0.048889ms**입니다. 첫 위상906의 내부 최종대기1회가 추가됐지만 화면 간 VBlank 수는 늘지 않았습니다. 완전한 시간 무회귀나 실제 FPS 개선을 주장하지 않습니다.

장시간판 전체 Lite FIT는 15,295 LE·963/963 LAB·56/56 M9K, 기존 제약 STA는 setup/hold/recovery/removal +0.104/+0.137/+1.460/+0.488ns로 MMC690과 같습니다. ARM Flash 여유는 MMC695 8B,MMC696 52B입니다. 외부 IO 전체 승인과 장시간 실기 안정성은 아직 미완료이며 기존 제한 실기 기준으로 전달합니다.
