# MMC485 — 선행 BG·bulk ACK 소유권 실기 비교본

실제 SMB3(J) ROM은 포함하지 않는다. **현재 확인된 실기는482 평균14.60fps이며,485의 시간/FPS 개선은 아직 미측정**이다.485는484의 계획 명령 절감과 첫 BG 선행 발행·bulk 큐잉/ACK 추적을 연결한 후보다. FPGA 내용은 실기에서 동작한482와 같고, 기존 독립 검사·STOP·최종 ACK·VBlank 경로를 유지한다.

## 설치와 확인

1. 기존 SD 파일과 세이브를 보존한다. ZIP의 `01-MMC485-SD-ROOT` **안의 내용물**을 SD 루트에 복사한다.
2. 사용 중인 원본 `mmc480.nes` 또는 `mmc482.nes`를 바이트 변경 없이 `sd2snes/nes/mmc485.nes`로 복사한다.393232B·CRC32 `5a04eed7`·SHA256 `dbb1cb5e18b091ca9101b1c2f5a5d6bdbeaa4a30ae1a504251310f6765cabb49`다. 다른 버전·매퍼 ROM으로 대체하지 않는다.
3. 메뉴에서 **NES MMC3 485.nh1**을 선택한다. 기존482와 가능한 한 같은 조작·장면으로 약60초 실행한다. 게임 화면·입력 반응과 메뉴 복귀를 확인한다.
4. 아래 새 로그3개를 전달한다. 재실행하면 덮어쓰므로 보존할 때 `-1회차` 등의 이름을 붙인다.

- `sd2snes/nes-progress-mmc485.txt`
- `sd2snes/nes-budget-mmc485.txt`
- `sd2snes/nes-game-last-mmc485.txt`

검정 화면·잘못된 화면·복귀 실패가 있으면 그 증상도 로그와 함께 알려준다. 이 후보에서 멈췄다면 반복 실행으로 성공을 만들지 않고 원복한다.

## 비교할 비용

기존 DWT 계측이 실제 ARM 실행·SPI·IRQ/guard·ROM 대기·VBlank를 포함한 수신/계획·공급/SEAL·최종 ACK 시간을 기록한다. E8/E0·quiet는 단계 안에 중첩되므로 더하거나 두 번 빼지 않는다. 평균FPS·완료 프레임 수·각 단계·SPI 호출 수와 종료 중 미완료 상태를 함께 비교한다. 같은 ROM만으로 같은 장면/입력이 보장되지는 않는다.

소유권용 상태20B를 추가했고 새로운 payload buffer는 없다. Flash 잔여와 전체 stack 미증명 범위는 verification에 명시한다. 기능 결합 시험은 실제 RTL/PSRAM/65816·CRC/ACK·VBlank·픽셀을 확인했지만, 실제 M4·IRQ 전체 시간과 이번 보드의 메뉴 복귀는 이 실기로 확인해야 한다.60fps나 제품 완료를 뜻하지 않는다.

## 원복

- `02-RESTORE482-SD-ROOT`: 마지막 정상 게임482로 복귀한다. 기존 `mmc482.nes`를 사용한다.
- `03-RESTORE476-SD-ROOT`: 이전 문양 NROM476 회귀본이다.
- `04-RESTORE164-SD-ROOT`, `05-RESTORE467-SD-ROOT`: 이전에 제공한 복원물을 바이트 그대로 보존했다.

원하는 원복 폴더 **안의 내용물**을 SD 루트에 덮어쓰고 해당 메뉴 항목을 선택한다. 저장 파일을 삭제하거나 SD를 포맷할 필요는 없다. 이 ZIP은 개인 시험용이며 일반 NES/GBC 배포물을 대체하는 공개 릴리스가 아니다.
