# MMC662 제한 SMB3 실기 비교

661 FPGA와 검증된 ARM·65816을 묶은 시험판입니다. MMC643과 같은 첫 레벨 동선에서 5–40초·40–55초 표시 횟수와 스테이지 진입·메뉴 복귀를 비교합니다.

## 설치

1. ZIP의 `01-MMC662-SD-ROOT` **안의 내용**을 SD 최상위로 복사하고 같은 파일은 덮어쓰세요.
2. 기존 `sd2snes/nes/mmc643.nes`를 같은 폴더에 **`mmc662.nes`**로 복사하세요. 이전 시험에서 사용한 SMB3(J), CRC32 `5a04eed7`을 사용합니다.
3. 메뉴에서 **`NES MMC3 662.nh1`**을 선택하세요.

설치에 쓰이는 ARM은 `sd2snes/firmware.stm`, FPGA는 `sd2snes/fpga_mmc662.bi3`입니다. 메뉴 복귀에 필요한 `fpga_base.bi3`와 `m3nu.bin`도 포함했습니다. 게임 ROM과 RESTORE는 제외했습니다.

## 플레이와 확인

1. 오프닝에서 지난번과 비슷한 시점에 START를 눌러 스테이지 선택 화면에 들어가세요. 여기에서 화면이 나오는지 확인해 주세요.
2. 첫 레벨 1-1을 MMC643 때와 비슷한 동선·속도로 플레이하세요. 초반 5초와 마지막 5초는 성능 집계에서 제외합니다. 초반에는 이전과 같은 구간을, 후반에는 적이 많이 나오는 구간을 비슷하게 진행해 주세요.
3. 약 60초 뒤 자동 STOP과 메뉴 복귀를 기다리세요. STOP은 종료 절차에서 실행되므로 별도 버튼 입력은 필요하지 않습니다. 복귀한 메뉴가 표시되고 입력을 받는지도 확인해 주세요.
4. 검정 화면·조기 메뉴 복귀·스테이지 진입 중 종료가 있으면 재실행 전에 해당 실행의 로그 세 개를 복사하고 마지막으로 보인 화면을 적어 주세요.

## 반환할 로그

SD의 `sd2snes` 폴더에서 아래 세 파일을 같은 실행의 묶음으로 보내 주세요.

- `nes-progress-mmc662.txt`
- `nes-budget-mmc662.txt`
- `nes-game-last-mmc662.txt`

다시 실행하면 같은 이름으로 갱신됩니다. 여러 번 시험할 때는 PC에 복사한 뒤 세 파일 모두에 `-1차`, `-2차`처럼 같은 실행 번호를 붙여 주세요. 영상은 원하실 때 함께 남겨 주세요.

## 비교 기준

| 완료 표시 집계 구간 | MMC643 실기 | MMC662 |
|---|---:|---|
| 5–40초 | 18.17 fps | 반환 로그로 계산 |
| 40–55초 | 18.67 fps | 반환 로그로 계산 |

각 구간의 완료 표시 횟수를 35초·15초로 나눕니다. 시작 실패·조기 종료는 별도로 진단합니다. 661의 시뮬레이션에서는 954·955가 두 시작 위상 모두 3 VBlank였고, 전체 FIT·기존 제약의 STA를 통과했습니다. MMC662의 실제 프레임 개선과 스테이지 진입·메뉴 복귀는 이번 시험에서 확인합니다.
