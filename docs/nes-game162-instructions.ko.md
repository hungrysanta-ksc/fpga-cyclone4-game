# NES162 — SMB3 사운드 복원 시험

161에서 첫 레벨 플레이와 정상 메뉴 복귀가 확인됐다.162는 차단했던 APU 채널 쓰기를 복원하고 실제 음원을 카트리지 DAC 출력에 연결한다. 음악과 효과음, 음원을 켠 상태의 첫 레벨 플레이가 이번 시험 대상이다. 소리의 실제 출력·음질은 아직 미확인이다.

**화면은161과 같은 방식이다.** 전체 화면 DMA 중 소거와6프레임 유지가 남아 있고 연속 화면 개선판이 아니다. 아래 방향 유지 문제도 아직 수정하지 않았다. 사운드·연속 화면을 먼저 확인한 다음 플레이 제한 해제와 조작 품질로 진행한다.

1. ZIP의 `01-GAME162-SD-ROOT` **안의 내용**을 SD 루트에 덮어쓴다. MCU·FPGA·ROM을 같은 세트로 적용한다.
2. `NES GAME 162.nh1`를 실행한다.0바이트 표식이 정상이고 확장자는 바꾸지 않는다.
3. 기존처럼 제목 →1PLAYER →월드맵 →첫 레벨로 들어간다. **음악·선택/점프 등 효과음이 들리는지**, 소리를 켠 뒤 다시 종료 오류가 생기는지 확인한다. 가능하면 게임 소리가 포함된 짧은 영상을 남긴다.
4. 현재 약60초 자동 종료는 유지한다. 제목·선택·월드맵도 실행 시간에 포함된다. 첫 레벨에서 가능한 만큼 이동·점프·대시를 확인하되 입력 유지 문제의 최종 판정은 이후 연속 화면 환경에서 진행한다.
5. 메뉴 복귀 후 `sd2snes/nes-progress-162.txt`, `sd2snes/nes-game-last-162.txt`, 음악·효과음과 메뉴 복귀 여부를 전달한다. 오류로 먼저 돌아와도 남은 로그를 전달한다.

적재 방식은161과 같다. 기존 약3분50초는 참고치이며162 실측은 아니다. 전체7분 이상 무반응이면 대기를 끝내고 남은 TXT와 상태를 전달한다. **리셋 버튼으로 로그를 저장하는 기능과 시간 제한 해제는 아직 구현하지 않았다.** 오류 감시·STOP/base/menu 회수는 기존 경로를 유지한다.

044/GBC 복원 시험은 반복하지 않는다. 정상 사용으로 돌아갈 때 동봉 `02-RESTORE044-SD-ROOT`를 사용한다. 장시간 플레이·연속 화면·속도·음질·입력 유지·저장·전체 호환성은 미완료다.
