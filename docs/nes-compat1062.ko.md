# NES 1062 디버그판·배포판

## 목표

드래곤 퀘스트 IV 이무르 마을에서 이동 화면을 준비하는 ARM 비용을 줄이고, 헤더·실제 배선이 기존 FPGA 보드와 맞는 ROM의 실행 범위를 넓힌다.

## 작업내용

각 ZIP에서 `sd2snes` 폴더를 SD 루트에 덮어쓴다. 이무르 계측은 DEBUG, 시간 제한 없는 플레이는 RELEASE를 사용한다. 기존 세이브를 그대로 읽는다. 설치본에는 게임과 세이브가 들어 있지 않다.

- **이무르 비교** — DEBUG에서 기존 드퀘4 한글판을 선택하고 슬롯 1을 불러온다. 방향키를 한 번 뗐다가 1061과 같은 길로 6초 이상 이동한다. 첫 방향 입력부터 5.5초를 집계한다. EXIT TO MENU 뒤 `nes-{frame,stop,progress,game-last}-debug1062` 네 파일을 회차별로 보관한다. 같은 슬롯으로 두 차례 반복한다.
- **테트리스 일본판** — SD에서 기존 `Tetris (j).nes`를 직접 선택한다. 타이틀에서 게임을 시작해 블록·배경과 메뉴 복귀를 확인한다. 헤더를 고치거나 ROM을 변환할 필요가 없다.

## 성과

1061 두 실기는 같은 슬롯 1, 저널 4, 본문 CRC `caa52cd8`를 복원했다. 두 실행의 마지막 진행 레코드는 MENU_PREPARED였고 STOP과 base 복귀도 성공했다.

| 첫 방향키부터 5.5초 | 1회차 | 2회차 |
|---|---:|---:|
| 공개 화면 수 / 표시 FPS | 68 / 12.36 | 71 / 12.91 |
| 이전 최종 ACK → 마지막 타일 반환 | 54.09ms | 50.85ms |
| 마지막 타일 반환 → SEAL | 10.38ms | 10.34ms |
| SEAL → 공개 | 15.72ms | 16.05ms |
| 공개 → 최종 ACK | 0.14ms | 0.12ms |
| 공개 간격 95백분위 | 99.86ms | 99.86ms |

스크롤 좌표·방향·변경 행 수·타일 바이트가 같은 12개 조건에서 평균 공개 간격은 74.87ms와 68.01ms였다. 첫 구간에는 입력 수신과 ARM 계획도 포함된다. 1062에서는 행마다 셀 시작 주소와 스크롤 열을 한 번 계산하고, 같은 1KiB 임시 공간에 14비트 BG 태그를 대조하는 캐시를 256개에서 512개로 늘렸다.

실제 슬롯을 Questa에서 복원하고 아래 방향 입력으로 첫 세 화면을 수집했다. 두 ARM 링크에서 같은 데이터와 뱅크 이력 조건을 재생한 결과 화면별로 계획 명령 6,624개가 줄었다. 전체 계획 대비 3.9–4.8%에 해당한다. 타일 명령 수·전송량과 map·OAM·팔레트·HDMA·표시 타일 정의의 해시가 일치했다. 물리 5.5초 전체 동선의 FPS 변화는 1062 실기 결과로 판정한다.

NES 2.0의 서브매퍼 1 중 이미 보드에 구현된 두 구성(CNROM 수직 PRG/CHR 32/32 KiB, AxROM PRG 512 KiB·CHR RAM 8 KiB)을 연결했다. 구형 수평 헤더를 가진 테트리스는 제공된 파일의 전체 CRC `6118313f`가 일치하면 수직 보드로 보낸다. 원본 배선과 현 보드는 리셋 중 한 번 뱅크 값이 달랐고, 두 값이 다시 일치하기 전 PPU의 CHR 읽기는 0회였다. 동일 입력 5,400프레임에서 30프레임마다 얻은 180개 화면 해시와 뱅크 쓰기 기록을 대조했다. 다른 수평 ROM은 이 예외를 적용하지 않는다. 최종 RELEASE 링크에서 실제 FatFS로 128개 섹터의 데이터와 PRG/CHR 목적지, START·STOP·메뉴 복귀를 검사했고 CRC를 바꾼 파일은 START 전에 거절했다.

## 후속작업

1062 실기에서 같은 작업량의 공개 간격·마지막 타일 반환을 비교한다. 차이가 실행 간 편차 안에 있으면 다음 디버그판에서 첫 D1·계획 진입·첫 E9·마지막 뱅크 반환을 같은 세대로 기록해 51–54ms 구간을 분해한다. 호환성은 MMC1의 젤다 1·2와 FF1&2, 혼합 CHR의 MOTHER·메탈 맥스, VRC6a의 악마성 전설 순으로 진행한다. [전체 계획](nes-cartridge-compatibility-plan.ko.md)
