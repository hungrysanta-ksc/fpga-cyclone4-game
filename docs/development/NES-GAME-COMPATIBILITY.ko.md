# NES 첫 게임 목표와 맵퍼 확장 순서

사용자가2026-10-08 제공한 **Super Mario Bros 3 (J).nes**를 첫 NES 게임 구동 목표로 확정했다. 이후 이 게임의 회귀를 유지하면서 맵퍼를 늘려 호환성을 확장한다. 작은 진단 ROM은 선행 검증 수단이며 첫 게임 목표를 대체하지 않는다.

## 입력 식별과 확인 범위

| 항목 | 제공 파일에서 읽은 값 |
| --- | --- |
| 전체 길이 | 393232바이트 =16바이트 헤더+384KiB payload |
| SHA-256 | dbb1cb5e18b091ca9101b1c2f5a5d6bdbeaa4a30ae1a504251310f6765cabb49 |
| 헤더16바이트 | 4e45531a101042000000000000000000 |
| 형식 | iNES1.0, NES2.0 표식 없음 |
| mapper 번호 | 4 |
| PRG ROM | 262144바이트,256KiB |
| CHR ROM | 131072바이트,128KiB |
| trainer / four-screen | 둘 다 없음 |
| 헤더 battery flag | 설정됨(flags6=0x42) |
| 잔여/누락 바이트 | 없음 |

파일명과 사용자가 지정한 목표는 일본판이다. 헤더만으로 정품 dump·개정판·NTSC 실측·정확한 MMC3 칩 리비전을 인증한 것은 아니다. mapper4는 [MMC3 계열](https://www.nesdev.org/wiki/MMC3)을 가리키지만 iNES1.0에는 submapper가 없어 세부 보드 변형을 구분할 수 없다. battery bit는 **이 파일의 헤더 값**으로 기록한다. 실제 게임의 배터리/저장 필요성을 확정하거나 임의로 헤더를 교정하지 않는다.

원본은 수정하지 않고 로컬 보관한다. ROM·스크린 자산·payload를 Git/진단 ZIP에 넣지 않는다. 재현 식별은 전체 해시와 헤더/크기로 한다.

## 현재 범위와 부족한 부분

현재 ROM loader의 크기는 `load_chr32`에 따라80/96KiB 두 값으로 제한된다. 17비트 길이와 제한된64KiB PRG·16/32KiB CHR 진단 경로를384KiB 게임 지원으로 해석하면 안 된다. 기존 제한 MMC3 배경 진단/8프레임 통과도 SMB3 호환 성공이 아니다. CLOCKREPORT090은 클록 관측용이며 이 게임을 실행하는 펌웨어가 아니다.

1. 현재 진행 중인 보드 클록 관측·메모리 접근 보호·정상 복원 검증을 마친다.
2. 실제 ROM 헤더 검증/mapper 선택,256KiB PRG+128KiB CHR 적재·주소폭·경계·전체 readback을 확장한다. 아직 지원하지 않는 형식/크기는 명확하게 거부하며 잘라서 적재하지 않는다.
3. mapper4의 PRG/CHR 뱅크 전환, mirroring, PRG RAM 접근, IRQ 타이밍을 실제 PPU 주소 동작과 연결해 검증한다. 칩 리비전 차이 및 battery flag 처리 정책은 근거를 남겨 결정한다.
4. CPU/PPU/OAM·스프라이트·스크롤·컨트롤러·APU/오디오를 게임에 필요한 경로로 통합한다. 기존 전체 코어 fit의 LAB 여유4개라는 과거 제한도 새 구성으로 다시 확인한다.
5. 같은 해시의 SMB3로 제목/시작→월드맵→1-1 진입·이동·점프·아이템·스크롤·클리어를 우선 실기 확인한다. 입력과 음악/효과음, 자동 종료/깨짐/정지 여부, 정상 복원/menu/GBC 회귀를 기록한다. 이후 다른 스테이지·장시간·재진입으로 범위를 늘린다. 1-1 성공을 게임 전체 호환 완료로 부르지 않는다.

## 이후 맵퍼 확장 원칙

SMB3의 mapper4 목표를 우선 달성하고, 다음 mapper는 목표 ROM과 요구 기능을 명시한 별도 작업으로 선택한다. 지원 mapper 번호만 늘리지 않고 헤더 수용→적재→뱅크/IRQ/RAM→입력·화면·소리→실기 회귀를 기종 공통 체크리스트로 사용한다. 호환성 표는 `미지원 / 진단만 통과 / 제목 표시 / 플레이 확인 / 확대 회귀`를 구분하고, 같은 ROM 해시·코어/펌웨어 버전·검증 구간을 함께 남긴다. 새 mapper 추가 후 SMB3 및 기존 GBC 회귀를 유지한다.

현재 SMB3 상태는 **목표 등록·헤더 확인 완료 / 실제 실행 미완료**다.
