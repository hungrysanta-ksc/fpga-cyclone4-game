# GBC774 원색 표시 실기 시험

대상은 갤러가의 두 로고 다음 타이틀과 해리 포터 슬롯 1의 폴리오마기 → 보호 → 괴짜 웬델린이다. GBC773으로 확인한 8 MiB 로더를 사용한다.

## 실기 결과 및 공개

사용자는 GBC774로 갤러가와 해리 포터 두 문제 장면 모두 정상 동작을 확인했다. GBC773에서는 원피스 한국어판과 다른 8 MiB ROM이 실행됐다. GBC774의 세 실행 파일을 [sd2snesHST 0.9.1](https://github.com/hungrysanta-ksc/sd2snesHST/releases/tag/v0.9.1)로 배포했다. [버전 대응표](../../release/product-version-map.json)에 설치 파일·소스·공개 자산의 해시를 기록했다.

## 표시 경로

FPGA는 매 픽셀의 RGB555에서 빨강·파랑 하위 한 비트와 초록 하위 두 비트를 분리한다. PSRAM에 상위 색 ID와 하위 네 비트를 같은 워드로 쓴다. 기존 일곱 HDMA 채널이 상위 색을 공급하고 SNES Mode 3의 BG2가 하위 색을 더한다. 화면 SRAM은 기존 상위 색·메타데이터 페이지와 같은 소유권으로 하위 색을 두 페이지(물리 0x60000, 0x68000)에 보관한다. SNES는 41:8000에서 하위 색 11,520 B를 읽는다. FPGA/renderer 식별자는 B0이다.

65816은 비활성 BG2 VRAM에 먼저 전송하고 다음 185선부터 기존 BG1 전송을 수행한다. 준비 중에는 보이는 화면의 초기 CGRAM과 HDMA를 매 프레임 다시 시작한다. 두 레이어가 준비되면 같은 표시 경계에서 교체한다. 캡처가 바쁘면 LCD 프레임의 첫 픽셀에서 해당 프레임 전체를 건너뛴다. 게임 CPU와 음원이 계속 실행되는 동안 표시 갱신 빈도는 낮아질 수 있다.

## 검증

- 첨부 세이브로 재현한 웬델린과 갤러가 타이틀을 입력으로 사용했다. Questa에서 각 장면의 하위 색을 교대로 변경해 네 프레임씩 재생했다. 각 92,160픽셀이 RGB555 원본과 일치했다. 8클록 픽셀 간격에 16클록마다 5클록을 다른 접근에 예약하고 쓰기 허가를 제한한 모델에서 FIFO 최대 점유는 웬델린 34/256, 갤러가 52/256이었다.
- 실제 65816 설치 ROM의 카트리지 상태·메뉴 응답만 고정하고 실제 RTL 출력으로 두 SRAM 창을 채운 Snes9x 재생에서, 두 장면 모두 첫 표시부터 23,040픽셀이 일치했다. L+R+START, B 입력 뒤에도 전 픽셀이 일치했다. 완성된 한 장면을 반복 공급한 시험이다. 이후 사용자가 두 게임의 실기 시험도 정상으로 보고했다.
- Quartus Lite 25.1 전체 FIT 14,862/15,408 LE, 56/56 M9K. 기존 STA 요약 48개 최소 slack +0.056 ns. SRAM 쓰기 슬롯의 실기 타이밍은 실제 게임 확인 대상이다.
- SD 루트 ZIP SHA-256 `e15a089bc81a63aa8281ef7b6f43d071f55c7424655dc2b609dcceb9ea936697`. 실행 펌웨어 166,932 B, renderer 131,072 B, MCU 검사 CRC32 `b6ed88f2`. 사용자 ROM·세이브는 패키지에 포함하지 않는다.

## 재현 및 실기 동선

[빌드 절차](../BUILD-C44.ko.md)의 renderer 빌드에 `--rgb774`, ARM에 `-Rgb774 -Candidate`, Quartus에 `--candidate`를 사용한다. RGB774용 세 파일을 함께 설치한다. GBC773로 돌아갈 때도 해당 버전 세 파일을 함께 사용한다.

`tests/gbc_rgb774_tb.sv`를 frame_pipeline_ring3, capture_ring3_lcd, rgb_capture64_abort, next_use_builder, palette_planner, indexed_sixplane, video_router, gbc_inverse_ram과 함께 컴파일한다. Questa에서 altera_mf_ver 라이브러리와 `+VECTORS=<23040 RGB555 hex 워드> +EXPORT=<접두사>`로 실행한다. `tools/test_gbc_rgb774.py <gbc_snes.bin> <접두사> <비공개 시험.sfc>`로 65816 재생 ROM을 만들 수 있다. 게임에서 캡처한 자료는 로컬에만 둔다.

1. 갤러가에서 두 로고 이후 타이틀을 보고 게임을 시작한다. L+R+START로 메뉴를 열고 B로 돌아와 화면과 조작을 확인한다.
2. 해리 포터에서 제공한 세이브 슬롯 1을 불러와 웬델린 카드 그림과 설명을 확인한다. 카드를 닫았다 다시 열고 게임으로 복귀한다.
