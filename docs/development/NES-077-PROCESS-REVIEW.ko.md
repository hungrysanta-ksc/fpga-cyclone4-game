# NES 전체 공정 점검과 다음 작업 계획 — 077 기준

검토일: 2026-10-08 KST. 기준 커밋: `a4ed773c6a6776e9c1857b948787062587c091f9`. 기존 소스·결과·인계 문서를 대조한 **검토 전용 작업**이다. 새 구현, 빌드, 시뮬레이션, 실기 시험은 수행하지 않았다. [PR #27](https://github.com/hungrysanta-ksc/fpga-cyclone4-game/pull/27)은 이번 조회에서 open/미병합이었다. 이후 작업 시작 시 다시 확인한다.

후속078: [보고서 전체 세션](../../analysis/REPORT-SESSION078-RESULT.ko.md)116검사/대조2 완료. 아래2026-10-08 검토 당시 기록은 유지하며 P1의 다음 항목은 [관측 계약](../nes-report-observation078-contract.ko.md)의 플랫폼 구현·부팅/전체 시간 검증이다. P1 전체/실기는 미완료다.

## 판단

구성요소 구현과 재현 가능한 검증은 진전했다. 그러나 사용자가 실행하여 성공·실패를 구분하고 원래 메뉴로 복귀하는 통합 경로가 뒤처졌다. **가장 가까운 목표는 CPU/PPU 없는 PSRAM 적재·전체 비교·STOP·복구 실기 한 건을 끝내는 것**이다. 이를 일반 NES 게임 구동 완료와 구분한다.

전체 계획 JSON과 준비도 표는 070 또는 그 이전 상태가 남아 있었다. 071에서 끝난 오프라인 파일 쌍 조립이 다음 작업으로 표시됐고, 확인한 PSRAM 부품도 미확인으로 남아 있었다. 이번에 현재 상태와 과거 기록을 구분해 정정한다. 일정·공수 기준선이 없으므로 일정 준수율이나 NES 완성률을 산정하지 않는다.

## 진행 효율 평가와 개선

- **유지할 점:** 정상 기준선 보호, 실제 C/RTL 연결, 인과 대조, 실패 로그/해시 보존, 영향 없는 RTL의 fit/시뮬레이션 재사용. 이 근거를 버리고 다시 시작하지 않는다.
- **고칠 점:** 072 쓰기 권한은 계층별 mock 통과로 놓쳤다. 앞으로 상태/권한을 건너는 변경은 실제 호출 경로를 연결한 성공 한 건과 대표 실패를 먼저 만든다. 검사 수·버전 수를 사용자 관측 진척으로 보고하지 않는다.
- **실기 왕복 줄이기:** 074 LED는 사용자에게 보이지 않았다. 파일 사본으로 해결된 정보 수집은 종료한다. 새 시험마다 판별할 가설, 실제 관측 수단, 예상 결과별 다음 행동, 복원 방법이 있어야 한다.
- **순환 조건 없애기:** 과거 “0바이트 실기 원인 확정 뒤 재시험”을 다음 승인 기준으로 사용하지 않는다. 로컬 통합/필수 보호/관측 설계를 마친 구별 가능한 제한 시험으로 원인을 좁힐 수 있다. 원인 확정과 수정 성공은 그 후 관측으로 판정한다. 기존074를 그대로 재실행하는 것은 제외한다.
- **목표 단위 조정:** 다음 마일스톤은 새로운 helper나 번호가 아니라 저장→재읽기→결과 전달 또는 적재→비교→복귀 같은 하나의 연결된 동작이다. SD 수집기 일반화, 임의 카드 조합 확대, 이미 고정한 칩 식별은 범위에서 제외한다.
- **현재 상태 한 곳에서 관리:** 이번 계획과 준비도 표를 현재 판단 기준으로 삼는다. 과거 결과/해시는 보존하되 현재 인계 앞에 역사적 지시를 반복해서 추가하지 않는다. 주요 진전 때 계획 JSON·현황·등록부를 함께 갱신한다.
- **재검증 범위 제한:** 최종 변경과 사용한 입력의 영향표를 먼저 만든다. 변경 없는068 RTL의 조립/fit를 무조건 반복하지 않는다. 반대로 변경된077 하위 SD 경로를 과거070 전체 성공으로 승인하지 않는다.

P1과P2는 서로 기다릴 필요 없는 조사 범위지만, 이 검토가 자동 구현이나 병렬 에이전트 실행을 승인한 것은 아니다. 이후 사용자의 진행 요청 시P1부터 시작하고 P2의 독립 점검을 이어갈 수 있다. 보고서 전용 시험은 기존 검증된 경로만 사용한다는 영향 검토와P1/해당P3 조건을 충족하면 미완료CF68 타이밍 작업을 기다리지 않는다. CF68 시험은P2와 해당P3도 필요하다. 새 패키지 전달 시점은 이 범위별 완료 조건으로 판단하며 미측정 시간을 임의의 완료일로 약속하지 않는다. 물리 성공을 미리 요구하는 순환 조건과 실제 전기적 충돌/미식별 핀을 넘기는 판단 모두 피한다.

[12개 준비도 항목](NES-HARDWARE-READINESS-REVIEW.ko.md)을 최신 후보 기준으로 다시 평가하면 **완료4 / 부분7 / 미완료1**이다. H10은 과거070 성공을 취소한 것이 아니라, 변경된077을 포함한 현재 전체 세션은 미검증이므로 부분으로 판정했다. 이 수치는 제한 진단 체크리스트이며 NES 완성도·공수·일정 비율이 아니다.
