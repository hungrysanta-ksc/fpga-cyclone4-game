# MMC1014 모험도 4 무입력 60초 실기판

1. ZIP을 풀고 `MMC1014-ADVENTURE-60SEC-SD-ROOT` 폴더 **안의 내용**을 SD 루트에 복사합니다.
2. MMC1012에서 사용한 모험도 4 일본판 ROM을 `sd2snes/nes/mmc1014.nes`로 복사합니다.
3. SD 메뉴에서 **NES MMC3 1014.nh1**을 선택합니다. 입력 없이 60초 동안 오프닝에서 스테이지 데모로 전환되는지, 종료 후 메뉴로 복귀하는지 확인합니다.
4. 메뉴 복귀 후 SD의 `sd2snes` 폴더에서 아래 네 로그를 보관합니다. 두 번 실행할 때는 첫 회차 로그를 먼저 PC에 복사해 두면 회차별 비교가 가능합니다.

| 로그 | 확인할 내용 |
|---|---|
| `nes-budget-mmc1014.txt` | 1–30초 오프닝·30–60초 데모의 표시 수 |
| `nes-frame-mmc1014.bin` | 55–60초의 23행 화면과 조건에 맞는 패킷 순서·시각 |
| `nes-game-last-mmc1014.txt` | ROM 검증·실행·종료 결과 |
| `nes-progress-mmc1014.txt` | STOP·base 복구·메뉴 복귀 과정 |

MMC1012와 같은 보드·65816·계측량으로 비교합니다. 이번 ARM은 조건에 맞는 23행 화면에서 확정된 map 704B를 타일보다 먼저 발행합니다. 실기에서는 map을 보낸 화면의 표시 간격과 그 뒤 화면에서 캡처 한 번을 더 확보했는지 함께 봅니다.
