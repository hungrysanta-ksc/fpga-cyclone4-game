# MMC763–766 SMB3 실기 비교

모두 같은 707D 배경 CHR 수정 보드 로직을 사용합니다. 먼저 60초판 두 개를 같은 첫 레벨 동선으로 비교해 주세요. 장시간판은 보너스 진입과 수동 종료를 확인할 때 사용합니다.

| 역할 | 60초 자동 종료 | 장시간 수동 종료 |
|---|---|---|
| A · 기존 실기 ARM·표시 프로그램 | MMC763 | MMC764 |
| B · 753 ARM·751 표시 프로그램 | MMC765 | MMC766 |

## 설치

1. 전원을 끈 뒤 ZIP 안에서 한 설치 폴더의 **내용만** SD 루트에 복사합니다. 판을 바꿀 때 해당 폴더의 `sd2snes/firmware.stm`, FPGA 이미지, base·메뉴 파일을 함께 교체합니다.
2. MMC704·705에서 실행한 동일한 SMB3(J) ROM을 복사해 `sd2snes/nes/mmc763.nes`, `mmc764.nes`, `mmc765.nes`, `mmc766.nes` 중 설치한 번호에 맞게 이름을 붙입니다.
3. 메뉴에서 같은 번호의 `NES MMC3 763.nh1` 등 해당 항목을 선택합니다. ZIP은 설치용이며 게임 ROM·세이브·RESTORE는 제외했습니다.

## 시험 순서

- **MMC763 → MMC765** 순서로 첫 레벨에서 평소와 비슷하게 플레이하고 약 60초 뒤 자동 메뉴 복귀를 확인합니다. FPS는 로그의 **5–40초와 40–55초** 최종 표시 수로 나눠 계산하고 map·OBJ 작업량을 함께 봅니다. 두 판의 화면 움직임, 타일 밀림이 있었다면 장면과 대략적인 시각을 알려 주세요.
- **MMC764와 MMC766**은 시간 제한 없이 플레이할 수 있습니다. 월드 1의 레벨 1·2 뒤 스페이드에서 슬롯 결과와 월드 맵 복귀를 확인합니다. **L + R + Start + Select**를 함께 길게 눌러 STOP과 메뉴 복귀를 확인합니다. 의도한 수동 종료와 예기치 않은 메뉴 복귀를 구분해 주세요.
- 각 판을 종료하면 `sd2snes/nes-progress-mmc번호.txt`, `nes-budget-mmc번호.txt`, `nes-game-last-mmc번호.txt` 세 파일을 보관합니다. 같은 판을 재실행하면 로그가 덮어써지므로 재시도 전에 복사합니다. 실패한 실행도 따로 보관하면 부팅 타임아웃과 BG CHR 마감 오류를 구별할 수 있습니다.
