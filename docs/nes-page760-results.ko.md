# 760 · 957 오른쪽 map 페이지의 단일 패킷 비용

## 목표

753과 같은 map·OBJ에서 오른쪽 페이지 8개 패킷을 묶고, 759가 계산한 위상별 2.259 / 2.311ms 부족분을 넘는지 먼저 판정한다. 이 예산은 planner 진입 시각과 나머지 필수 거래 순서를 고정하고, 기존 SPI 드라이버 비용과 마지막 map의 수락→반환만 센 하한이다.

## 작업내용

- 753 양 위상의 955·957 WRAM 이미지와 실제 192B DATA 8개를 대조했다. 1,536B 중 4B 그룹 34개가 달라졌다. 기존 뱅크 serial 4B와 전체 결과의 두 16비트 검사합 4B를 한 번 전송한다. 48B 마스크+136B 값 또는 34개의 (2B 위치, 4B 값) 튜플을 인코딩했다. 각각 16B 공통 헤더와 3B SPI 프레이밍을 포함해 211B·231B이며 기존 256B 큐 슬롯에 들어간다.
- Mesen의 65816에서 751의 부팅, 프레임·sequence·길이·identity 검사와 실제 FIFO 반환을 사용했다. 957에서 첫 원본 패킷이 도착할 때만 WRAM에 진단 코드를 설치했다. 비활성 뱅크와 이전 serial, 범위·길이·소비량을 확인하고 변경분을 쓴 뒤, 대상 WRAM 1,536B를 직접 다시 읽어 두 합계를 검사한다. 위치 목록은 정렬·증가 순서를 검사한다. 기존 coverage·DMA descriptor에 등록한 뒤에만 ACK를 공개한다. 원본 8건을 한 건으로 바꿔 뒤따르는 sequence를 7 줄였다.
- 앞선 화면의 부팅·소비 기록을 보존하고, 묶음에는 첫 원본 패킷과 같은 도착 시각을 주었다. 뒤따르는 패킷은 기존 제안 시각과 실제 소비 credit에 따라 수락했다. 정상 재생 네 건에서 변경 명령 이전 65816 이벤트가 해당 위상 원본과 일치하고, 각 53화면의 WRAM·VRAM 및 RGB가 일치했다. 새 ARM 생산 코드나 FPGA를 연결한 시간은 이 비교에 포함되지 않는다.

## 성과

각 칸은 위상 1 / 위상 2다. SPI 비용은 2.625MHz와 753의 211B E1에서 측정한 평균 거래당 드라이버 비용을 적용했다. 65816 시간은 명령 실행에서 측정했다.

| 957 오른쪽 map | 753 전체 행 8건 | 48B 마스크 1건 | 직접 위치 1건 |
|---|---:|---:|---:|
| 버스 전송량 | 1,688B | 211B | 231B |
| SPI 시간 | 5.543ms | 0.693ms | 0.754ms |
| SPI 절감 | 기준 | 4.850ms | 4.789ms |
| 진입·헤더 확인 (ms) | — | 0.189 / 0.189 | 0.186 / 0.185 |
| 변경분 복원 (ms) | — | 5.875 / 5.875 | 2.075 / 2.077 |
| 독립 재검사부터 coverage·ACK까지 (ms) | — | 11.167 / 11.171 | 11.176 / 11.176 |
| 묶음 수락→반환 (ms) | 마지막 1건 0.581 / 0.582 | 17.231 / 17.235 | 13.438 / 13.439 |
| 부족분을 넘기기 위해 허용되는 묶음 수락→반환 (ms) | — | 3.172 / 3.121 | 3.112 / 3.060 |
| 고정 순서 예산 초과 (ms) | 2.259 / 2.311 | 14.058 / 14.114 | 10.326 / 10.379 |

기존 759 예산에서 마지막 1건의 수락→반환을 빼고 새 묶음의 수락→반환을 한 번 더했다. 원본의 8건 수락→반환 합계는 4.601 / 4.602ms이고, 일부가 다음 SPI와 겹친다. 후보에 유리하게 이 합계까지 전부 절감으로 인정해도 직접 위치 방식의 순절감은 −4.048 / −4.048ms다. 또 압축 없이 공통 헤더만 합친다고 가정하면 7건분의 19B와 드라이버 호출만 줄어 약 0.75ms 절감에 그치며 1,536B 원본은 1슬롯에 들어가지 않는다.

첫 원본 도착 시각을 준 재생에서 직접 위치 방식의 실제 마지막 map 반환은 첫 248선을 21.676 / 21.961ms 넘었다. 957 표시는 3→4 VBlank, 최종 ACK는 16.212 / 16.190ms 늦었다. 마스크도 4 / 4 VBlank였다. 이 결과는 생산·ROM 경쟁을 새로 실행한 수치와 구분한다.

직접 위치 방식의 위상 1에서 생략한 그룹의 WRAM을 1비트 손상시키면 0xE0으로 거부했다. 첫 변경 그룹을 쓴 뒤 STOP을 넣으면 0xE4로 취소했다. 두 경우 모두 956 화면이 유지됐고 957 최종 ACK가 공개되지 않았다. 초기 고정 도착 재생은 느린 수신기가 FIFO를 채워 overflow를 검출했다. 최종 비교는 네 슬롯이 찼을 때 다음 실제 반환까지 후속 수락을 미룬 기록이다.

시간 선행 조건에 미달해 753을 유지한다. 후보의 cold 재시작·메뉴 복귀·새 패킷 우선과 전체 908·E8·OBJ·단일 DMA 마감 재검증은 진행하지 않았다. 진단 본체는 491 / 467B이며 정적 ROM 링크·보드 FIT와 실기 설치본은 이번 단계의 산출물에 포함되지 않는다.

## 후속작업

753에서 955 최종 ACK 이후 957이 대상 뱅크를 다시 쓰기 전까지, 65816이 직접 확인한 행 이력을 어느 유휴 구간에 만들 수 있는지 계측한다. 저장된 이력의 손상과 확인 후 WRAM 변경을 모두 검출하고 STOP·부분 쓰기에서 무효화하는 비용을 포함한다. 직접 위치 목록의 수락→반환을 양 위상 모두 3.060ms 이내로 줄일 예산이 확보되면 ARM 전체 링크·credit·ROM 경쟁과 248선·E8·OBJ 마감을 다시 검증한다. 직접 위치 방식의 진입 및 복원 시간을 그대로 유지하면 위상 2에서 독립 검사·coverage·ACK에 남는 시간은 약 0.797ms다.
