# 749 · 957의 마지막 OBJ 수락과 257선 DMA 마감

727을 유지한다. ARM이 마지막 map 페이지 앞에서 직전 48B BG의 수신 ACK를 확인하고 E8로 다음 descriptor를 조회하면, 65816은 두 위상 모두 1,536B map DMA 시작 전에 288B OBJ의 수락을 끝낸다. 수락 여유는 7.053 / 6.726ms다. 그러나 694의 DMA 선택 시점에는 48B BG가 OBJ 앞에 남는다. OBJ의 첫 VRAM DMA는 다음 VBlank 226선이고 밀집 표시 간격과 957 최종 ACK 모두 늦어졌다.

## 같은 OBJ의 준비부터 수락까지

시간은 956 공개 이후의 ms다. 준비는 마지막 OBJ ROM 응답 뒤 staging descriptor가 확정된 시각이다. E8의 종류·섹션·길이·오프셋·세대·토큰을 E1 및 실제 65816의 staging 반환과 대조했다. E8 응답 수신, 검사 후 ARM 발행 함수 진입, E1 전송 완료, 65816 수신 ACK를 각각 관찰했다. 표시 승인은 별도의 최종 ACK로 비교했다.

## DMA와 표시 일정

두 시작 위상에서 각각 905–957의 실제 ARM 전체 링크, 694 ROM의 65816 명령 실행, 동일한 SPI·IRQ·ROM 경쟁 모델을 사용했다. 모든 후보의 53화면에서 패킷 종류·payload·작업량, RGB, map WRAM→VRAM 결과가 727과 일치했다. 밀집 간격은 951 공개부터 957 공개까지 여섯 간격의 평균이다. 양수 성능 차이는 727보다 늦음을 뜻한다.

모든 실행에서 952·957의 1,536B map 선행 DMA, 908·911 표시 2 VBlank, 951 공개 236선, 952 표시 3 VBlank와 957 최종 대기 0회를 유지했다. 727의 밀집 간격은 49.932319 / 49.932304ms, 페이지 앞 조회는 49.946287 / 49.940545ms였다. 패딩 배치만 변경한 이전 대조군의 변화는 +4.889 / 0µs, 최종 ACK +246 / 0클록이다.

페이지 앞 조회에서 map MDMAEN 시점의 WRAM descriptor 순서는 **BG 48B → OBJ 288B → map 1,536B**였다. 65816은 map을 먼저 전송하고 두 위상 모두 **BG 48B → OBJ 288B**를 남겼다. 이후 첫 선택은 257 / 254선이었고 해당 시점의 수신 큐는 비어 있었다. 같은 선에서 빔 검사로 전송을 보류했다. 선행 수락과 실제 DMA를 구분하는 근거는 694 명령 주소에서 관찰한 descriptor 순서, 보류 분기 및 MDMAEN 쓰기다. 검증용 코드는 ROM·WRAM 실행 경로를 수정하지 않는다.

## 자원·복구

- 장시간 ARM 전체 링크는 map 뒤 조회 212,752B, E0 진행 뒤 조회 212,756B, 페이지 앞 조회 212,784B다. 한도 212,992B 안에서 각각 240 / 236 / 208B가 남는다. 748의 영 패딩 배치를 사용해 세 후보 모두 727 대비 BSS가 240B 늘었다. FPGA는 707D, 65816은 694로 ROM 여유 26B다. 이번 시험은 펌웨어·시뮬레이션 비교이며 새 보드 합성이나 실기 측정은 수행하지 않았다.
- 각 ARM 전체 링크에서 기존 admission·기한·최종 ACK 17조건, receipt·STOP·wrap 9조건, 메뉴·base 복귀 5경로 및 로그 표식 4건을 검사했다. 페이지 앞 조회에서는 지연 반환·wrap, 잘못된 BG identity, receipt/E8 CRC, OBJ 세대 오류와 STOP을 포함해 8조건을 추가했다.
- 선행 수락에 성공한 두 후보는 두 위상에서 실제 65816으로 오류를 주입해 재생했다. 957 STOP·오래된 OAM identity에서 최종 ACK를 발행하지 않고 956 화면을 보존했다. 긴 map DMA 도중 다음 실제 패킷을 공개하면 두 위상 모두 추가 DMA보다 먼저 그 패킷을 읽었다.
