# NES155 — SMB3 배경 읽기 선행 처리 시험

154에서 스테이지 전환 순간 배경 데이터가 샘플 기한까지 도착하지 않은 사실을 확인했다.155는 타일 번호가 확정된 앞 구간에서 배경 패턴 읽기를 준비한다. 짧은 충돌 모델에서는 오류를 없앴지만, 실제 게임의 같은 정지가 해결됐는지는 이번 실기로 확인한다.

## 설치

1. 전원을 끄고 현재 SD의 `firmware.stm`을 별도 백업한다.
2. ZIP의 `01-GAME155-SD-ROOT` 안의 내용을 SD 루트에 복사한다.
3. 메뉴에서 `NES GAME 155.nh1`을 실행한다. 0바이트 표식이며 확장자는 바꾸지 않는다.

펌웨어와 FPGA는155 조합(64/DE)을 사용한다. ROM은 `sd2snes/nes/game155.nes`다. 개인용 ZIP에 사용자 ROM이 포함되어 있으므로 공개하지 않는다.

## 한 번의 실기 시험

- 로딩은 이전과 같으며,151 실측 약3분50초를 참고한다. 로딩 영상은 필요 없다.
- 첫 Start로 선택 화면, 다음 Start로 다음 장면에 진입한다. 각 입력 후 버튼을 떼고 화면을 확인한다. 이전154처럼 전환 때 종료되는지 확인한다.
- 계속 진행된다면 방향키와 A/B로 이동·점프 등을 확인하고 게임 화면부터 짧게 촬영한다. 같은 증상으로 종료된다면 영상 없이 로그만 전달해도 된다.
- 게임 실행은 최대 약60초이며 오류가 감지되면 조기 종료한다. 실행 후 총7분이 지나도 메뉴로 돌아오지 않으면 전원을 끄고 남은 로그를 전달한다.7분은 관찰 상한이다.

## 전달 자료

전원을 끈 뒤 다음 두 파일, 메뉴 복귀 여부와 전보다 진행된 장면을 전달한다.

- `/sd2snes/nes-progress-155.txt`
- `/sd2snes/nes-game-last-155.txt`

오류 문맥과 PPU 상태 기록·STOP·메뉴 복귀는154와 같다. `ppu_state`의 hint 비트는155부터 일반 배경 선행 읽기도 포함한다. 로그는 직접 해독할 필요 없다.

현재 약0.5초 화면 유지, DMA 중 입력 공백, 무음·저장 미구현은 남아 있다. CRT 촬영의 대각선 띠는 오류로 판정하지 않는다.154·A/B 패턴·044/GBC 복원 시험을 다시 보고할 필요는 없다. 정상 사용으로 돌아갈 때는 전원을 끄고 `02-RESTORE044-SD-ROOT` 안의 내용을 복사한다.
