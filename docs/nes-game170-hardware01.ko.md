# NES170 실기 — 13회 표시 후 영상 데이터 수집 시간 초과

사용자는 화면이 몇 번 끊겨 갱신된 뒤 도입 장면에서 멈췄지만, 스타트는 반응하고 음악은 계속 나왔다고 보고했다. 사진 색상과 CRT 촬영 간섭은 오류 판단에서 제외한다. **첫 화면 출력은 성공했으나 연속 화면·정상 플레이 목표는 미달성이다.**

## 화면만 멈춘 이유

배포한169/170 공통 FPGA의 ABORT는 상위4비트에 fill 사유, 하위4비트에 exporter 사유를 넣는다.0x34는 **fill 실패4 + fill 전체 MAX_CYCLES 초과3**다. 짧은 응답 대기 초과4, ROM 오류, SNES의 E3와 구분된다. 최초와 마지막 중단만 사유가 저장되어 있으므로 중간6회까지 동일 원인이라고 확정하지 않는다.

현재 fill 전체 제한은16777216클록, exporter 제한은33554432클록이다. fill은 busy 동안 매 클록 전체 시간을 센다. COOPERATIVE_WAIT는 메모리 승인 대기 REQUEST와 소비자 대기 STREAM을 짧은 제한131072클록에서 제외하지만 **전체 제한에서는 제외하지 않는다**. 메모리 승인은 NTSC/MMC3 vblank 구간과 CPU 캐시·DMA 등 조건을 만족할 때만 허용한다. 따라서 코어가 정상 실행 중이어도 다음 화면의 CHR 데이터 수집·전송이 제한에 걸릴 수 있다.

수신기는 ABORT 후보를 버리고 IDLE로 돌아간다. 완성 후보의 COMMIT과 SNES SEAL/표시 ACK까지 성공해야 표시 횟수가 증가하므로, 실패한 후보로 화면을 갱신하지 않고 기존 그림을 유지한다.13번 완료 뒤 마지막 표시 세대27에 머물고 세대29부터 중단한 기록은 사용자 관찰과 부합한다. 정확히 어느 순간 화면이 멈췄는지, 승인 대기와 SPI/소비자 대기 중 어느 쪽이 시간을 지배했는지는 현재 로그로 나눌 수 없다.1892는 최초 실패 후보에서 받은 CHR 바이트이며 프레임 전체 크기나 전송 처리량이 아니다.

## 다른 오류와 구분

- native_receiver_error21은 상태 통신 콜백 실패 또는 상태 형식 오류의 공통 코드다. runtime guard가60초 만료를 먼저 기록하면 이후 receiver 실패가 그 결과를 덮지 않는다. 이번 최종 native_result1과60010ms는 **정상 제한에 따른 마지막 수신 중단**에 부합하며21만으로 SPI 손상을 주장하지 않는다.
- 스타트 눌림·해제가3쌍 기록됐고 음악 지속은 사용자 확인이다. 모든 버튼·입력 유지·첫 레벨 정상 플레이까지 입증하지는 않는다.
- screen_error169는 이 후보에서 SPC 초기화 결과 A9이며 unmute1이다. screen_frames0은 비신뢰 구형 표시 카운터로, native_frames13을 무효화하지 않는다.
- 169의 첫 BEGIN 실패는 이번에 재현되지 않았다.170은 진단만 추가했으므로 그 원인이 수정됐다고 확정하지 않는다.13회 ACK만으로169의 E2/E3 대형 전송 분기 자체가 실행됐다고도 확정할 수 없다.

## 다음 작업

다음은 CHR 수집·전송의 전체 예산 초과를 수정한다. 실제 vblank/CPU 우선 메모리 승인과 SPI 소비자 대기를 포함해 최초 중단1892바이트·0x34를 재현하고 병목을 구분한다.167에서 이미 전체 예산을8배 늘렸으므로 단순 재증가를 반복하지 않는다. 승인 기회·전송 오버헤드를 줄이거나 측정 근거로 유한한 진행/전체 예산 계약을 정하고 변경 경계만 검증한 뒤 SMB3 실기로 간다.169 첫 BEGIN 실패는 이번 미재현이며 해결 확정은 아니다. 같은170/044·무변경FIT·추가 영상은 요청하지 않는다. 연속 AV→장기 플레이/오류·리셋 로그→입력 유지 순서와 코어 우선권·PSRAM 타이밍·세이브 SRAM/GBC/164 보호를 유지한다.

이번에는 결과·계획만 기록했다. 새 펌웨어·FPGA·ZIP은 만들지 않았다. 기존170 시험판 준비 검증과 과거 실패 근거는 보존한다. 원본 두 TXT와 사진은 비공개 보관하고 [필드·시간·해시·배포 소스 대조](../analysis/game170-hardware01-verification.json)를 공개한다.
