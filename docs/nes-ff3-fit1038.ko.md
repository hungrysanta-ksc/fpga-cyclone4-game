# FF3 상태 저장 회로와 전체 보드 배치

FF3 보드의 조합 논리가 16,336개에서 15,286개로 줄었다. Cyclone IV E EP4CE15F17C8의 조합 논리 한도에는 122개 여유가 생겼다. 전체 배치는 16,371 LE와 1,040 LAB를 요구해 실패했다. 소자 한도는 15,408 LE, 963 LAB다. 이 보드로 최종 STA를 측정하거나 설치 이미지를 만들 수 없다.

## 같은 장치에서의 합성 비교

| 후보 | 조합 논리 | 바꾼 회로 |
|---|---:|---|
| 1037 | 16,336 | FF3 화면·저장 회로 기준 |
| walk | 16,002 | 저장 파일은 워드 인덱스 하나로, 코어 메모리는 영역별 상위 주소와 13비트 오프셋으로 순회 |
| serial | 15,962 | SPI 전송 중 CRC와 워드 에코를 검사하고 응답 스냅샷과 수신 워드의 중복 저장을 축소 |
| row | 15,722 | 직전 33셀을 map RAM에서 다시 읽음. 이 구성은 M9K 57개 요구 |
| packed | 15,738 | 행 descriptor까지 map RAM의 서로 다른 주소에 배치해 M9K 56개로 회복 |
| rank | 15,611 | 스프라이트 rank별 키·마스크를 기존 OBJ RAM에서 읽고 연속 갱신은 전달 회로로 처리 |
| mixer | 15,286 | map RAM 블록 배치를 조정하고 기존 APU 믹서 테이블 값을 M9K에서 읽음 |

저장 주소와 SPI 변경의 전체 보드 순감소는 374개다. 이후 세 변경 영역은 모두 FF3 보드 생성기에만 적용했다. mixer의 15,286개 조합 논리 외에 레지스터만 사용하는 LE가 1,085개다. M9K는 56/56개다. FF 수나 남은 메모리 비트를 가용 LE 또는 추가 RAM 포트로 환산할 수 없다.

## 검증 범위

- 첨부 FF3를 실행한 코어 시험에서 배터리 RAM 8,192바이트와 상태 워드 2,658개를 검사했다. 콜드 초기화 후 복원한 첫 64개 CPU 명령 경계와 이어지는 두 화면의 PPU 픽셀 122,880개가 연속 실행과 일치했다. 저장·복원 응답을 보류한 상태에서 각각 STOP을 넣은 시험도 통과했다.
- SPI 시험은 잘못된 CRC, 워드 에코 및 인덱스, 재시도와 STOP을 포함한다. 부팅 시험은 배터리 접근을 끝낼 때까지 CPU가 해제되지 않는지 확인한다.
- CHR 표시 경로는 8 KiB 스냅샷, BG·OBJ 바이트 순서, 캡처 중 변경, 지난 세대 반환, STOP·cold 시험을 통과했다. 원본 캡처 RTL과 변경 RTL은 224행, 유효 조회 1,164건에서 일치했다. APU는 DAC 샘플 에지에서 삼각파·노이즈·DMC 입력 32,768조합을 원본과 대조했다.
- 메뉴를 연 실제 SNES 화면, SD에서 파일을 재선택한 뒤의 장면 복귀, 외부 SRAM을 포함한 보드 타이밍은 미검증이다. 코어 시험 장면의 화면은 3색이며 게임 플레이 중 고른 부하 장면은 후속 실기 검증 대상이다.

## 재개 지점

Fitter 오류 170012의 77 LAB 부족분이 다음 목표다. MAP의 상태 레지스터 하위 모듈 20개에 전용 레지스터 914개가 잡힌다. 다음 후보는 일시정지 중 팔레트·매퍼 등에서 복원 대기용 사본과 실행 레지스터를 함께 보유하는 구간이다. 직접 기록할 수 있는 필드부터 확인하고, 부분 복원 뒤 STOP·콜드 재시작과 완료 전 실행 차단을 먼저 검증한다. 914개는 조사 대상의 크기이며 배치에서 회수한 면적은 새 FIT로 측정한다.

배치에 성공하면 전체 STA를 확인한 뒤 L+R+START 메뉴, 일반 저장, 상태 슬롯, 재선택·장면 복원 순으로 연결한다. 설치본은 그 결과로 판정한다.

작업 루트의 `probes/nes-ff3-1038/lite-mixer/board.fit.summary`, `board.fit.rpt`, `board.map.rpt`에 최종 수치가 있다. 중간 후보는 같은 상위 폴더의 `lite-*`에 있다. RTL 원시 로그 사본은 `probes/nes-ff3-1038/verification/`에 있다. 보드는 `tools/prepare_ff3_display1037.py`로 생성하고 `tools/fit_ff3_display1037.ps1`로 빌드한다. 두 Questa 시험 진입점은 `tools/check_ff3_checkpoint_rtl.ps1`과 `tools/check_ff3_display1037.ps1`이다.
