# 1062 이무르 이동과 테트리스 실기 결과

## 목표

드래곤 퀘스트 IV에서 1062의 ARM 명령 수 절감이 끊김을 줄였는지 판정하고, 다음 호환성 시험 대상을 선정한다.

## 작업내용

동일한 슬롯 1·저널 4·본문 CRC `caa52cd8`를 복원한 뒤 첫 방향 입력부터 5.5초 동안 실제 공개된 화면을 집계했다. 1061과 1062 각 두 회차이며 네 파일의 STOP·base 복귀와 디버그 진행 로그의 마지막 순번도 확인했다. [실기 집계](../analysis/nes-hardware1062.json)

## 성과

|버전·회차|표시 수|표시 FPS|공개 간격 P95|직전 ACK→마지막 타일 반환 평균|
|---|---:|---:|---:|---:|
|1061 1차|68|12.36|99.86ms|54.09ms|
|1061 2차|71|12.91|99.86ms|50.85ms|
|1062 1차|69|12.55|99.86ms|52.78ms|
|1062 2차|78|14.18|83.48ms|43.25ms|

버전별로 11초씩 합하면 139→147장, 12.64→13.36 FPS(+5.76%)다. 1062 1차는 6 VBlank 간격이 18번, 2차는 0번이었다. 두 회차를 버전별로 합쳐 좌표·방향·변경 행·타일 바이트가 같은 16개 조건의 평균을 같은 가중치로 비교하면 77.79→72.82ms(각 25개 간격)다. 네 회차 각각에 모두 등장한 조건은 1개뿐이다. 1062를 유지하되 동일 장면에서 반복 재현되는 가속률은 아직 정할 수 없다.

테트리스 일본판은 보드 `81`, ROM CRC `6118313f`로 START, 오류 0, STOP·base·MENU_PREPARED를 기록했다. 게임 실행은 사용자가 실기에서 확인했다. 테트리스의 이무르 이동 계측 창은 비어 있어 이 게임의 FPS는 산출하지 않았다.

## 후속작업

드퀘4 추가 미세 조정은 보류한다. 다음 대상은 한글 젤다 1·2가 공유하는 MMC1의 PRG ROM 256KiB·CHR RAM 8KiB·배터리 RAM 8KiB 구성이다. 두 ROM 각각 1,800프레임 동안 Mesen의 뱅크 쓰기 전체를 기록했다. 독립 Questa 시험에서 젤다 1의 쓰기 26,259회, 젤다 2의 쓰기 17,894회를 새 매퍼 RTL에 재생하고 각 240개 PRG·CHR·네임테이블 주소 표본이 일치했다. 별도 경계 시험에서 PRG 모드·뱅크 전수, CHR 선행 주소, 연속 쓰기 억제, 직렬 쓰기 중간 상태 복원, RAM 접근 허가를 확인했다. 참조 ROM의 메뉴·게임 전체를 FPGA에서 구동했다는 결과는 아니다.

보드의 실제 CPU 쓰기 클록과 CHR 캡처·SRAM·슬롯 경로를 먼저 연결하고, CPU 실행 및 저장 복원·Quartus Lite 전체 FIT/STA를 확인한 뒤 DEBUG·RELEASE로 전달한다. FF1&2의 512KiB 상위 PRG와 네 SRAM 뱅크는 다음 구성으로 분리한다. 게임별 속도 시험은 화면 전환·스크롤·스프라이트 밀집 중 재현 가능한 구간을 세이브로 고정해 후보로 남긴다. [호환성 계획](nes-cartridge-compatibility-plan.ko.md)
