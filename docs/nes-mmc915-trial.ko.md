# MMC915 · 모험도 4 무입력 60초 실기판

1. 전원을 끄고 ZIP 안의 `MMC915-ADVENTURE-60SEC-SD-ROOT` 폴더 **내용물**을 SD 카드 루트에 복사한다.
2. MMC907에서 사용한 `sd2snes/nes/mmc907.nes`를 같은 폴더에 **`mmc915.nes`**라는 이름으로 복사한다.
3. 메뉴에서 **NES MMC3 915.nh1**을 실행한다. 버튼을 누르지 않고 오프닝에서 스테이지 데모로 전환되는지, 60초 뒤 자동으로 메뉴에 복귀하는지 확인한다.
4. 재실행 전에 SD의 `sd2snes` 폴더에서 **nes-budget-mmc915.txt**, **nes-frame-mmc915.bin**, **nes-progress-mmc915.txt**, **nes-game-last-mmc915.txt**를 보관한다. BIN에 55–60초의 ROM 허가와 캡처 관련 시각이 들어 있다.

## 비교 기준

| 표시 완료 구간 | MMC907 실기 |
|---|---:|
| 1–30초 오프닝 | 597장 / 29초 = 20.59 FPS |
| 30–60초 데모 | 592장 / 30초 = 19.73 FPS |
| 55–60초 데모 부분 구간 | 92장 / 5초 = 18.40 FPS |

55–60초에는 세대별 요약과 상세 화면 한 장을 남긴다. MMC907 실기에서 선택된 56.46초 화면은 BG 529·OBJ 14·변경 map 9, 타일 9개·묶음 4개였다. ROM 허가는 64회, 첫 E9부터 마지막 OBJ 준비까지 18.725ms, 입력 완료부터 ARM이 확인한 최종 ACK까지 57.094ms였다. MMC915는 이 작업량을 우선해 상세 화면을 선택한다. 분석기는 두 실행의 묶음별 종류·크기까지 일치하고 시작 시각 차이가 0.30초 이내일 때만 ROM 허가·지연 변화량을 계산한다. 914I의 허가 수에는 선행 읽기가 포함된다.

캡처 여유의 기준은 해당 세대의 COMMIT D2 반환이다. MMC915는 ARM 수신 단계의 기존 시작·종료 타이머로 이 반환이 들어간 구간을 기록한다. FPGA의 ROM 허가는 NES 242–259선에서만 발생하고 다음 캡처 기회는 7선 dot 257이다. 분석기는 허가 타임스탬프, ARM 수신 구간, FPGA 조회 소요 시간을 함께 사용해 가장 가까운 캡처선까지의 **부호 있는 범위**를 계산한다. 양수면 D2 반환이 먼저였고 음수면 캡처선이 먼저였다. 범위에 0이 들어가면 선후를 판정하기 어렵다. 이는 실제 캡처 수락을 직접 기록한 값과 구별한다.

이 계산은 정상 NTSC 진행과 두 클록의 상대 오차 0.1% 이내를 가정한다. FPGA 시각의 분해능은 약 390µs이므로 수십 µs의 여유는 단정하기 어렵다. MMC907은 COMMIT D2 시각이 없어 END와 최종 ACK로 범위를 제한한다. 기준 화면의 두 시각은 한 프레임 이상 떨어져 있어 MMC907의 캡처 여유를 µs 단위로 복원할 수 없다. 두 버전의 실기 FPS·ROM 허가·최종 ACK는 각각 직접 비교한다. 비교 명령은 `python tools/compare_nes_trial915.py <MMC907 로그 폴더> <MMC915 로그 폴더>`다.

## 전달 구성

914I의 Quartus Lite 전체 FIT·STA를 통과한 SOF에서 변환한 BI3, 그 보드에 내장된 912 표시 ROM, 913idle을 기반으로 이름과 계측을 갱신한 60초 ARM 펌웨어를 사용한다. STM3 크기는 212,980 / 212,992B다. 실기 FPS는 위 네 파일로 판정한다.

재현할 때는 `tools/prepare_nes_trial915.py`의 `patch --step`으로 선택한 펌웨어 소스를 준비한다. 최종 링크·보드 응답 재생에는 같은 `--step`의 `wire`와 `replay`를 사용한다. `tools/package_nes_trial915.py <작업 임시 폴더> --step`은 네 조건의 재생, 보호 시험, 보드 이미지와 표시 ROM의 일치를 확인한 뒤 ZIP을 구성한다. [최종 링크·검증 수치와 파일 해시](../analysis/trial915-package.json)
