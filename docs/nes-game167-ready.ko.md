# NES167 — 그래픽 수집 대기 수정 실기 시험

166에서 소리는 나지만 화면을 완성하기 전에 그래픽 수집이 계속 취소됐다.167은 정상적인 메모리 사용권·데이터 소비 대기를 읽기 응답 오류와 구분한다. 새 FPGA와 펌웨어의 사전 검증을 통과했으며, **실기에서 화면이 복구되는지는 이번 시험으로 확인한다.**

1. ZIP을 풀고 `01-GAME167-SD-ROOT` **안의 내용**을 SD 루트에 복사한다. `sd2snes/firmware.stm`과 `sd2snes/fpga_n167.bi3`를 함께 적용한다. 폴더 자체를 SD 루트에 넣지 않는다.
2. 메뉴에서 `NES GAME 167.nh1`을 실행한다.0바이트 표식이 정상이며 확장자를 바꾸지 않는다. ROM 적재·검증은 기존과 같아 약4분 걸릴 수 있다.
3. 게임 화면이 나오면 스타트→플레이어 선택→월드맵→첫 레벨 진입을 시도한다. 화면 움직임과 소리가 담긴20~30초 영상이 있으면 좋다. 계속 검정 화면이면 촬영·조작은 필요 없다.
4. 게임 실행·소리 시작 후 약60초 뒤 자동 메뉴 복귀를 기다린다. 표식 선택부터 전체7분 이상 무반응이면 대기를 끝내고 마지막 상태를 알려준다.
5. `sd2snes/nes-progress-167.txt`와 `sd2snes/nes-game-last-167.txt`, 화면·소리·메뉴 복귀 여부를 전달한다. 마지막 TXT가 없으면 진행 TXT만 전달한다.

RUN 중에는 SD에 쓰지 않고 안전 정지 후 최종 TXT를 남긴다. 별도044/GBC 복원 반복 시험은 필요 없다. 문제가 있어 기존 상태로 돌아가려면 동봉한 `02-RESTORE164-SD-ROOT`의 내용을 SD 루트에 복사한다. 기존 세이브 파일과 카트리지 별도 SRAM은 영상 공간으로 사용하지 않는다.

이번에는 화면 출력 복구를 먼저 판정한다.60fps·입력 유지 품질·60초 제한 해제는 아직 완료된 것으로 보지 않는다. 로그 숫자는 해석하지 않고 그대로 전달하면 된다.
