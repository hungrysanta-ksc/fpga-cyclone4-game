# 596 · nonmap 페이지 묶음과 D4·NES 회로 예산

595와 같은 데이터를 보내면서 nonmap을 입력당 32페이지에서 6페이지로 줄일 수 있다. 이로써 없어지는 고정 비용은 78거래·546 B다. 회로는 개선 여지가 있지만 선택 상한 1,816 LE에는 도달하지 못한다. 세 가지 동일 경계 Quartus Lite 진단 중 결합 결과가 2,708 LE였고, 여기에 안전한 명령 유지와 페이지 묶음 회로를 추가해야 한다. 실기 기준은 MMC577이다. [프레임별 계산과 MAP 결과](../analysis/pages596-verification.json)

## SPI 전송 예산

581의 해시 고정 입력 905–957 각각에서 595 RTL과 같은 종류·32항목 경계·반복/linear 판정으로 블록을 만들었다. 원본 값 복원과 블록 순서를 검사했다. 페이지의 유효 길이는 254 B이며 그중 2 B가 phase와 ordinal이다. metadata와 raw는 서로 다른 페이지에 두고, 각 END와 COMMIT은 595처럼 독립 페이지로 남겼다. [계산기와 ARM 시험](../tools/budget_nes_pages596.py)

| nonmap 데이터 페이지 | 595 · 블록별 봉인 | 한 페이지 · literal 예약 | 압축 길이를 미리 아는 비교값 |
|---|---:|---:|---:|
| 입력당 · 53개 모두 | 32 | 6 | 5 |
| 53입력 합계 | 1,696 | 318 | 265 |

선택한 예약 방식은 다음 블록의 3 B 헤더와 최대 literal 본문이 남은 252 B 안에 들어갈 때만 같은 페이지에 쓴다. 반복·linear로 줄어들면 다음 쓰기 위치를 실제 끝으로 되돌린다. 최종 길이를 미리 아는 5페이지 방식은 별도 scratch 또는 재조회 비용이 필요할 수 있다. 6페이지 예산은 추가 페이지 RAM이나 collector 재조회 없이 계산했다. 구현에는 블록 시작 위치, 남은 용량 비교, 헤더 되쓰기 주소와 seal 후 재개 상태가 필요하다.

페이지 하나를 없애면 D1의 prefix 2 B·명령/CRC 3 B, D2 8 B, 594 ARM이 D2마다 수행하는 D0 token 확인 8 B가 사라진다. 독립 데이터 블록과 END CRC는 그대로다. 이를 합치면 26페이지당 **78거래·546 B**, 53입력에서 **4,134거래·28,938 B**다. SPI 2.625 MHz에서 입력당 wire 점유 1.664 ms에 해당한다. [594의 수신 경로](nes-receiver593-results.ko.md)

| 전체 입력 | 595 핀 관측 | 6페이지 계산 · 나머지 조회 수 고정 |
|---|---:|---:|
| cold 905 | 47패킷 · 202거래 · 4,402 B | 21패킷 · 124거래 · 3,856 B |
| warm 906 | 39패킷 · 172거래 · 2,692 B | 13패킷 · 94거래 · 2,146 B |

905·906의 원래 전체 wire는 D4 횟수·수신 길이·페이지·거래 수로 각각 정확히 재구성했다. 합쳐진 페이지가 늦게 준비되면 ARM이 빈 D0를 더 보낼 수 있다. 나머지 D0의 순증가를 q라 하면 실제 순절감은 78−q거래, 546−8q B다. 입력당 69회가 더 생기면 바이트 이득이 사라진다. 다음 비교에서는 반환 확인의 ready 재사용, 새 빈 조회, query 지연을 따로 기록해야 한다. 이번 계산에서 첫 BG·최종 표시 시각은 산출하지 않았다.

## 합성으로 가격을 확인한 삭제 항목

595와 같은 Quartus Lite 25.1·EP4CE15F17C8·region 포트·mailbox 원본에서 진단별로 새 MAP을 실행했다. 세 번 모두 RAM은 2,048 bit였다. [MAP 재현 도구](../tools/map_nes_budget596.py)

| 지역 MAP | LE | 조합 함수 | FF | 595 대비 LE |
|---|---:|---:|---:|---:|
| 595 기준 | 3,041 | 2,308 | 1,278 | — |
| D4 명령 복제 두 벌 제거 | 2,761 | 2,298 | 1,008 | −280 |
| NES CRC16·주소 진행 공유 | 2,993 | 2,260 | 1,249 | −48 |
| 두 삭제를 같은 회로에 적용 | **2,708** | **2,245** | **979** | **−333** |

- **D4 명령.** 기존 host의 action·identity·bitmap을 남기고 mailbox의 135비트 held와 135비트 received를 제거했다. 진단 회로에서는 유효 이벤트만 mailbox로 넘기고 NES는 host의 명령 버스를 직접 참조한다. 이것으로 FF 270개가 사라지는 것을 확인했다. 제품 후보는 첫 바이트부터 전송 적법성을 판정하고 NES 수락의 ACK가 돌아올 때까지 같은 host payload의 모든 쓰기(D2/D3 및 잘못된 D4 포함)를 막아야 한다. 원본 D4 CRC·epoch·serial·generation·token·bitmap 검사, STOP 양쪽 무효화, 첫 D0에서 토글 확인을 유지해야 한다. 묶음 데이터의 물리 지연·skew와 고장/클록 정지 시 차단은 별도 검증 대상이다. 진단 MAP에는 이 추가 비용이 빠져 있다.
- **CRC.** 원본 map을 읽을 때 CRC16을 누적하고 요청 행과 REPAIR를 내보낼 때 같은 상태를 고정한다. MAP_ACCEPT 뒤 같은 누적기를 nonmap에 이어 쓴다. 기존 stream_crc 16비트와 별도 CRC16 update/선택을 삭제할 수 있다. warm 행 요약의 CRC32, SPI D1/D4 CRC, ARM의 독립 map·metadata·raw 검사는 모두 유지한다.
- **주소.** row_base 13비트와 row_base+word_at 조회 주소 생성을 삭제했다. 활성 cursor 하나가 map의 매 단어에서 +1, 생략 행에서 +33, 새 nonmap 종류에서 0부터 진행한다. 33단어 종료와 첫 값 판정에 쓰는 word_at, 행 번호와 mask, 헤더에 기록하는 행 시작 주소는 여전히 필요하다. CRC·주소 합성의 FF 순감 29개는 두 누적 상태의 16+13비트와 일치한다.

결합 진단은 1,225 LE 중 333 LE를 설명한다. **아직 892 LE가 필요하다.** 조합 함수만 2,245개여서, 모든 레지스터를 이상적으로 배치해도 현재 조합 함수 수를 최소 429개 더 줄여야 한다. 892에는 CDC 보호, 묶음 페이지 제어의 비용이 아직 들어 있지 않다. MAP 차이는 계층별로 단순 합산하거나 전체 보드 FIT 절감으로 해석할 수 없다.

## 보호 조건과 다음 판정

594 전체 ARM ELF를 모델 상대 장치와 연결해 6페이지 방식의 cold 905·warm 906 복원, warm 907의 부분 metadata 수신 뒤 STOP/reset, 다음 cold에서 CRC 오류로 29개 전체 행을 복구하는 경로를 확인했다. 정상 최종 ACK는 표시 1회·EA 후 IDLE, 틀린 generation은 표시 0회·EA 차단, EA 중 STOP은 표시 1회·COMMITTED였다. 595의 실제 핀 보호 시험과 별도로 수행했다. 596의 진단 MAP은 이 시험의 상대 장치가 아니며 CDC 안전성·VBlank 타이밍·실기 복귀를 인증하지 않는다. [595 핀 시험 범위](nes-region595-results.ko.md)

다음 한 단계는 **NES의 64비트 값/첫 값/이전 값 보관·raster 비교·header/END 바이트 선택과 host의 SPI 응답 snapshot/CRC 생성**까지 포함해 삭제할 조합 회로를 산정하는 것이다. 동일 페이지를 명령과 데이터에 공유하는 대안은 host 쓰기/NES 읽기 포트 및 검증 전 D4가 봉인 페이지를 덮지 못하는 소유권까지 계산한다. 추가 제어를 포함해 892 LE를 설명할 근거가 생길 때만 안전한 결합 RTL과 두 시작 위상 시험으로 진행한다.

재현 순서는 `map_nes_budget596.py <새 MAP 디렉터리>`, 이어서 `budget_nes_pages596.py --arm <594 ARM01/src> --archive <581 evidence01.zip> --maps <MAP 디렉터리> --out <결과 JSON>`이다.
