# NES164 — 반복 점멸 제거·SMB3 화면 시험

163에서 성공한 사운드를 유지하고, 첫 화면 이후에는 표시를 끄지 않은 채 수직 공백 시간에 나눠 전송한다. 이번 목표는 **반복되는 검정 구간 제거**다. 전체 화면은11번에 걸쳐 부분 갱신되므로 움직임의 계단·위아래 혼합은 남을 수 있다. 부드러운60fps나 완성된 연속 화면으로 판정하는 시험은 아니다.

1. ZIP의 `01-GAME164-SD-ROOT` **안의 내용**을 SD 루트에 덮어쓴다. 펌웨어와 FPGA 파일을 함께 적용한다.
2. `NES GAME 164.nh1`를 실행한다.0바이트 표식이 정상이며 확장자를 바꾸지 않는다.
3. 처음 화면을 준비하는 짧은 검정 구간 이후, 제목 →1PLAYER →월드맵 →첫 레벨로 진행한다. **플레이 중 반복해서 화면 전체가 검게 꺼지는지**, 이동·점프 때 화면이 얼마나 늦게 따라오는지 확인한다. 가능하면 첫 레벨 플레이15~30초를 소리와 함께 촬영한다.
4. 소리가 계속 정상인지, 조작 반응이 있는지 확인한다. 버튼 유지 문제의 최종 판정은 화면 갱신 속도를 더 개선한 뒤 진행한다.
5. 기존처럼 실행 구간 약60초 후 메뉴에 자동 복귀하는지 확인한다. 제목·월드맵 시간도 포함한다. `sd2snes/nes-progress-164.txt`, `sd2snes/nes-game-last-164.txt`와 영상·메뉴 복귀 결과를 전달한다.

적재 시간은 이전 약3분50초를 참고한다. 이번에는 적재량·검증 절차를 바꾸지 않았다. 전체7분 이상 무반응이면 대기를 끝내고 남은 TXT와 상태를 전달한다. 리셋으로 로그를 저장하는 기능은 아직 없다.

로그의 `spc_init_status_hex=a9`·`spc_unmute_confirmed=1`·`screen_error=169`는 본체 사운드 초기화 성공이다. 게임 오류는 `run_error`·`run_rom_error`로 구분한다. 카메라와 CRT의 주사 간섭 띠는 이미 알려진 현상이므로 화면 전체 점멸과 구분한다.

FPGA 로직·배치를 재사용해 내부 식별6B/E5가 정상이다. 이 식별이나 A9만으로164 파일을 적용했는지 구분할 수 없으므로 두 파일을 함께 복사한다. 동봉 manifest에 파일 해시가 있다. 044/GBC 복원 시험은 반복하지 않는다. 정상 사용으로 돌아갈 때는 동봉 `02-RESTORE044-SD-ROOT`를 사용한다.
