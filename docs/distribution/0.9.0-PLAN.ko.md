## 첫 릴리스 결정

- 제품: sd2snesHST 0.9.0, HST = HungrySanTa.
- 구현 기준: 실기 확인된 GBC C44, 소스 커밋 `35ef4aef14fc6abef6495a980b7f00f257e5174f`.
- 대상: FXPAK Pro / Mk.III STM32 + Cyclone IV EP4CE15F17C8.
- 설치 방식: 정상 설치된 공식 sd2snes 1.11.2 계열 위의 업데이트.
- 실행 파일 내용은 C44 그대로 유지합니다. 제품명·버전은 배포 이름, 문서, manifest, 태그에 표시합니다.
- 기기 화면의 기존 코어 제목이나 기반 펌웨어 버전 문자열 변경은 0.9.0 포장 작업에 끼워 넣지 않습니다. 나중에 변경하면 별도 후보 검증을 거칩니다.

## 검증을 반복할 범위

C44 실행 파일이 그대로라면 전체 게임 시험과 FPGA 재합성을 반복하지 않습니다. 패키지 누락, 해시, 사용자 문서, 시차 설정 보존, 기존 SD에 덮어쓰는 파일 목록을 점검합니다. 실행 파일·컴파일 옵션·메모리 배치가 바뀌면 C44와 동일한 후보로 간주하지 않고 영향에 맞춰 다시 검증합니다.

현재 C44의 SRAM/RTC/강제 저장 형식과 로그 OFF 정책을 유지합니다. 기존 사용자 저장을 마이그레이션한다는 주장을 새로 추가하지 않습니다.

## 이후 순서

1. GBC 사용자 보고를 안정적으로 수집하고 0.9.x 유지보수.
2. NES 최소 코어의 자원·영상/음향 출력 가능성 조사.
3. NES 경로에서 검증한 공통 부분을 분리하고 회귀 범위를 확정.
4. PCE HuCard 기본 경로 조사. CD-ROM²·추가 메모리·주변기기는 별도 범위.
5. 검증된 코어를 다음 제품 MINOR에 편입.

NES/PCE 편입 버전·완료 날짜는 아직 약속하지 않습니다. 현재 GBC의 56/56 M9K 사용량은 다른 코어의 별도 이미지 가능성을 판정하는 수치가 아닙니다. 각 이미지를 독립적으로 합성·검증합니다.
