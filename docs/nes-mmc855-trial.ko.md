# MMC855 모험도 4 무입력 60초 실기 시험

1. 전원을 끈 상태에서 ZIP의 `MMC855-ADVENTURE-60SEC-SD-ROOT` 폴더 안의 내용물을 SD 루트에 복사한다.
2. MMC826 시험에 사용한 일본판 모험도 4 ROM을 `sd2snes/nes/mmc855.nes`로 복사한다.
3. SD 메뉴에서 `NES MMC3 855.nh1`을 선택한 뒤 버튼을 뗀다. 약 60초 동안 입력 없이 두고, 오프닝에서 자동 플레이로 넘어갈 때 배경과 스프라이트가 계속 표시되는지, 종료 후 SD 메뉴로 돌아오는지 확인한다.
4. 메뉴 복귀 후 `sd2snes/`의 `nes-progress-mmc855.txt`, `nes-budget-mmc855.txt`, `nes-game-last-mmc855.txt`를 보관한다. 일찍 종료한 경우에도 생성된 로그를 보관한다.

시간의 기준은 표시 세션 시작이다. 예산 로그 `display_1_30_60`의 첫 번째 완료 횟수를 29초로 나누면 오프닝 [1, 30)초의 표시 FPS, 두 번째를 30초로 나누면 데모 [30, 60)초의 표시 FPS다. MMC826의 같은 구간은 각각 17.52 FPS와 16.13 FPS였다.
