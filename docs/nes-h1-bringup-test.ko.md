# NES H1 037 실기 시험

대상은 기존 GBC 0.9.0(C44)을 사용하던 FXPAK Pro / Mk.III STM32, EP4CE15F17C8 조합이다.
이번 묶음은 035 MCU와 SPI 수정 036 FPGA를 함께 설치한다. NES 게임 코어는 아직 포함하지 않는다.
실기 첫 동작 확인용 후보이며, 실제 MCU/FPGA 실행과 전기적 타이밍은 미검증이다.

## 설치와 복구

가능하면 현재 정상 SD의 복제본으로 시험한다. 콘솔 전원을 끄고 SD를 PC에 연결한다.
압축을 PC의 새 폴더에 푼다. sd-overlay 폴더 자체를 SD에 복사하지 않는다.
Python 3.11 이상에서 아래 명령을 실행한다. E:/는 실제 SD 루트, C:/NES-H1-backup-037은
SD 밖의 아직 없는 백업 폴더로 바꾼다. python 명령이 없으면 설치된 python.exe의 전체 경로를 사용한다.
PowerShell에서는 전체 경로 앞에 &를 붙인다.

    python manage_nes_h1_sd.py check --sd-root E:/
    python manage_nes_h1_sd.py install --sd-root E:/ --backup C:/NES-H1-backup-037

check는 쓰지 않는다. install은 패키지 전체 해시, 기존 C44 펌웨어/GBC 이미지,
기본 FPGA와 menu.bin의 존재를 확인하고 변경할 세 파일의 원본과 복원 기록을 먼저 백업한다.
설치 대상은 sd2snes/firmware.stm, sd2snes/fpga_nh1.bi3, 루트의 NES H1 037.nh1뿐이다.
firmware.im3는 STM32 대상 파일이 아니다. base/GBC/게임/세이브 파일은 설치 대상이 아니다.
기존 펌웨어 해시가 다르면 임의로 검사값을 바꾸지 말고 출력 내용을 남긴다.
설치 중 중단되면 콘솔을 켜기 전에 아래 restore를 수행한다. 백업은 실기 시험이 끝나도 보관한다.

    python manage_nes_h1_sd.py restore --sd-root E:/ --backup C:/NES-H1-backup-037

restore는 같은 SD 경로인지, 백업과 현재 대상 파일의 해시가 맞는지 확인한 뒤 원본을 복원한다.
새로 추가했던 H1 파일만 제거하며 다른 파일/디렉터리를 삭제하지 않는다. 복원은 다시 실행해도 된다.
시험 이후 대상 파일이 다른 내용으로 바뀌었다면 덮어쓰지 않고 중단한다.
OS 안전 제거를 거쳐 SD를 콘솔에 옮긴다. 전원 손실에 대한 FAT 원자성까지 보장하는 도구는 아니다.

## 실기 순서와 정상 화면

1. 전원을 켜 메뉴가 정상인지 확인한다. 메뉴에서 NES H1 037.nh1을 수동 선택한다.
   이 파일은 실행 표식이다. 이름만 .sfc로 바꾸거나 ROM으로 적재하지 않는다.
2. 화면 제목은 **NES H1 034**가 맞다. 037은 묶음 번호이고 화면 프로그램은 검증한 034 그대로다.
   reference.png와 비교한다. **GRID → BARS → CROSS**, 화면 번호 **1 → 2 → 3**이
   약 60 NTSC 프레임마다 바뀌며 반복되어야 한다. LINK WAIT는 잠깐 나타날 수 있다.
3. 우선 10초 동안 가독성과 반복을 확인한다. 정상이라면 2분 정도 유지해 정지·깨짐 유무를 본다.
   검은 화면, 지속되는 LINK WAIT, LINK ERROR, 무의미한 점무늬, 멈춤은 통과가 아니다.
4. 콘솔 RESET을 눌러 메뉴 복귀를 확인한다. 다시 표식을 실행하고 세 화면 순환을 확인한다.
   재진입은 FPGA 재설정이므로 화면 세대 숫자가 반드시 증가해야 하는 시험은 아니다.
5. 정상일 때만 기존에 확인한 GBC 게임으로 전환해 실행·입력·소리·기존 세이브 읽기를 확인한다.
   저장 시험은 백업한 세이브의 복제본으로 한다. H1 중 USB 통신은 중단되므로 USB 전송은 하지 않는다.
6. 검은 화면/LED 정지/메뉴 복귀 실패이면 반복 조작 대신 전원을 끄고 PC에서 restore한다.
   기존 메뉴와 GBC가 복구되는지 확인하고 어느 단계에서 실패했는지 기록한다.

results.tsv에 콘솔/지역, 카트, cold/warm, 화면, RESET, 재진입, GBC, 복원 결과를 남길 수 있다.
영상은 메뉴 선택부터 첫 화면 전환까지, 이후 RESET/재진입 장면을 포함하면 원인 분리에 도움이 된다.
실기 영상 통과도 수치적 setup/hold·버스 경합·장기 안정성 인증을 뜻하지 않는다.
