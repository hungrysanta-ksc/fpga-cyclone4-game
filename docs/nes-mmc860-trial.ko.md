# MMC860 모험도 4 무입력 60초 실기 시험

1. 전원을 끄고 ZIP 안의 `MMC860-ADVENTURE-60SEC-SD-ROOT` 폴더 **내용물**을 SD 루트에 복사한다.
2. MMC855에서 사용한 일본판 모험도 4 ROM을 같은 바이트 그대로 `sd2snes/nes/mmc860.nes`로 복사한다.
3. SD 메뉴에서 `NES MMC3 860.nh1`을 선택하고 버튼을 뗀다. 이후에는 입력 없이 오프닝과 자동 플레이를 지켜본다. 표시 세션 60초 뒤 메뉴로 복귀하면 시험이 끝난다.
4. SD의 `sd2snes/` 폴더에서 `nes-budget-mmc860.txt`, `nes-progress-mmc860.txt`, `nes-game-last-mmc860.txt`를 보관한다. 일찍 종료되면 당시 화면과 생성된 로그를 함께 기록한다.

| 표시 세션 구간 | 계산 | MMC855 실기 기준 |
|---|---|---:|
| 오프닝 [1, 30)초 | 첫 완료 횟수 ÷ 29초 | 520회 · 17.93 FPS |
| 데모 [30, 60)초 | 두 번째 완료 횟수 ÷ 30초 | 504회 · 16.80 FPS |

카운트는 예산 로그의 `display_1_30_60`에 순서대로 기록된다. 로딩 시간은 두 구간에서 제외된다. 끝나지 않은 구간은 FPS 비교에서 제외한다.
