# MMC613 SMB3 실기 결과

MMC613에서 60.08초 동안 973화면을 표시했다. MMC577은 같은 시간에 838화면을 표시했다. 사용자가 정상 실행과 메뉴 복귀를 확인했다. 각 버전 한 차례의 플레이 기록이며 같은 시각의 장면과 작업량은 달라질 수 있다.

| 최종 표시 완료 시각 | MMC577 횟수 / fps | MMC613 횟수 / fps | 변화 |
|---|---:|---:|---:|
| 5–40초 | 482 / 13.77 | 559 / 15.97 | +16.0% |
| 40–55초 | 211 / 14.07 | 224 / 14.93 | +6.2% |
| 5–55초 | 693 / 13.86 | 783 / 15.66 | +13.0% |

전체 실행을 완료 화면 수로 나누면 평균 간격은 71.69→61.75 ms다. ARM 계측의 수신은 19.89→18.82 ms, 계획·공급은 14.83→10.65 ms, 출력·최종 ACK는 36.37→31.63 ms다. 각 단계는 IRQ와 대기를 포함한다. 같은 폴링 시간을 다시 더하면 중복된다.

45–50초에 시작해 표시된 화면은 72→59개, 화면당 변경 map 행은 9.07→16.22개였다. 이 구간의 출력 시간은 10 ms tick 집계 기준 35.14→47.80 ms였다. 50–55초에는 70→91개였다. 장면별 차이를 분리하려면 양쪽에서 같은 map·OBJ 작업량을 골라 출력 발행, 65816 수락·DMA, 최종 VBlank·ACK 시각을 맞춰야 한다.

ROM 393,216 B 적재·대조, START, 최종 EA 973회, STOP, base 복구와 MENU_PREPARED를 확인했다. CRC 오류·실패 전송·trace abort는 0회다. 59.93초에 마지막 표시가 끝났고 종료 시 다음 SEAL 한 건은 ACK 대기 중이었다. 이 요청은 완료 횟수에서 제외했다. 현재 로그로 개별 DMA와 VBlank 대기 시간, 게임 내부 진행률은 구분할 수 없다.
