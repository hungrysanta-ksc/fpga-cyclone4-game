# MMC866 모험도 4 무입력 60초 실기 시험

1. 전원을 끄고 ZIP 안의 `MMC866-ADVENTURE-60SEC-SD-ROOT` 폴더를 연다. **그 안의 내용물**을 SD 루트에 복사한다.
2. MMC855에서 사용한 일본판 모험도 4 ROM을 `sd2snes/nes/mmc866.nes`라는 이름으로 복사한다.
3. SD 메뉴에서 `NES MMC3 866.nh1`을 선택하고 버튼을 뗀다. 오프닝과 스테이지 데모는 추가 입력 없이 진행된다. 표시 세션 60초 뒤 SD 메뉴로 자동 복귀하는지 확인한다.
4. 메뉴 복귀 후 `sd2snes/`의 `nes-budget-mmc866.txt`, `nes-progress-mmc866.txt`, `nes-game-last-mmc866.txt`를 보관한다. 일찍 종료되면 그때까지 생긴 로그와 마지막 화면을 기록한다.

| 무입력 구간 | 예산 로그 `display_1_30_60`의 표시 FPS 계산 | MMC855 실기 기준 |
|---|---|---:|
| 오프닝 [1, 30)초 | 첫 번째 완료 횟수 ÷ 29초 | 520장 · 17.93 FPS |
| 스테이지 데모 [30, 60)초 | 두 번째 완료 횟수 ÷ 30초 | 504장 · 16.80 FPS |

표시 세션 시작을 0초로 잡는다. 30초 정각에 완료한 화면은 데모 구간에 들어간다. 조기 종료했을 때는 끝까지 측정된 구간만 비교한다.
