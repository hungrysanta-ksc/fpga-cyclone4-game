# MMC1012 모험도 4 무입력 60초 계측판

1. ZIP 안의 `MMC1012-ADVENTURE-60SEC-SD-ROOT` 폴더 내용을 SD 루트에 복사한다.
2. MMC1010에서 사용한 모험도 4 일본판 ROM을 `sd2snes/nes/mmc1012.nes`로 복사한다.
3. 파일 선택 메뉴에서 **NES MMC3 1012.nh1**을 선택한다. 입력 없이 60초 동안 두고 오프닝, 스테이지 데모 전환, 자동 메뉴 복귀를 확인한다.
4. 메뉴 복귀 후 `sd2snes` 폴더의 `nes-frame-mmc1012.bin`, `nes-budget-mmc1012.txt`, `nes-game-last-mmc1012.txt`, `nes-progress-mmc1012.txt`를 함께 보관한다. 두 번 실행하면 첫 실행의 네 파일을 먼저 복사한다.

MMC1010과 같은 보드와 65816을 사용한다. 1–30초와 30–60초 표시 수를 계속 집계하며, 55–60초에 특정 23행 화면을 만나면 일반 패킷별 준비·발행·반환 확인 시각을 추가로 보관한다. 주된 비교 대상은 패킷 대기와 화면 공개 시각이다.
