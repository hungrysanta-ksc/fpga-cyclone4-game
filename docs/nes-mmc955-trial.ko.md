# MMC955 · 모험도 4 무입력 60초 실기판

1. 전원을 끄고 ZIP 안의 `MMC955-ADVENTURE-60SEC-SD-ROOT` 폴더를 연다. **그 안의 내용물**을 SD 카드 루트에 복사한다.
2. MMC925에서 사용한 모험도 4 일본판 ROM을 `sd2snes/nes/mmc955.nes`로 복사한다. 비교에 사용한 원본 파일 SHA-256은 `9d7402da135fd1290346ccc9332836daee3a9a3cda3789999c3f86efdb5b19c2`다.
3. SD 메뉴에서 **NES MMC3 955.nh1**을 실행한다. 버튼을 누르지 않고 오프닝에서 스테이지 데모로 넘어가는지, 60초 뒤 메뉴로 자동 복귀하는지 확인한다.
4. 실행 직후 SD의 `sd2snes` 폴더에서 `nes-budget-mmc955.txt`, `nes-progress-mmc955.txt`, `nes-game-last-mmc955.txt`, `nes-frame-mmc955.bin`을 보관한다. 같은 판을 다시 실행하면 로그가 갱신된다.

## 표시 FPS 비교

| 화면 공개 시각 | 집계 시간 | MMC925 실기 표시 수 | MMC925 표시 FPS |
|---|---:|---:|---:|
| 1–30초 오프닝 | 29초 | 642장 | 22.14 |
| 30–60초 데모 | 30초 | 667장 | 22.23 |

공개가 끝난 화면을 센다. 첫 1초를 제외하고, 30초 경계의 공개는 데모에 포함한다. 저장소의 `tools/nes_windows518.py compare`에 두 판의 budget·progress 로그를 넣어 같은 집계식으로 비교할 수 있다. 중도 종료된 실행은 종료 원인 분석에 사용한다.

## 전달 전 확인

952 보드와 950 ARM·65816을 묶었다. 최종 ARM은 212,980B로 Flash 여유는 12B다. 두 위상에서 각각 기존 캐시와 빈 캐시로 재생했다. 같은 여섯 화면에서 MMC925와 MMC955 모두 15회의 진단 페이지 조회와 8,044B의 로그를 기록했다. 55–60초 상세 계측은 두 판 모두 같은 방식으로 한 화면을 선택한다. 실제 60초 표시 FPS는 이번 실기 로그로 비교한다.
