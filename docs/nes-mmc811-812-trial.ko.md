# MMC811·812 실기 시험

전원을 끄고 시험할 판의 설치 폴더 **안에 있는 내용 전체**를 SD 루트에 복사한다. 이전에 사용한 SMB3(J) ROM을 아래 이름으로 복사한 다음 전원을 켠다.

| | MMC811 · 60초 | MMC812 · 장시간 |
|---|---|---|
| 설치 폴더 | `01-MMC811-60SEC-SD-ROOT` | `02-MMC812-LONG-SD-ROOT` |
| ROM 위치 | `sd2snes/nes/mmc811.nes` | `sd2snes/nes/mmc812.nes` |
| SD 메뉴에서 선택 | `NES MMC3 811.nh1` | `NES MMC3 812.nh1` |

**MMC811**에서는 MMC807 때와 비슷한 시점에 첫 레벨에 진입해 같은 동선으로 플레이한다. 60초 뒤 SD 메뉴가 보이는지 확인한다. 비교 구간은 시작 후 5–40초와 40–55초다. MMC807 실기 기준은 각각 666화면(19.03fps)과 277화면(18.47fps)이다.

**MMC812**에서는 중간 성의 내려오는 천장을 통과한 뒤 다음 스테이지까지 진행한다. 적이 많은 장면에서 잠깐 멈췄다면 조작과 화면이 다시 이어졌는지 기록한다. 시험을 마치면 **L + R + Start + Select**를 함께 길게 눌러 SD 메뉴로 복귀한다. 도중에 자동으로 복귀했다면 마지막으로 보인 장면을 기록한다.

각 실행이 끝나면 다음 실행 전에 SD의 `sd2snes` 폴더에서 해당 번호의 세 파일을 보관한다.

| 판 | 진행 로그 | 표시 통계 | 종료·오류 기록 |
|---|---|---|---|
| MMC811 | `nes-progress-mmc811.txt` | `nes-budget-mmc811.txt` | `nes-game-last-mmc811.txt` |
| MMC812 | `nes-progress-mmc812.txt` | `nes-budget-mmc812.txt` | `nes-game-last-mmc812.txt` |

종료 기록의 `obj_line`과 `obj_load`는 마지막으로 스프라이트 한도를 넘긴 화면의 줄과 그 줄에서 확인한 항목 수다. `obj_load=0`이면 이번 실행에서 한도 초과를 관측하지 않았다.
