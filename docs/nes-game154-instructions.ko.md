# NES154 — 게임 진입 오류의 PPU 상태 회수

153에서 메뉴 복귀와 오류 로그 회수는 실기로 확인했다. 이번 판은 **같은 SMB3 게임에서 오류 순간의 PPU 위치와 주소 생성 상태를 8바이트 더 기록**한다. PPU 읽기 오류 자체를 수정한 판은 아니다.

## 설치

1. 전원을 끄고 현재 SD의 `firmware.stm`을 별도 백업한다.
2. ZIP의 `01-GAME154-SD-ROOT` **안의 내용**을 SD 루트에 복사한다.
3. 메뉴에서 `NES GAME 154.nh1`을 실행한다. 0바이트 표식이며 확장자를 바꾸지 않는다.

이번에는 펌웨어와 FPGA 모두154 조합을 사용한다. 이전153 파일을 섞지 않는다. 식별은63/DD이며 실제 ROM은 `sd2snes/nes/game154.nes`다. 개인용 ZIP에는 사용자 ROM이 포함되어 있으므로 공개하지 않는다.

## 한 번의 실기 시험

- 로딩 시간은 바꾸지 않았다. 앞선151 실측은 약3분50초였으며 로딩 영상은 필요 없다.
- `1 PLAYER GAME / 2 PLAYER GAME` 선택 화면이 보이면 **Start를 한 번 누르고 뗀다.** 그 앞의 타이틀 연출 화면이면 선택 화면에 도달하는 입력과 구분한다. 처음부터 무조건 두 번 연타하지 않는다.
- WORLD 1 진입 뒤 동일하게 메뉴로 돌아오면 그 결과만 전달하면 된다. 같은 증상이라면 영상은 생략해도 된다.
- 실제 맵이나 스테이지에서 계속 진행된다면 방향키·A·B를 확인하고 짧은 영상을 촬영한다. 기존153에서 다른 버튼은 아직 검증되지 않았다.
- 게임 실행은 최대 약60초이며 오류가 감지되면 조기 종료한다. 실행 후 총7분이 지나도 메뉴로 돌아오지 않으면 전원을 끄고 남은 로그를 전달한다. 7분은 관찰 상한이다.

## 전달 자료

전원을 끈 뒤 다음 두 파일과 메뉴 복귀 여부를 전달한다.

- `/sd2snes/nes-progress-154.txt`
- `/sd2snes/nes-game-last-154.txt`

새 `ppu_state_*` 항목은 직접 해독할 필요 없다. RUN 도중 SD에 쓰지 않고, 오류 당시 저장한 상태를 STOP 확인 뒤 읽어 최종 로그에 포함한다. 보조 응답 형식이 맞지 않으면 유효성0으로 남긴다. 전송·클록 안전 검사는 계속 적용된다.

기존의 약0.5초 화면 유지와 DMA 중 입력 공백, 무음·저장 미구현은 그대로다. CRT 촬영의 대각선 띠는 오류로 판정하지 않는다. 같은153·A/B 패턴·044/GBC 복원 시험을 반복할 필요는 없다. 정상 사용으로 돌아갈 때는 전원을 끄고 `02-RESTORE044-SD-ROOT` 안의 내용을 복사한다.
