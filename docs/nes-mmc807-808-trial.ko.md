# MMC807·808 스프라이트 초과 화면 복구 시험

먼저 MMC808에서 중간 성을 지난 뒤 MMC806이 종료됐던 다음 스테이지까지 플레이한다. 같은 장면을 다시 지날 수 있으면 통과 횟수와 화면이 잠깐 멈춘 뒤 조작이 이어졌는지를 기록한다. 한도 초과가 이어지는 동안에는 마지막 정상 화면이 계속 보일 수 있다. 플레이를 마치면 L + R + Start + Select를 함께 길게 눌러 SD 메뉴로 복귀한다. 자동 복귀했다면 직전에 보인 장면을 기록한다.

| | MMC807 · 60초 | MMC808 · 장시간 |
|---|---|---|
| 설치 폴더 | `01-MMC807-60SEC-SD-ROOT` | `02-MMC808-LONG-SD-ROOT` |
| 기존 SMB3(J) ROM 복사 위치 | `sd2snes/nes/mmc807.nes` | `sd2snes/nes/mmc808.nes` |
| SD 메뉴에서 실행 | `NES MMC3 807.nh1` | `NES MMC3 808.nh1` |

전원을 끄고 선택한 설치 폴더 안의 내용 전체를 SD 루트에 복사한다. MMC807에서는 평소 첫 레벨 동선으로 60초간 플레이한다. 5–40초와 40–55초의 실제 표시율을 MMC805와 비교한다.

각 실행 직후 SD의 `sd2snes` 폴더에서 해당 번호의 `nes-progress-mmc808.txt`, `nes-budget-mmc808.txt`, `nes-game-last-mmc808.txt` 세 파일을 PC에 보관한다. MMC807은 세 파일 이름에 807이 들어간다. 여러 번 플레이할 때는 매번 복사한다. game-last의 `obj_line`과 `obj_load`는 마지막으로 한도 초과를 판정한 화면의 줄(0–223)과 그 줄에서 처음 확인된 초과 항목 수다. `obj_load=0`이면 이번 실행에서 초과를 관측하지 않았다. 마지막 화면·직접 종료 여부·SD 메뉴가 보였는지를 로그와 함께 대조한다.
