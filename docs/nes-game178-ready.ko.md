# NES178 — START 이후 화면 갱신 확인

이 안내는 배포 검증을 통과해 생성된 `NES178-SMB3-CLIP.zip`용이다. START 뒤 게임이 왼쪽8픽셀을 숨기면 정상 화면까지 거부하던 조건을 수정했다. **실기 해결 여부를 확인하는 시험이며, 초기 끊김·60fps는 아직 해결한 것으로 보지 않는다.**

1. ZIP의 `01-GAME178-SD-ROOT` 안 내용을 SD 루트에 덮어쓴다. 펌웨어와 FPGA를 함께 적용한다.177 파일과 섞지 않는다.
2. 메뉴에서 `NES GAME 178.nh1`을 한 번 실행한다. ROM 적재 방식은 그대로여서 로딩에 수분 걸릴 수 있다.
3. START로 플레이어 선택→월드맵으로 진행하고 첫 레벨에 들어간다. 각 전환 뒤 **화면 갱신이 계속되는지**, 사운드·기본 조작이 이어지는지 확인한다. 정확한 입력 유지 품질 판정은 이후 연속 영상 개선 뒤 진행한다.
4. 표시 준비 후 약60초의 자동 메뉴 복귀를 기다린다. `sd2snes/nes-progress-178.txt`와 `sd2snes/nes-game-last-178.txt`를 전달하고 마지막으로 정상 표시된 장면·메뉴 복귀 여부를 알려준다. 같은 정지라면 새 영상은 필수가 아니다.

메뉴에서 실행한 뒤6분이 지나도 복귀하지 않으면 전원을 끄고 남은 로그를 복사한다. 정상 사용으로 돌아갈 때는 `02-RESTORE164-SD-ROOT`를 사용한다.044 복원 검증은 반복하지 않는다.

ROM·메뉴·164 복원 내용은177 패키지와 같은 바이트다. 실행 중 SD 쓰기와 세이브 SRAM 영상 버퍼 사용은 없다. 로그는 STOP 뒤 기록하며, history 형식은177을 유지한다.
