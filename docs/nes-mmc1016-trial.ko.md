# MMC1016 모험도 4 무입력 60초 타일 공급 계측판

1. ZIP의 `MMC1016-ADVENTURE-60SEC-SD-ROOT` 폴더 내용을 SD 루트에 복사한다.
2. MMC1012에서 사용한 모험도 4 일본판 ROM을 `sd2snes/nes/mmc1016.nes`로 복사한다.
3. **NES MMC3 1016.nh1**을 선택한다. 조작 없이 60초 동안 오프닝과 데모를 두고 자동 메뉴 복귀를 확인한다.
4. 다음 실행 전에 SD의 `sd2snes` 폴더에서 아래 네 파일을 PC의 `1차` 폴더로 복사한다. 같은 방법으로 한 번 더 실행하고 두 번째 결과를 `2차`에 보관한다.

- `nes-frame-mmc1016.bin`
- `nes-progress-mmc1016.txt`
- `nes-budget-mmc1016.txt`
- `nes-game-last-mmc1016.txt`

MMC1012의 실행 일정을 기준으로 1–30초와 30–60초의 표시 수를 집계한다. 59–60초에 map 23행·BG 521·OBJ 17과 마지막 64B OBJ descriptor가 일치하는 화면에서 세 번의 타일 뱅크 반환과 15개 타일 기록을 수집한다. 세대 번호는 회차에 따라 바뀔 수 있다. 상세 읽기는 해당 화면의 최종 ACK 뒤에 공유 SPI를 사용하므로 그 이후 표시 간격에는 계측 비용이 포함된다.

저장소에서 `python tools/read_nes_supply1016.py <1차.bin> <2차.bin>`을 실행하면 CHR 태그·행·플레인과 뱅크별 묶음이 같은 두 기록을 비교한다. 파일 하나만 주면 각 타일의 전체 내역을 출력한다. 대상 화면이나 유효한 전체 기록이 없으면 해당 회차의 상세 비교는 보류한다.

기준 시각은 FPGA가 세대의 첫 E9 명령 바이트를 인식한 시점이다. 타일 소스 시각은 NES 도메인에서 동기화한 뒤 세며 한 눈금은 NTSC 명목 0.763ms이다. 뱅크 반환은 84MHz host 도메인에서 세며 한 눈금은 0.780ms이다. 소비용 요청·첫 허가·응답을 구분하고, 소비자가 선행 읽기의 ROM 점유와 겹친 구간은 별도로 표시한다. 겹친 시간은 요청 대기에 이미 포함될 수 있다. 서로 다른 도메인에서 한 눈금 안에 발생한 두 사건의 선후는 이 기록만으로 단정할 수 없다.
