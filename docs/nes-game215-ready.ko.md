# NES215 계획 상태 오류 확인판

214는 게임을 시작하고50회 표시한 뒤 계획 상태 검사에서 중단됐습니다. 이번 판은 **같은 문제가 발생하면 최초 실패한 응답과 검사 조건을 남기는 시험판**입니다. 원인 수정 완료 또는60fps 개선판으로 해석하지 않습니다. FPGA·게임 출력·입력·사운드 구현은214와 같습니다.

1. 전원을 끈 상태에서 `01-GAME215-SD-ROOT` 폴더 **안의 내용**을 SD루트에 복사합니다. `NES GAME 215.nh1`을 실행합니다.
2. 지난번처럼 플레이어 선택 후 스테이지 선택으로 들어갑니다. 계속 진행되면 숫자1 타일에서A로 첫 레벨에 진입해 오른쪽+B와A반복으로 확인합니다.
3. 오류 발생 시 기존 종료 경로로 복귀합니다. 오류가 없다면 게임 시작 후 약60초에 종료합니다. 로딩 시간은 기존과 같습니다.
4. `/sd2snes/nes-progress-215.txt`, `nes-game-last-215.txt`, **`nes-budget-215.txt`** 세 파일과 어느 화면에서 종료됐는지, 메뉴 복귀 여부를 알려 주세요. 핵심 오류 응답은 budget 파일에 있습니다. 같은 조기 종료라면 영상은 필수가 아닙니다.

로딩이 끝난 뒤90초가 지나도 복귀하지 않으면 전원을 껐다 켜고 남은 로그를 전달해 주세요. 214 재시험이나044 복원 시험은 필요하지 않습니다. 기존 패키지는 보관하며, ZIP의164복원 파일도 이전 바이트 그대로입니다.

정상 전송에 새 SPI 요청·재시도·SD쓰기를 추가하지 않았습니다. 최초 오류 정보를 RAM에 보존하고 기존 안전한 종료 뒤 TXT에 기록합니다. 보호 조건이나 복원 자체가 실패하면 결과 TXT가 없을 수 있으므로 남은 progress도 필요합니다.
