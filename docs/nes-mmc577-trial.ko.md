# MMC577 제한 실기 시험

MMC558 이후의 ROM 공급·시작·중단 처리를 실기에서 확인하는 전달본이다. 실제 프레임 변화는 같은 동선의 로그로 판단한다. 대상은 이전 MMC558을 실행한 동일한 FXPAK Pro / Mk.III 보드다.

1. ZIP의 **01-MMC577-SD-ROOT** 폴더 안 내용을 SD 카드 루트에 덮어쓴다.
2. MMC558에서 사용한 SMB3(J) ROM의 내용은 바꾸지 않고 **sd2snes/nes/mmc577.nes**라는 이름으로 복사한다. 비교 ROM의 CRC32는 **5a04eed7**이다. ROM과 세이브는 ZIP에 포함하지 않는다.
3. 메뉴에서 **NES MMC3 577.nh1**을 실행한다. MMC558과 비슷하게 첫 레벨을 플레이하고 적이 많은 구간과 약 60초 뒤 메뉴 복귀를 확인한다.
4. SD의 sd2snes 폴더에서 아래 세 파일을 전달한다. 실행 실패가 있으면 재실행 전에 해당 세 파일을 따로 복사해 보존한다.

- nes-progress-mmc577.txt
- nes-budget-mmc577.txt
- nes-game-last-mmc577.txt

집계는 처음과 마지막 5초를 제외한 **5–40초 / 40–55초**다. 이전 로그를 이름만 바꿔 보내지 않는다. RESTORE 묶음은 포함하지 않으며 기존 백업을 유지한다. fpga_base.bi3와 m3nu.bin은 MMC558과 같은 메뉴 복귀용 파일이다.

내부 타이밍 검사를 통과한 제한 시험 후보이며 전체 외부 IO의 전기적 검증 완료를 뜻하지 않는다. 예기치 않은 화면·조작·메뉴 복귀 문제가 생기면 추가 반복보다 해당 로그와 증상을 남긴다.
