# MMC520 제한 실기 시험

1. ZIP을 풀고 `01-MMC520-SD-ROOT` **안의 내용**을 SD 카드 루트에 복사한다. `firmware.stm`은 이번 전달본으로 설치한다. 기존 MMC516 백업은 따로 보관한다.
2. MMC516에서 실행했던 `sd2snes/nes/mmc516.nes`를 같은 폴더에 복사해 **`mmc520.nes`**로 이름을 바꾼다. ROM 내용은 수정하지 않는다. 대상 SMB3(J)는 393,232B, CRC32 `5a04eed7`이다.
3. 메뉴에서 **NES MMC3 520.nh1**을 실행한다. 앞선 시험처럼 첫 레벨을 플레이하고, 적이 많은 구간의 움직임·타일 깨짐·입력을 확인한다. 약 60초 뒤 메뉴로 복귀하는지도 확인한다.
4. SD 카드의 `sd2snes` 폴더에서 아래 세 파일을 전달한다. 재실행하면 덮어쓰므로 여러 번 시험한 경우 회차별로 복사해 둔다.

- `nes-progress-mmc520.txt`
- `nes-budget-mmc520.txt`
- `nes-game-last-mmc520.txt`

ARM이 승인된 표시 횟수를 1초 이상~40초 미만(39초)과 40초 이상~60초 미만(20초)으로 분리한다. 45–50초 무렵 느려짐이 다시 보이면 어느 장면이었는지 로그와 함께 알려주면 된다. MMC516 구형 로그에는 같은 방식의 두 카운터가 없다.

게임 ROM과 RESTORE 폴더는 포함하지 않는다. MCU Flash의 212,992B 한도를 모두 사용하며 FPGA 이미지는 실기에서 동작한 MMC516과 같다. MMC520의 실기 동작과 FPS는 이 시험으로 확인할 항목이다.
