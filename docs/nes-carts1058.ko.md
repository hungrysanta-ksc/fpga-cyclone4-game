# NES 1058

디버그판과 배포판 중 하나를 SD 루트에 풀고 사용하던 .nes 파일을 선택한다. 배포판은 무제한 플레이용이며 1057에서 확인한 수동 종료 경로를 유지한다.

- 와이와이월드 2는 캐릭터를 선택한 뒤 첫 스테이지에서 이동한다. 1057 STOP에는 프리렌더 6번 dot에 일치하는 CHR 주소 20F122가 대기 중이지만 응답은 아직 없었다. 원본 ROM에서는 프리렌더 2번 dot의 렌더링 재활성화도 관찰됐다. 네 CPU 읽기 위상으로 기존 ROM 서비스의 고장 문맥을 재현했다. 1058에서는 프리렌더에도 기존의 렌더링 재시작 예측을 적용한다.
- 배틀토드는 첫 스테이지에서 이전과 비슷하게 이동한 뒤 퀵메뉴로 종료한다. 1057은 55–60초에 25화면을 공개했다. 화면 상단이 비어 있는 동안 패턴 RAM의 일부에만 써도 이전 구현은 여덟 페이지 전체를 변경으로 보고했다. 1058은 마지막 반환 이후의 쓰기와 현재 쓰기를 모두 포함해 변경된 페이지만 표시한다. 실제 ROM의 첫 스테이지 기준 프레임 2100에서는 셋을 변경하고 다섯을 재사용할 수 있다. 전체 복구, 가시 구간 쓰기 충돌과 STOP, 닫힌 스냅샷은 기존 검사를 유지한다.
- 두 게임을 연달아 시험할 때는 다음 게임 실행 전에 SD의 nes-game-last-debug1058.txt, nes-progress-debug1058.txt, nes-frame-debug1058.bin, nes-stop-debug1058.bin을 각각 보관한다.
