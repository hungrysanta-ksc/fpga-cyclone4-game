# NES 655 · 네 참조 거리의 RAM 검색

## 교체 경계와 대조군

654 combined의 ARM 이미지(212,508 B), END/E9 묶음, 큐 credit, 65816 ROM, 주소별 map 데이터와 serializer를 고정했다. 검색 대상은 현재 블록에서 이미 복원 가능한 1·2·4·33셀 앞의 값이다. 최대 32셀까지 비교하고, 같은 길이에서는 앞선 거리, 즉 더 짧은 참조 거리를 택한다. 두 셀보다 짧은 일치는 literal로 보낸다.

- **walk**는 RAM 주소 레지스터 하나로 현재 바이트에서 참조 바이트로 이동한다. 비교가 맞으면 같은 가산기로 다음 현재 바이트에 도달한다. 매번 origin+length를 다시 계산하는 회로, 별도 참조 index 및 비교 단계의 상·하위 바이트 플래그를 제거했다. digest·literal·원본 복구·최종 CRC의 순차 읽기도 이 가산기를 쓴다.
- **pair**는 셀 페이지에서 포트 B가 현재 셀, 쓰기 작업이 없는 포트 A가 같은 클록의 참조 셀을 읽는다. 읽은 16비트를 한 번에 비교하여 비교용 두 번째 바이트 읽기와 저장 단계를 삭제했다. 포트 A는 직접 입력·공통 serializer·압축 출력 쓰기가 우선이다.
- **mask**는 pair의 두 포트에서 네 거리의 후보를 한 현재 셀에 대해 검사한다. 불일치한 거리는 4비트 마스크에서 탈락시키고, 남은 거리를 모두 검사한 뒤에만 현재 주소와 공통 길이를 진행시킨다. 각 거리마다 길이를 초기화하고 최대 길이와 다시 대조하던 제어를 대체한다. 살아남은 거리 중 가장 낮은 비트를 선택해 동률 순서를 보존한다.
- **단일 M9K mask**는 같은 mask 제어를 Cyclone IV E의 256×16 true dual-port M9K 한 개에 연결했다. 포트 A의 바이트 쓰기 허가와 두 읽기 주소 모두 host 클록을 쓴다. 첫 primitive 구성은 사용하지 않는 clock1을 연결해 Lite elaboration에서 중단됐다. 그 포트를 제거한 최종 소스로 전체 컴파일과 vendor 모델 시험을 다시 실행했다.

## 실제 RAM 검색 비용

955 첫 7블록은 네 경우 모두 500 B다. 열의 시간은 각 블록을 공급할 수 있게 된 시각부터 D0 공개까지 측정한 시간의 합이다. 이 합을 프레임 표시 시간에서 직접 빼지 않는다.

| 955 첫 7블록 | 준비 시간 합 | 봉인 후 처리 | 현재/참조 비교 상태 A / B 실행 수 | 검색 진행 상태 실행 수 |
|---|---:|---:|---:|---:|
| 654 | 258.512 µs | 150.655 µs | 1,597 / 1,597 | 1,724 |
| walk | 239.500 µs | 131.643 µs | 1,597 / 1,597 | 1,724 |
| pair | 190.262 µs | 82.405 µs | 1,126 / 0 | 1,253 |
| mask | 188.893 µs | 80.976 µs | 1,126 / 0 | 1,133 |

654와 walk는 A·B에서 8비트씩 읽고, pair·mask는 두 포트의 16비트 값을 A에서 비교한다. 위 수치는 955 입력만 따로 계측한 실제 RTL 상태 실행 수다. 별도 905–957 실행에서 901개 D1 payload와 wire CRC 전체를 확인했다.

## 전체 보드 FIT와 표시 판정

| Quartus Lite 25.1 · EP4CE15F17C8 | 전체 LE / 15,408 | 필요한 LAB / 963 | 부족 LE / LAB | 입력 RAM의 합성 결과 |
|---|---:|---:|---:|---|
| 654 | 15,837 | 999 | 429 / 36 | M9K 1개, simple dual port |
| walk | 15,739 | 993 | **331 / 30** | M9K 1개, simple dual port |
| pair | 15,720 | 995 | 312 / 32 | AUTO 논리 RAM 4개 |
| mask | 15,689 | 994 | **281 / 31** | AUTO 논리 RAM 4개 |
| 단일 M9K mask | 15,790 | 997 | 382 / 34 | M9K 1개, true dual port |

네 후보 모두 전체 Fitter가 LAB 부족으로 중단됐다. 배치 후 STA·SOF와 실기 설치본은 생성되지 않았다. pair와 mask는 한 배열에서 모델링한 byte write와 두 read가 Lite에서 단일 포트 2개 및 simple dual port 2개로 나뉘었다. 전체 논리 RAM은 305,264→309,360비트였고 실패 보고서의 M9K 수는 55개다. 이 수치를 여유 M9K 한 개로 간주할 수 없다. 명시적 M9K에서는 전체 56개, 305,264비트로 확인했다.

두 위상의 **모든 후보**에서 951–955 표시 간격은 3·4·3·3·3 VBlank였다. 954 SEAL 여유는 직전 953 표시 기준 1.658 / 1.592 ms, 공통 시작 기준 84.931 / 85.096 ms였다. 951은 239 / 239번 선에서 공개했고, 밀집 평균은 53.281 / 53.249 ms, 957 최종 추가 대기는 0 / 0회였다. 957 ACK는 68,589,578 / 68,589,458 master clock으로 654와 정확히 일치했다. MMC643보다 116.616 / 133.081 ms 빠르다. 명시적 M9K 후보는 901개 payload와 각 블록의 준비·봉인 후 클록까지 mask와 모두 같아 동일한 입력의 두 연속 재생 결과를 사용했다.

**다음 회로 비교 기준은 walk**로 둔다. 한 개의 M9K를 유지한 두 구현 중 필요한 LE와 LAB가 모두 적고, 더 빠른 검색도 이번 두 위상에서는 마지막 ACK를 추가로 앞당기지 못했다. 다음 후보에는 walk 기준 최소 331 LE·30 LAB를 순삭제할 예산이 필요하다. 네 거리 안에서만 비교 순서를 더 바꾸기 전에, 검색 밖의 literal 출력·헤더·CRC 순회와 원본 재생 제어의 진행 상태를 함께 대체할 수 있는지 검토한다.

## 검증 조건과 재현

1. `prepare_nes_search655.py <654 최종 보드> <새 출력> walk|pair|mask|m9k`로 보드를 생성한다. `quartus_sh --flow compile board`로 원래 보드 설정·디바이스·SDC·RAM 이미지를 써서 후보별 전체 FIT를 확인한다.
2. 기존 한 좌석 FLOAT 환경에서 `check_nes_serial654.py`의 일반·`--guards` 실행을 분리한다. 실제 exporter·양쪽 mailbox·SPI·공유 복구 serializer를 거친 데이터를 대조한다. 명시한 M9K는 Questa의 `altera_mf_ver` 모델을 사용한다.
3. 같은 보드에서 `check_nes_search655.py --mode walk|pair|mask`로 주기가 1·2·4·33인 map, 일치가 중간에 끊기는 map, 마지막 19셀, 블록 내 동률·겹침·32셀 상한을 시험한다. 실제 비교마다 주소와 데이터를 원본 scene과 대조한다. 길이 3의 일치가 진행 중일 때 STOP을 넣고 D0의 빈 상태·token을 확인한 뒤 다른 80셀을 cold 복구한다. `--profile`은 955의 상태 횟수만 계측한다. 단일 M9K에는 동일한 mask 검사를 사용한다.
4. 654 combined ELF에서 CRC·세대·범위·token, 99셀 원본 복구와 token wrap, STOP·최종 ACK·메뉴 및 base 복귀 정상/네 실패 차단을 확인한다. `test_nes_direct653.py`에 각 RTL의 `sender.json`을 공급하고 654의 같은 두 시작 시각·ARM CPI 2·IRQ·공유 SPI·ROM 달력·두 슬롯·65816에서 905–957을 재생한다. 물리 보드 FPS와 구분한다.
5. 보관 디렉터리에서 최초 명시적 M9K 시도는 `m9k`, 최종 보드·RTL·추가 검사는 `m9k2`다. 생성 모드는 둘 다 `m9k`다. `analyze_nes_search655.py`로 FIT 보고서·실제 RAM 종류·상태 횟수·ARM 해시·표시 결과를 대조한다. [검증 수치와 추적 해시](../analysis/search655-verification.json) · [654 시간·회로 기준](nes-credit654-results.ko.md)
