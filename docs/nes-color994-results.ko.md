# 994 · 911 팔레트·OAM 수신 복원 비용

## 목표

978의 두 빈 캐시 부팅 위상에서 마지막 384B OBJ 반환 뒤의 수신 시간을 줄여 911을 VBlank 44의 246선 안에 공개하고 912 최종 ACK를 앞당기는 것이 목표다. 같은 클록을 기준으로 908 공개, 909 선행 624B, 910 캡처를 비교했다.

## 작업내용

65816에서 각 패킷의 load, 헤더·identity·길이·범위·cursor 확인 후 WRAM 주소가 결정된 명령, 실제 복원 완료 후 accepted, 큐가 받은 ACK를 기록했다. 복원 구간에는 DMA 설정·실행과 그 사이 실제 STOP·입력 서비스가 들어간다. 서비스 호출부터 RTS 명령 진입까지의 구간은 원자료에 따로 실었다.

가장 비싼 op8에 들어가는 네 바이트가 [a,b,a,a]이면 64B 이하씩 a를 고정 source DMA로 쓴 뒤 각 네 바이트의 둘째 위치에 b를 쓴다. 나머지 패턴은 기존 범용 복원을 사용한다. 65816이 검사한 대상 뱅크와 범위만 쓰며 64B마다 STOP을 확인한다. 별도 후보는 같은 바이트가 반복되는 OAM op4의 32B 등 짧은 구간에 기존의 고정 source DMA를 사용한다. 두 후보 모두 ARM 전송 형식과 길이, 독립 검사 및 최종 ACK를 유지한다.

마감은 993에서 정한 SEAL의 낙관적 진입 한계인 44회 217.55 / 217.51선이다. 수신 처리 열은 각 실행의 마지막 OBJ 패킷 ACK부터 후속 일곱 패킷의 실측 수락→ACK와 SEAL 헤더 처리만 더했다. 따라서 앞선 OBJ 반환 자체의 시각도 반영된다. 실제 열에는 SPI·큐 credit·65816의 다음 헤드 수락 대기와 빈 큐 DMA가 들어간다. ACK 차이의 양수는 978보다 늦다는 뜻이다.

정적 결합에서 908은 두 위상 모두 38회 245선, 909는 624B, 910 캡처 여유는 0.205 / 0.153ms였다. VBlank 44에서 타일을 먼저 보낸 만큼 실제 911 공개선은 4 / 1선 빨라졌지만 두 표시 사이의 간격은 모두 2회, 밀집 여섯 간격 합은 13회였다. 336B 단독 후보는 909가 592 / 592B, 균일 OAM 단독 후보는 560 / 624B였다.

993의 201B 선행 발행까지 결합하면 SEAL은 978보다 0.038 / 0.012ms 빨랐다. 908 공개·909 선행 624B·910 캡처를 지켰지만 두 위상 모두 공개 간격과 마지막 ACK에서 이득은 없었다. 이 추가 대조군의 ARM은 213,084B다.

즉시 복원 대조군은 검증된 inactive WRAM 주소와 현재 수신한 payload에서 계산한 각 바이트를 시뮬레이터가 쓴다. 910까지의 ACK 및 두 번째 OBJ 뱅크 반환은 978과 같은 클록이다. 독립 검사를 마친 뒤의 다섯 데이터 복사만 무료로 놓고 실제 ARM·SPI 및 65816 서비스·ACK를 계속 실행했다. 그 결과 수신 예산에는 여유가 생겼지만, 앞 패킷의 ACK 후 section 5의 240B가 SPI에서 도착하기까지 0.630 / 0.651ms, 그 패킷 ACK 후 SEAL 도착까지 0.245 / 0.272ms가 걸렸다. 이 부호와 시각은 실제 wire 도착과 이전 ACK의 차이다.

두 위상 모두 336B WRAM을 먼저 반전한 뒤 실제 코드가 전체 범위를 복원했고, 첫 64B 직후 STOP은 0xE4와 함께 뒤의 272B를 보존했다. 잘못된 길이는 쓰기 전에 0xE0으로 거부했다. 네 바이트가 모두 다른 입력도 기존 범용 경로에서 336B 전체를 재현했고 뒤따르는 잘못된 cursor를 거부했다. 실패 주입 시험은 모두 910까지의 여섯 공개와 기존 화면을 보존했다. 정상 실행은 905–912의 map·plan·패킷별 데이터와 최종 RGB, 실제 CGRAM·OAM 내용을 대조했다.

978 ARM은 212,992B다. 65816 저장 이미지는 978의 5,096B, 336B 변경의 5,261B, 균일 OAM 변경의 5,142B, 정적 결합의 5,305B다. 보드 한도는 5,120B다. 실험에는 ARM 바이너리, Mesen 65816 및 기존 SPI·ROM 경쟁 모델을 사용했다. 실기판·새 보드 합성·실기 메뉴 복귀 시험은 이번 범위에 포함하지 않았다. [패킷별 클록·DMA·오류 주입 원자료](../analysis/color994-results.json)

## 후속작업

978을 유지한다. 같은 OAM 복사 루프만 더 줄여도 두 위상의 마감을 회복하기 어렵다. 다음에는 실제 wire의 201B·240B·168B SEAL과 수신 복원 비용을 한 번에 줄일 예산을 먼저 확인한다. 911의 240B 본문 중 215B, SEAL 168B 중 132B가 0이다. 압축 해제·독립 검사와 credit까지 포함해 남는 시간을 대조하고 911 공개와 912 ACK가 두 위상에서 모두 앞당겨질 때만 실기 후보로 올린다.
