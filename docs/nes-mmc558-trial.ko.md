# MMC558 제한 실기 시험

1. ZIP의 `01-MMC558-SD-ROOT` 안에 있는 파일을 SD 카드 루트에 덮어쓴다.
2. MMC551에서 사용한 SMB3(J) ROM을 그대로 복사해 `sd2snes/nes/mmc558.nes`로 둔다. 비교 대상 ROM의 CRC32는 `5a04eed7`이다.
3. 메뉴에서 `NES MMC3 558.nh1`을 선택하고, MMC551과 비슷한 첫 레벨 동선으로 약 60초간 플레이한다. 적이 많은 구간의 움직임과 메뉴 복귀를 확인한다.
4. SD 카드의 `sd2snes` 폴더에서 `nes-progress-mmc558.txt`, `nes-budget-mmc558.txt`, `nes-game-last-mmc558.txt`를 전달한다. 시작에 실패하면 재실행 전에 세 로그를 따로 복사해 둔다.

비교 구간은 시작과 끝 5초를 제외한 **5–40초와 40–55초**다. 이 버전은 556의 E1 CRC와 65816 검사·512B map 전송을 사용한다. 두 뱅크의 SPI 수신 권한을 반영한 시뮬레이션에서 개선된 표시 간격이 실기에서도 나타나는지 확인한다. 보드 판정은 MMC529 동등 제한 실기 기준이며, 복구에는 기존 백업을 사용한다.
