# MMC890 · 모험도 4 무입력 60초 실기 시험

1. 기기 전원을 끄고 ZIP을 푼다. `MMC890-ADVENTURE-60SEC-SD-ROOT` 폴더 안의 내용을 SD 루트에 복사한다. 같은 이름의 펌웨어와 메뉴 파일은 동봉본으로 덮어쓴다.
2. MMC872에서 사용한 일본판 모험도 4 ROM을 `sd2snes/nes/mmc890.nes`로 복사한다.
3. SD 메뉴에서 `NES MMC3 890.nh1`을 선택하고 버튼을 뗀다. 표시 시작부터 60초 동안 입력 없이 오프닝과 스테이지 데모를 본다. 장면 전환과 60초 뒤 자동 메뉴 복귀를 확인한다.
4. 메뉴로 돌아온 뒤 `sd2snes/`의 `nes-budget-mmc890.txt`, `nes-progress-mmc890.txt`, `nes-game-last-mmc890.txt`를 보관한다. 중간에 종료되면 남은 파일과 마지막으로 본 장면을 기록한다.

| 구간 | MMC872 실기 기준 | MMC890 비교 방법 |
|---|---:|---|
| 오프닝 1초 이상 30초 미만 | 519장 · 17.90 FPS | budget 로그의 첫 번째 표시 횟수 ÷ 29초 |
| 스테이지 데모 30초 이상 60초 미만 | 523장 · 17.43 FPS | 두 번째 표시 횟수 ÷ 30초 |

30초 정각 표시는 데모에 넣고, 조기 종료했을 때는 끝까지 기록된 구간만 비교한다.
